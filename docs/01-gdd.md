## 1. 아키텍처 원칙 (제일 먼저 정해야 할 것)

### 1.1 시뮬레이션 층과 표현 층을 분리한다

바이브 코딩으로 진행할 때 발목을 잡는 건 GDScript 문법이 아니라 **씬 트리 결합**이다.
노드에 로직을 붙이고 `get_node("../../Manager")` 참조가 쌓이면 몇 주 뒤 엉뚱한 데가 부서진다.

| 층 | 내용 | 형태 |
|---|---|---|
| **시뮬레이션 층** | 회원, 팀, 일정, 경기 계산, 이벤트 판정, 만족도, 재정 | Godot 노드에 붙지 않은 **순수 GDScript 클래스 / Resource** |
| **표현 층** | UI 화면, 경기 연출, 애니메이션 | Godot 노드 |

**시뮬레이션 층은 Godot을 전혀 몰라야 한다.**

이렇게 하면:

- 화면 없이 헤드리스로 시즌 100번을 돌려 밸런싱을 **데이터로** 할 수 있다
- LLM에게 로직 수정을 시킬 때 컨텍스트가 자기완결적이라 정확도가 크게 오른다
- 나중에 UI를 갈아엎어도 게임이 안 부서진다

### 1.2 결정론 — 모든 판정은 시드로 고정한다

모든 확률 판정을 `(게임 시드, 주차, 대상 ID)`로 결정한다. 난수를 그때그때 뽑지 않는다.

#### 세이브 스커밍이 이 게임을 무너뜨릴 뻔했다

**"일요일 아침 공개"가 시그니처 장면(10장)**인데, 결과가 나쁠 때 재로드해서 다시 뽑을 수
있으면 그 장면이 무의미해진다. 용병 호출 베팅(6장)도 실패하면 되감으면 그만이 된다.

**저장을 제한하는 대신 재추첨을 무의미하게 만든다.**

- 재로드해서 **똑같이 플레이하면 똑같은 결과**가 나온다 → 스커밍 무의미
- **다르게 플레이하면 다른 결과**가 나온다 → 정당한 재도전은 가능

> 이번 주에 김씨가 안 나오는 건 되돌린다고 바뀌지 않는다.
> 대신 지난주에 김씨를 만나러 갔다면 나왔을 것이다.

**플레이어를 처벌하지 않으면서 스커밍만 죽인다.** 저장 횟수 제한보다 우아하다.

#### 게임 오버가 없으니 되돌릴 이유도 적다

컨셉에 **"게임 오버 없음"**이라고 적혀 있다. 이것이 유리하게 작용한다.

| 게임 오버가 있으면 | 없으면 |
|---|---|
| "망했다, 되돌리자" | **나쁜 결과도 서사로 흘러간다** |

에이스가 이적해도 게임은 계속되고, 경기가 취소돼도 다음 주가 있다.
**실패가 끝이 아니라 이야기**라서 되돌리기의 유인 자체가 약하다.
세이브 정책이 강제가 아니라 **자연스럽게 성립**한다.

#### 시드로 못 막는 것

이벤트 선택지는 시드로 고정할 수 없다. **선택 자체가 플레이어의 입력**이기 때문이다.
여기는 자동저장 시점으로 완화하되, **굳이 되돌리겠다는 플레이어까지 막지는 않는다.**
핵심 랜덤(참석 · 경기)만 보호되면 게임의 뼈대는 유지된다.

#### 개발에도 이득이다

- **버그 재현이 쉽다** — 시드만 있으면 같은 상황이 재현된다
- **밸런싱이 정확하다** — 같은 시드로 다른 전략을 비교할 수 있다
- 헤드리스 시즌 시뮬레이터(15장)와 정확히 맞는다 — 같은 시드로 100시즌

시드 기반 결정론은 1.1의 순수 로직 층에서 자연스럽게 나온다.

### 1.3 세이브 정책

| 층 | 정책 |
|---|---|
| **슬롯** | **최대 3개** = 별개의 게임 |
| **슬롯 내부** | 자동저장 + 수동저장 **둘 다 지원** |

슬롯을 여러 개 두는 이유는 스커밍과 무관하다. 캐릭터 생성 4축(5.3)이 사실상 난이도이자
**다른 게임**이라, 한 번에 하나만 할 수 있으면 그 설계가 죽는다.

> "다른 동네에서 30대 외부인으로 다시 해보고 싶다"

수동 저장을 허용해도 **시드 고정이 핵심 랜덤을 지키므로** 문제되지 않는다.

- 자동저장 — 주 진행마다
- 수동저장 — 언제든
- **되돌릴 수 없는 결정에는 확인 대화상자** (방출 통보, 규칙 제정, 장기 예약)

> 🔶 **미정:** 아이언맨 옵션(수동 저장 비활성화). 시드 고정으로 핵심은 이미 보호되고
> 게임 오버도 없으므로 지금 넣을 필요는 없다. 원하는 플레이어가 생기면 옵션 하나로 추가.

## 2. 회원 (Member)

이 게임의 유일한 핵심 엔티티. 다른 모든 시스템은 회원의 파생이다.

### 2.1 데이터 구조 — 3층

**"무슨 형" 같은 분류 라벨은 쓰지 않는다.** 수치 조합에서 성격이 읽히게 한다.

| 층 | 항목 | 답하는 질문 |
|---|---|---|
| **능력** | 기술 · 체력 · 피지컬 · 스피드 · 센스 (5) | 경기에서 **뭘 할 수 있나** |
| **기질** | 성실함 · 친화력 · 승부욕 · 자존심 · 참을성 · 영향력 (6) | **어떤 사람인가** |
| **포지션 적성** | GK / DF / MF / FW 각각 등급 (4) | **어디에 세울 수 있나** |
| **프로필** | 직업 · 거주지 · 가족 상황 · 나이 | **어떤 상황인가** |
| **상태** | 컨디션 · 부상 · 만족도 | 지금 어떤가 (변동값) |
| **이력** | 출전 수, 득점, 가입 시점, 규칙 위반 횟수 | 서사의 재료 + 규칙 판정 근거 |

### 2.2 능력 (5)

| 능력 | 무엇 | 나이 영향 |
|---|---|---|
| **기술** | 볼 다루기, 슛, 패스 | 거의 없음 |
| **체력** | 활동량, 90분 유지 | 급격히 하락 |
| **피지컬** | 몸싸움, 높이, 반사신경 | 완만히 하락 |
| **스피드** | 순간 속도, 순발력 | **가장 급격히 하락** |
| **센스** | 위치 선정, 판단, 패스 타이밍 | **나이와 함께 상승** |

스피드와 센스가 정반대 곡선이라 **세대 대비**가 선명해진다.

> 젊은이 — 스피드 · 체력 높고 센스 없음. 열심히 뛰는데 엉뚱한 데로 뛴다
> 노장 — 스피드 · 체력 없고 센스 · 기술 높음. 안 뛰는데 공이 그 앞으로 온다

### 2.3 기질 (6)

| 기질 | 높으면 | 낮으면 |
|---|---|---|
| **성실함** | 웬만하면 나온다 | 기분 내킬 때만 |
| **친화력** | 누구와도 잘 어울린다 | 겉돈다 |
| **승부욕** | 팀이 지면 분해한다 | 결과에 무심 |
| **자존심** | 벤치 · 교체를 못 견딘다 | 안 뛰어도 괜찮다 |
| **참을성** | **조용히 삭인다** | 작은 일에도 터진다 |
| **영향력** | **감정이 남에게 퍼진다** | 혼자 조용히 |

#### 승부욕과 자존심은 다르다

구분되는 순간은 하나다. **팀이 이기려면 내가 빠져야 할 때.**

| 조합 | 반응 |
|---|---|
| 승부욕만 높음 | "내가 빠지는 게 낫겠네" — 순순히 벤치, 대신 지면 자기가 더 분해함 |
| 자존심만 높음 | "지든 말든 나는 뛴다" |
| **둘 다 높음** | **"내가 뛰어야 이긴다"고 믿는다** — 실력이 받쳐주면 에이스, 아니면 민폐 |
| 둘 다 낮음 | 그냥 나와서 어울리는 사람 |

#### 참을성이 높은 게 좋기만 한 게 아니다

| 참을성 | 표출 방식 | 플레이어 입장 |
|---|---|---|
| 낮음 | 자주 터진다 | 시끄럽지만 **신호를 준다** |
| 높음 | 조용히 삭인다 | 편하지만 **어느 날 그냥 사라진다** |

톤 가이드라인의 "그냥 시들해짐, 연락이 뜸해짐"이 여기서 나온다.
**조용한 사람의 만족도는 플레이어가 먼저 살펴야 알 수 있다.**

#### 영향력

스탯과 무관하게 어떤 사람을 구조적으로 중요하게 만든다.

> "저 형이 나가면 세 명이 따라 나간다."

파벌 형성과 분열(7장 이탈 경로 3번)이 이 수치 하나로 굴러간다.
실력은 평범한데 절대 놓치면 안 되는 사람이 생긴다.

### 2.4 조합이 성격을 만든다

라벨은 게임이 붙이는 게 아니라 **플레이어가 읽어내는 것**이다.

| 조합 | 플레이어가 느끼는 것 |
|---|---|
| 성실함↑ 친화력↑ 자존심↓ | 궂은일 도맡는 형님. 안 뛰어도 매주 나온다 |
| 승부욕↑ 자존심↓ | 벤치에서도 열심히 응원. 지면 자기가 더 분해함 |
| 승부욕↓ 자존심↑ | 지든 말든 나만 뛰면 됨 |
| 성실함↓ 기술↑ | **에이스인데 반은 안 나온다.** 제일 골치 아픈 유형 |
| 친화력↑ 능력 전부↓ | 실력은 없는데 이 사람 없으면 분위기가 안 산다 |
| 성실함↑ 자존심↑ 능력↓ | **"3년 개근인데 출전 시간 꼴찌"** — 가장 아픈 케이스 |
| 참을성↑ 영향력↑ | **조용한 실세.** 터지면 팀이 쪼개진다 |

분류가 아니라 조합이라 **경계에 있는 사람**도 표현된다.
3종 분류로는 못 담던 애매한 사람이 오히려 대부분이다.

### 2.5 포지션 적성

회원마다 **포지션 4개 각각에 등급**을 가진다.

| 등급 | 성능 | 만족도 |
|---|---|---|
| 주포지션 | 100% | — |
| 소화 가능 | 소폭 하락 | — |
| 못함 | 크게 하락 | **하락** (자존심 높으면 더) |

포지션별 주력 능력:

| 포지션 | 주력 |
|---|---|
| GK | 피지컬 + 센스 |
| DF | 피지컬 + 스피드 + 센스 |
| MF | 체력 + 센스 + 기술 |
| FW | 스피드 + 기술 |

**GK 적성이 희소재다.** 명단 14명 중 GK 적성자가 1명이면 그 사람 결석 = 매주 위기.
"GK 한 명 더 확보"가 명확한 중기 목표가 되고, 영입 전략을 규정한다.

### 2.6 만족도

**출전 시간이 만족도의 최대 입력값이다.** 단, **기질이 가중치로 작동**해서
공식은 하나인데 사람마다 결과가 달라진다.

| 입력 | 크게 반응하는 기질 |
|---|---|
| 출전 시간 (+/−) | 자존심 |
| 팀 성적 (+/−) | 승부욕 |
| 회식 · 소모임 참여 (+) | 친화력 |
| 교체 당함 (−) | 자존심 |
| 적성 없는 포지션 기용 (−) | 자존심 |
| 추가 회비 징수 (−) | — (직업이 좌우) |
| 사이 나쁜 회원과 함께 뛰기 (−) | 친화력(역) |
| 경기 취소 (−) | 승부욕 · 자존심 |
| 규칙이 불공정하게 적용됨 (−) | — **예외를 두면 여기서 터진다** |

#### 5단계

내부적으로는 0~100 수치지만 **플레이어에게 숫자를 보여주지 않는다.** 5단계로만 보인다.

| 단계 | 범위 | 행동 |
|---|---|---|
| **아주 좋음** | 80~100 | 참석률 상승 + **신규 회원 소개** · 분위기 상승 |
| **좋음** | 60~79 | 웬만하면 나온다 |
| **그저 그럼** | 40~59 | 평범. 있는 듯 없는 듯 |
| **안 좋음** | 20~39 | 불참 증가, 출전 요구, 교체 거부 |
| **많이 안 좋음** | 0~19 | **탈퇴 / 타 구단 이적** |

> **"신규 회원 소개"는 아주 좋음에서만 나온다.** 좋음과 아주 좋음을 나누는 이유가 이것이다.

불만이 표면에 드러나는 속도는 **참을성**이, 그 불만이 남에게 번지는 정도는
**영향력**이 결정한다.

#### 화면에는 얼굴로 나온다

만족도는 **숫자가 아니라 얼굴 아이콘 5종**으로 표시한다 (`16×16` 도트, 05-ui.md).

**게이지는 거짓말을 못 하지만 얼굴은 할 수 있다.** 이게 이 표기를 고른 이유다.

#### 참을성 보정 — 조용한 사람은 좋아 보인다

**참을성이 높으면 실제보다 한 단계 좋은 얼굴로 표시된다.**

| 조건 | 표시 |
|---|---|
| 참을성 높음 + 실제 **안 좋음** | **그저 그럼**으로 보인다 |
| 참을성 높음 + 실제 **많이 안 좋음** | **안 좋음**으로 보인다 |
| 참을성 높음 + 실제 좋음 이상 | 보정 없음 — **나쁜 쪽만 가린다** |
| 참을성 낮음 | 항상 정직하게 표시 |

한 방향으로만 거는 이유는 **"편해 보이는 사람이 사실 위험하다"** 는 메시지를
하나로 세우기 위해서다. 좋은 사람이 더 좋아 보이면 그 메시지가 흐려진다.

이 규칙 하나로 2.3의 **"편하지만 어느 날 그냥 사라진다"** 가 화면에서 문자 그대로 일어난다.
가려진 사람을 알아내는 단서는 **관찰 가능한 사실뿐**이다 — 출전 이력 · 읽씹 기간 · 회신 문구.

#### 숫자를 보는 유일한 방법

**따로 만나면** 그 회원의 만족도 숫자가 **한 주 동안** 보인다.
"만나기"라는 행동에 값을 주는 장치이고, 21칸 제약(10장) 때문에
**매주 볼 수 있는 사람은 한둘뿐**이다.

### 2.7 프로필

수치가 아니라 범주. 스탯에 보정을 주고 이벤트를 트리거한다.
**이 층이 있어서 능력 5 · 기질 6만으로도 캐릭터가 무한히 다양해진다.**

| 프로필 | 영향 |
|---|---|
| **직업** | 회비 여력 / 참가 가능 시간대 / 주중 활동 가능 여부 / 시한부 여부 |
| **거주 지역** | 참석 확률(거리) / 이사 이벤트 / **구장 위치와 상호작용** |
| **가족 상황** | 미혼 · 기혼 · 자녀. 자녀가 어리면 주말 아침이 어려움 |
| **나이** | 능력 곡선 / 부상 회복 속도 |

#### 직업

| 직업 | 시간 | 돈 | 특이사항 |
|---|---|---|---|
| 사무직 | 주말 자유 | 여유 | 야근 → 주중 활동 어려움 |
| 교대근무 (생산직 · 간호사 · 경찰) | **불규칙** | 여유 | 참석이 예측 불가 |
| 자영업 (식당 · 가게) | **주말이 대목** | 들쭉날쭉 | 장사 잘되면 못 나옴 |
| 운전직 (택시 · 배달 · 화물) | 주말이 대목 | 불안정 | |
| 학생 · 취준생 | 시간 많음 | **없음** | **군대 · 취업으로 이탈** |
| 은퇴 · 무직 | 시간 많음 | 애매 | 고령 |

**회비 인상이 직업별로 다르게 아프다.** 전원 일괄 하락이 아니라 여력 없는 회원부터
떨어져 나가고, 그런 회원이 대개 **시간은 제일 많은 사람**이다.

#### 거주 지역 × 구장 위치

구장 위치를 고르는 것이 곧 **누구를 배려하는가**가 된다.

> 이번 주는 북쪽 구장. 가까운 5명은 나오기 쉬워지고,
> 남쪽 사는 3명은 아침에 40분을 운전해야 한다.

매주 같은 구장만 잡으면 특정 회원만 유리하고, 돌려가며 잡으면 아무도 완벽히
만족하지 않는다. 라인업과 같은 성격의 배분 딜레마가 하나 더 생긴다.

#### 신규 회원 생성 규칙 (E25)

무작위 조합은 이상한 사람을 만든다(20살 은퇴자). **순서를 정하고 앞이 뒤를 제약한다.**

```
지역 유형 (3.4)  →  나이  →  직업  →  가족 상황
                                        ↓
                     능력 (나이 곡선 2.2 적용)
                                        ↓
                     기질 ← 독립적으로 뽑음
                                        ↓
                     포지션 적성  →  칭호(2.12)  →  이름
```

##### 능력 — 총합은 평범하게, 분배는 편중되게

조기축구는 대부분 평범하다. 그런데 **완전히 평범하면 기억에 안 남는다.**

> 총합은 정규분포로 뽑고, 5개에 나눌 때 편중시킨다.

- **발만 빠른 애** — 스피드만 높고 나머지 평범
- **기술만 좋은데 체력이 없는 형** — 5분이면 숨찬다

**특화형이 기억에 남는다.** 그리고 특화형은 기용 판단을 만든다 —
후반에 넣을지, 특정 상대에게만 쓸지.

##### 기질은 독립적으로 뽑는다

나이 · 직업과 상관관계를 주면 **스테레오타입**이 된다.

> "50대 형님은 다 고집 세고, 20대는 다 불성실하다"

이러면 사람이 안 보이고 분류만 보인다. **성실한 20대 학생**도
**불성실한 50대 형님**도 나와야 한다. 2.4의 "조합이 성격을 만든다"가 여기서 지켜진다.

##### 이름 — 세대별 음절 조합

구현: [`scripts/systems/name_generator.gd`](../scripts/systems/name_generator.gd)

- 성씨는 실제 빈도 가중 (김 22% · 이 15% · 박 10%)
- 이름 음절은 **출생 연대별 풀**에서 조합
- 시드 기반이라 결정론(1.2)을 지킨다

**이름만 봐도 나이대가 느껴진다.**

| 세대 | 생성 예 |
|---|---|
| 1960년대생 | 정표, 동출, 일호, 기국, 성남 |
| 1990년대생 | 정혁, 진원, 규민, 태현, 지일 |

김씨가 22%라 30명이면 6~7명이 김씨다 — **별명이 필요해지는 이유**(2.1)가 데이터로 나온다.

##### GK는 희소하게

GK 적성자 비율을 낮게 잡아야 병목(2.5)이 유지된다.
*"골키퍼 구합니다"* 공고를 내도 잘 안 붙는다(6장).

##### 과장 — 자존심이 폭을 정한다

6장의 "본인 진술은 과장 가능"에서 **과장 폭을 기질에서 가져온다.**

| 자존심 | 자기 실력 진술 |
|---|---|
| 높음 | **크게 부풀림** |
| 보통 | 약간 |
| 낮음 | 정직하거나 오히려 낮춤 |

데이터가 안 늘고, **"말 많은 사람이 실력은 별로"**가 자동으로 나온다.
그리고 자존심 높은 사람은 받고 나서도 벤치를 못 견딘다(2.3) —
**면접에서 잘난 척하는 것이 실제 위험 신호**가 된다.

##### 유입량 — 평판은 질이 아니라 표본을 늘린다

| 평판 | 지원자 | 결과 |
|---|---|---|
| 낮음 | 한 달에 한 명 | **고를 처지가 아님** |
| 중간 | 두세 명 | 약간의 선택 |
| 높음 | 줄을 섬 | **골라 받는다** |

지원자 개개인의 능력 분포는 평판과 무관하다. 다만 **표본이 많으면 좋은 사람이
섞일 확률이 오른다.** 4.7의 "골라 받을 수 있음"과 일관되고,
플레이어가 하는 일(고르는 것)도 남는다.

#### 시한부 회원

**생성 시점에 심긴다.** 학생 · 취준생은 군대 · 취업으로, 그 외 이사 예정 · 출산 예정.
면접에서 알 수도, 모를 수도 있다.

> **"2년 뒤 군대 가는 애를 지금 받을 것인가."**

인원이 급하면 받아야 한다. 하지만 유니폼 값 들여서 2년 쓰고 보낸다.
이사 예정, 출산 예정도 같은 성격. **알고도 받는 결정**이라 후회가 플레이어 몫이 된다.

### 2.8 플레이어에게 어떻게 보여줄 것인가

회원당 수치가 15개다(능력 5 + 기질 6 + 포지션 4). 숫자를 나열하면 읽히지 않는다.

**수치는 내부에 두고 문장으로 요약해 보여준다.**

> 성실하고 조용한 편. 벤치는 잘 견디지 못함.
> 발이 느려졌지만 위치 선정이 좋다.

숫자를 원하는 플레이어를 위해 상세 보기를 따로 둔다.

**정보 공개 범위**는 관찰로 드러나는 방식으로 간다. 전부 보여주면 최적화 게임이 되고,
전부 숨기면 랜덤으로 느껴진다. **관찰 수단은 단톡방(10장)이다** — 읽씹과 응답 패턴이
만족도의 간접 지표가 된다. 별도 UI를 만들지 않아도 된다.
초기 구현은 전부 공개로 시작해 재미를 먼저 확인하고, 이후에 가린다.

### 2.9 궁합

회원 간 감정 값. 사이 나쁜 둘을 같이 출전시키면 팀 전체 성능 하락.

이거 하나로 **라인업이 퍼즐이 된다.** 잘하는 11명을 고르는 게 아니라, "이 둘은 사이가
나쁘고, 저 형은 벤치 되면 삐지고, 이 친구는 이적 후보라 못 빼고"를 매주 푸는 게 된다.

- 전체 행렬(N명이면 N(N−1)/2 쌍)은 회원이 늘수록 제곱으로 커진다
- **가시성이 미정이다.** 전부 숨기면 랜덤으로 느껴지고, 전부 보여주면 정보 과부하
- 유력안: **이벤트로 발견되게** 한다. 처음엔 안 보이다가 사건을 통해 드러남

#### 궁합은 누적된다 (E27)

입력이 둘이다.

| 입력 | 속도 | 성격 |
|---|---|---|
| **같이 출전** | 빠름 | 호흡이 맞아간다 |
| 회식 · 소모임 | 느림, **전체적** | 친해진다 |

여기서 트레이드오프가 하나 더 나온다.

| 전략 | 궁합 | 대가 |
|---|---|---|
| 고정 라인업 | **빠르게 쌓임** → 강해짐 | 벤치 불만 폭발 |
| 로테이션 | 안 쌓임 → 약함 | 다들 만족 |

**로테이션 팀은 회식으로 메울 수 있다. 대신 돈이 든다.**

> 골고루 뛰게 하려면 회식을 자주 해야 한다.

화목 축의 비용이 "전력 손실"이라는 막연한 표현에서 **재정 비용으로 구체화**된다.
회식은 다음날 컨디션도 깎으므로(10장) 그것도 대가다.

#### 나이 차가 궁합 속도를 늦춘다

20대와 50대는 회식을 같이 해도 궁합이 천천히 오른다(2.11).
**연령대가 벌어지면 파벌이 생기는 이유**가 여기에 있다.

### 2.10 능력은 어떻게 변하는가

#### 훈련은 성장이 아니라 유지다 (E24)

> 조기축구 훈련은 실력을 늘리는 게 아니라 **떨어지는 걸 늦추는** 것이다.

이 정의가 다른 설계를 전부 지킨다.

- 노장이 훈련해도 젊어지지 않는다 → **노장 아키타입 유지**(2.3)
- 성실함이 능력으로 환전되지 않는다 → **"잘하는 사람 ≠ 좋은 회원" 유지**
- 영입이 여전히 주된 전력 개선 수단이다 → **유입 채널의 긴장 유지**(6장)

그리고 이 게임의 문법에 반대 버전이 생긴다.

> 단기 처방이 장기 병을 키운다 ↔ **장기 투자는 눈에 안 보인다**

훈련은 효과가 즉시 보이지 않는다. 안 해도 당장은 멀쩡하고, 2년 뒤에 티가 난다.

##### 훈련 3종 — 통제 가능한 건 하나뿐

| 종류 | 비용 | 효과 | 플레이어 통제 |
|---|---|---|---|
| **경기 전 몸풀기** | 없음 | 부상 위험 소폭↓ | 자동 |
| **따로 훈련** | 구장 + 슬롯 | 능력 하락 지연 | **가능** |
| **개인 관리** | — | 하락 지연 | **불가능** |

세 번째가 중요하다. **개인 운동은 시킬 수가 없다.**

- 성실함이 높으면 알아서 관리한다
- 낮으면 배가 나온다

플레이어가 할 수 있는 건 잔소리뿐이고 그건 만족도를 깎는다.
**"권한 없음"이 여기서도 나온다.**

"따로 훈련"은 참석률이 낮다. 다들 직장이 있고, 경기도 아닌데 새벽에 나오라면 안 나온다.
**훈련 참석률 자체가 팀 상태의 지표**가 된다.

#### 포지션 적성 확장 — GK를 만들 수 있다

계속 그 자리에 세우면 **"못함" → "소화 가능"**까지 올라간다. **주포지션까지는 못 간다.**

그러면 GK 병목(2.5)에 해법이 하나 생긴다.

> **GK를 만들 수 있다. 대신 그 사람을 몇 달간 괴롭혀야 한다.**

적성 없는 자리에 세우면 팀 성능이 떨어지고 그 사람 만족도가 깎인다(2.5).
자존심이 높으면 더 깎인다. 그걸 몇 달 버텨야 소화 가능해진다.

**누구를 희생시킬 것인가**가 결정이 된다. 주포지션까지는 안 가므로
**진짜 GK 영입이 여전히 낫다** — 병목이 완화되되 사라지지 않는다.

#### 정리 — 상승 경로 4가지

개인 능력은 거의 안 오른다. 대신 **팀이 좋아진다.**

| 경로 | 무엇이 오르나 |
|---|---|
| 훈련 | 능력 **하락 지연** |
| 궁합 누적 | 팀 전체 성능 |
| 포지션 적성 확장 | 기용 유연성 |
| 경험 | 센스 소폭 (나이 곡선의 일부, 2.2) |

개인을 키우는 게 아니라 **조직을 굴러가게 만드는** 것 — 주제와 맞는다.

### 2.11 나이 위계 (E26)

5.1의 *"나이 위계와 인간관계가 직책보다 위"* 를 실제로 굴리는 시스템.
**코어 판타지의 근거**라 여기가 비면 "권한 없음"이 말뿐이 된다.

#### 별도 수치를 두지 않는다

**나이 차이에서 계산한다.** 데이터가 늘지 않는다.

한국 동호회의 서열은 나이와 연차 두 축인데, **우선 나이 하나로 간다.**
(연차 축 — 나이는 어린데 먼저 들어온 사람 — 은 나중에 검토)

#### 위계가 하는 일

##### ① 지시가 통하는가

| 상대 | 지시 수용 |
|---|---|
| 나보다 어림 | 잘 통함 |
| 동갑 · 비슷 | 보통 |
| **나보다 나이 많음** | **잘 안 통함** |
| 나이 많고 창단 멤버 | **거의 안 통함** |

교체 지시 거부(11장)와 규칙 무시(8.7)가 신뢰만이 아니라 **위계에도** 걸린다.

30대 외부인으로 시작하면 명단 절반이 형님이고, 50대 창단 멤버로 시작하면
대부분이 동생이다. **캐릭터 생성 한 줄이 난이도를 정하는 이유**가 여기서 구체화된다.

##### ② 규칙 제정에 걸린다

8.8의 *"영향력 높은 회원의 동의를 미리 얻는 것이 실질적 절차"* 에서
**영향력의 실체가 나이**다.

> 최고참 형님이 반대하면 규칙이 안 선다.

##### ③ 궁합 형성 속도 (2.9)

나이 차가 크면 관계가 잘 안 쌓인다. **연령대가 벌어지면 파벌이 생기고**,
그것이 분열(7장 이탈 경로 3번)의 씨앗이 된다.

#### 호칭 — 싸고 효과가 크다

**텍스트에 호칭만 넣으면 된다.**

| 상대 | 호칭 |
|---|---|
| 나이 많고 친함 | **형님** |
| 나이 많고 안 친함 | ○○님 |
| 동갑 | 이름 |
| 어리고 친함 | 이름 / 야 |
| 어리고 안 친함 | ○○씨 |

**궁합이 오르면 호칭이 바뀐다.** `"김○○님" → "형님"` 이 되는 순간이
관계 진전의 신호가 되고, 수치를 보여주지 않는 설계(2.8)와 맞는다.

이벤트 텍스트도 같은 대사가 호칭만 바뀌어 재사용된다 —
**텍스트 물량이 최대 작업량**인 게임(13장)에서 큰 이득이다.

#### 여기서 나오는 딜레마

##### 실력과 서열이 어긋날 때

> 제일 못하는 사람이 제일 높은 형님이다.

- 벤치에 앉히면 → 위계를 거스름. 본인도 주변도 불편
- 계속 뛰게 하면 → 전력 손실, 승부욕 높은 회원 불만

**자존심 기질이 나이와 곱해진다.** 나이 많고 자존심 높은 회원이 최악의 조합이다.

##### 젊은 실력자를 데려오면

전력은 오르는데 **위계가 흔들린다.** 형님들 위에 세우면 반발이 나오고,
안 세우면 데려온 의미가 없다.

#### 나이 분포가 팀 성격이 된다

지역 유형(3.4)이 프로필 분포를 정하므로 **연고지가 연령 구성을 좌우한다.**

| 팀 구성 | 성격 |
|---|---|
| 고령 편중 | 위계 안정. 전력 낮음. 화목하지만 정체 |
| 젊은 편중 | 전력 높음. 위계 약함 → **규칙이 잘 안 선다** |
| **양극화** | **파벌 발생 위험** |

### 2.12 칭호 (Trait)

기질(2.3)이 **수치**라면 칭호는 **이름이 붙은 라벨**이다.

> 리더형 · 독불장군 · 평화주의자 · 유리몸 · 개근왕

D6에서 폐기한 "성향 3종 분류"와는 다르다. 그건 **모든 사람을 3칸에 넣는 것**이었고,
칭호는 **선택적이고, 여러 개 가질 수 있고, 없을 수도 있고, 나중에 생기기도 한다.**

#### 하는 일

| 역할 | 내용 |
|---|---|
| **식별** | 30명이 있어도 칭호로 기억한다 |
| 표시 | 2.8의 "수치는 내부, 표시는 문장"의 **압축판** |
| 기계적 효과 | 소폭 보정 |
| 이벤트 조건 | 트리거 필터 |

*"성실하고 조용한 편"* 대신 **`묵묵한 일꾼`** 한 단어로 끝난다.

#### 획득 방식 — 두 가지

| 시점 | 조건 |
|---|---|
| **생성 시** | 기질 · 능력 조합이 조건을 만족하면 **확률적으로** 부여 |
| **진행 중** | 누적 기록이 조건을 만족하면 |

**있기도 하고 없기도 하다.** 아무 칭호도 없는 평범한 회원이 대부분이어야
칭호가 눈에 띈다.

일부는 **잃을 수도 있다** (`개근왕`이 결석하면). 일부는 영구다 (`창단 멤버`).

#### 칭호 목록 (초안 30종)

**성격형** — 기질 조합에서 파생

| 칭호 | 조건 |
|---|---|
| 리더형 | 영향력 높음 + 친화력 높음 |
| 독불장군 | 자존심 높음 + 친화력 낮음 |
| 평화주의자 | 친화력 높음 + 참을성 높음 |
| 분위기 메이커 | 친화력 최상 |
| 묵묵한 일꾼 | 성실함 높음 + 자존심 낮음 |
| 욱하는 성격 | 참을성 낮음 |
| 승부사 | 승부욕 최상 |
| 마이웨이 | 영향력 낮음 + 자존심 높음 |
| 예스맨 | 자존심 낮음 + 친화력 높음 |
| **조용한 실세** | 참을성 높음 + 영향력 높음 |

**능력형**

| 칭호 | 조건 |
|---|---|
| 해결사 | 기술 높음 |
| 철인 | 체력 최상 |
| 유리몸 | 부상 잦음 |
| 벽 | 피지컬 높음 |
| 총알 | 스피드 높음 |
| 축구 도사 | 센스 높음 |
| 만능 | 전 능력 평균 이상 |
| 몸치 | 전반적으로 낮음 |

**이력형** — 진행 중 획득

| 칭호 | 조건 |
|---|---|
| 창단 멤버 | 초기 가입 (영구) |
| 개근왕 | 무결석 누적 (잃을 수 있음) |
| 지각대장 | 지각 누적 |
| 유령 회원 | 명단에만 있고 안 나옴 |
| 백경기 | 출전 100회 |
| 베테랑 | 재적 N년 |
| 신입 | 가입 6개월 미만 (자동 소멸) |

**사건형** — 이벤트로 획득

| 칭호 | 조건 |
|---|---|
| 결승골의 사나이 | 결승골 누적 |
| 퇴장왕 | 퇴장 누적 |
| 회식왕 | 회식 개근 |
| 총무 출신 | 전임자 (특수) |
| 용병 출신 | 용병으로 왔다가 영입됨 |
| 돌아온 탕아 | 탈퇴 후 재가입 |

#### 왜 칭호가 값싼가

**전부 기존 데이터에서 파생된다.** 새 수치를 만들지 않는다.

- 성격형 = 기질 조합 조건
- 능력형 = 능력 임계값
- 이력형 = 누적 기록 (이미 2.1에 있음)
- 사건형 = 이벤트 결과

데이터는 안 늘고 **캐릭터 식별성은 크게 오른다.**

## 3. 세계와 지리

지도를 그리려는 게 아니라 **거리를 계산하려는 것**이다.

| 용도 | 영향 |
|---|---|
| 회원 거주지 ↔ 구장 거리 | **참석 확률** |
| 구장 위치 선택 | **배분 결정** — 누구를 배려하는가 (2.7) |
| 신규 회원 유입 | 어느 지역에서 지원이 오는가 |
| 이사 이벤트 | 자연 이탈 경로 |
| 원정 거리 | 리그 진입 이후 (보류) |

### 3.1 실존 지명을 쓴다

| 광역 | 단위 | 개수 |
|---|---|---|
| 서울 | 자치구 | **25** |
| 경기 | 시 · 군 | **31** (28시 + 가평 · 양평 · 연천) |

컨셉 문서의 원칙과 충돌하지 않는다 — **실존 팀 · 인물 이름은 안 쓰되 지명은 자유.**

연고지 선택은 **구 / 시 단위**로만 한다. 그 아래로는 플레이어가 고르지 않는다.

### 3.2 거리 — 좌표로 계산한다

각 구 · 시에 좌표를 준다(실제 위경도 기반). 거리표를 손으로 쓰지 않는다.

플레이어에게는 좌표가 아니라 **이동 시간(분)**으로 보여준다.

```
회원 거주: 강서구
우리 팀 연고: 강동구
→ 서울을 가로지름. 새벽 6시에 못 옴
```

조기축구단은 동네 기반이라 **대부분 같은 구, 일부는 옆 구**에 산다.
"옆 구 사람이 새벽에 나오기 힘들다"는 설명이 필요 없다.

| 거리 | 체감 | 참석 영향 |
|---|---|---|
| 같은 구 · 가까움 | 걸어서 / 차로 10분 | 없음~소폭 |
| 인접 구 | 차로 20~30분 | 중간 |
| 멀리 | 차로 40분+ | **큼** |

**새벽 6시에 40분 운전**은 진짜 장벽이다. 겨울엔 여기에 추위와 어둠이 곱해진다(D4).

### 3.3 구 내부는 숨겨진 좌표로 쪼갠다

구 단위로만 두면 **우리 구 안에서는 다들 같은 거리**가 되어, 구장 위치 선택이
배분 결정이 되지 못한다(2.7). 그래서 구 안에도 위치를 둔다.

- 회원마다 **구 내부 좌표**를 가진다
- 이 좌표는 **플레이어에게 노출하지 않는다**
- 표시는 `"강서구 · 구장까지 25분"` 형태로만

동 이름을 만들지 않으므로 데이터도 UI도 늘지 않는데, 배분 딜레마는 살아난다.

> 이번 주는 북쪽 구장. 가까운 5명은 편해지고 남쪽 3명은 40분을 운전한다.

### 3.4 지역 특성 — 유형으로 배정한다

56개 지역을 개별 설계하지 않는다. **유형에 배정만 한다.**
유형은 신규 회원의 프로필 분포(직업 · 가족 상황 · 나이대)를 결정한다.

| 유형 | 주로 오는 사람 |
|---|---|
| **업무지구** | 사무직, 야근 많음 → 주중 활동 어려움 |
| **주거지구** | 기혼 · 자녀. 안정적이지만 육아로 빠짐 |
| **대학가** | 학생 · 취준생. 시간 많고 돈 없고 **시한부** |
| **상업지구** | 자영업 · 운전직. **주말이 대목**이라 참석 불안정 |
| **산업단지** | 교대근무. **참석 예측 불가** |
| **신도시** | 젊은 기혼, 통근 김 |

이러면 **연고지 선택이 장기적으로 팀 구성을 바꾼다.** 대학가면 젊고 시간 많은 회원이
모이지만 몇 년 뒤 다 떠나고, 주거지구면 안정적인데 육아로 빠지는 사람이 많다.

#### ⚠️ 실존 지역에 값을 매기지 않는다

"○○구는 회비 여력 낮음" 같은 설정은 **실제 지역에 대한 평가**가 되어 반발을 산다.

그래서 특성을 **평가가 아니라 생활 패턴**으로 잡는다. 위 표가 "부유함/가난함"이 아니라
"업무지구/대학가"인 이유다. 같은 기계적 효과를 내면서 가치 판단은 하지 않는다.

돈은 **직업 분포를 통해 간접적으로** 작동시킨다. 대학가에 학생이 많은 건 사실 서술이고,
학생이 회비 여력이 없는 건 프로필 규칙이다(2.7).

### 3.5 구현 범위

56개 전부를 정교하게 만들 필요는 없다.
**실제로 쓰이는 건 연고 구 + 인접 3~5개**뿐이다. 리그가 열리기 전엔 원정도 없다.

| 지역 | 필요한 것 |
|---|---|
| 연고 구 | 전부 (구장, 상대팀, 특성, 내부 좌표) |
| 인접 구 3~5개 | 특성 + 상대팀 일부 |
| 나머지 | **이름과 좌표만** |

### 3.6 구장

**이 게임에서 밀도가 가장 높은 결정.** 구장 하나를 고르면 7개 시스템이 동시에 움직인다.

#### 개수 — 지역 유형과 연동

랜덤이 아니라 유형(3.4)에 묶는다. 그래야 **연고지 선택에 전략적 무게**가 생긴다.

| 지역 유형 | 구장 수 | 이유 |
|---|---|---|
| 업무지구 | 2 | 땅값. 구장이 귀함 |
| 상업지구 | 2~3 | |
| 대학가 | 3 | 대학 운동장 |
| 산업단지 | 3~4 | 공터는 많은데 시설이 나쁨 |
| 주거지구 | 4~5 | 학교 운동장, 공원 |
| 신도시 | 4~5 | 계획적으로 지어둠 |

구장 2개짜리 구는 예약 경쟁이 상시다. 5개짜리는 여유롭지만 대신 다른 걸 잃는다.

#### 속성 5종

| 속성 | 연결되는 시스템 |
|---|---|
| **위치** | 참석 확률(3.3), 배분 딜레마(2.7) |
| **대관료** | 재정 — 경기당 비용(9장) |
| **잔디** | 부상 위험, 경기 질 |
| **시설** | **만족도** |
| **수용규격** | 경기 질 (아래 참조) |

#### 잔디 × 계절

잔디 종류가 계절과 **곱해진다.** 이것이 계절(D4)을 구장 선택으로 끌어온다.

| 잔디 | 대관료 | 봄 · 가을 | 여름 | 겨울 |
|---|---|---|---|---|
| **천연잔디** | 비쌈 | 최상 | 좋음 | 잔디 보호로 폐쇄될 수도 |
| **인조잔디** | 보통 | 좋음 | **뜨겁다** — 체력 소모↑ | **딱딱하다** — 부상↑ |
| **맨땅 (흙)** | 쌈 | 보통 | 먼지 / 장마엔 진흙탕 | **얼어붙음** — 부상 최악 |

**맨땅 + 겨울이 최악인데 그게 제일 싸다.** 돈 아끼려고 맨땅을 잡으면 봄에 부상자가 쌓인다.
*단기 처방이 장기 병을 키운다* 는 이 게임의 반복 문법이 여기서도 나온다.

#### 시설 → 만족도

싸구려 구장은 돈은 아끼는데 **회원들이 싫어한다.**

| 시설 | 없으면 |
|---|---|
| 샤워실 · 탈의실 | 겨울에 치명적 |
| 주차장 | 거리 페널티가 커짐 |
| 조명 | 겨울 새벽엔 어둡다 |
| 화장실 | 기본적인 불만 |
| **근처 식당** | **뒤풀이가 힘들다** → 친화력 높은 회원 만족도↓ |

마지막 항목이 구장을 **회식 시스템과 물린다.** 밥집 없는 구장을 잡으면
친목 성향 회원이 조용히 불만을 쌓는다.

#### 시간대 — 2시간 단위 8회전

실제 공공 구장 구조를 따른다. **운영 06:00~22:00, 2시간 슬롯 8개.**

| 슬롯 | 대관료 | 예약 경쟁 | 참석률 |
|---|---|---|---|
| **06~08 (조기)** | **가장 쌈** | 낮음 | **낮음** — 춥고 어둡다 |
| 08~10 | 보통 | **높음** | 높음 |
| 10~12 | 보통 | 높음 | 높음 |
| 12~18 | 보통 | 중간 | 중간 (덥다) |
| 18~20 | 비쌈 | **가장 높음** | 직장인 유리 |
| 20~22 (야간) | 비쌈 | 높음 | 직장인 유리. 조명 필요 |

**주말은 평일의 약 2배.** 시간대 차이보다 주중/주말 격차가 크다.

##### 조기축구의 정체성이 곧 함정이다

**새벽이 가장 싸고 가장 안 나온다.**

돈을 아끼려면 새벽인데, 새벽이면 사람이 덜 나온다.
오전으로 옮기면 사람은 나오는데 예약 경쟁이 치열하고 비싸다.
저녁으로 가면 직장인이 편해지지만 그건 더 이상 *조기*축구가 아니다.

##### 겨울에도 모든 슬롯이 열린다

실제로는 잔디 보호와 안전 때문에 겨울 조기 대관을 막는 구장이 있지만,
**규칙을 단순하게 유지하려고 넣지 않는다.**

겨울의 압박은 **부상 위험 상승** 하나로만 표현한다(위 잔디 × 계절 표).
슬롯 폐쇄까지 넣으면 계절 규칙이 두 겹이 된다.

#### 수용규격 — 품질 차이로만 다룬다

**규격은 전부 11인제로 통일한다.** 좁은 구장은 규격이 다른 게 아니라
**경기 질이 떨어지고 부상 위험이 올라가는** 것으로 처리한다.

8인제 같은 별도 규격을 두면 경기 로직이 두 벌 필요해진다. 실내 구장을 뺀 것과 같은 이유다.
(*"싼 구장을 잡으면 3명이 덜 뛴다"* 는 트레이드오프는 매력적이지만 비용이 크다. 나중에 재검토.)

#### 예약 방식 3종

셋을 다 두는 이유는 **각각 다른 종류의 판단을 요구**하기 때문이다.

| 방식 | 요구하는 것 | 실패 시 |
|---|---|---|
| **선착순** | **행동 우선순위** — 주중에 이걸 먼저 할 것인가 | 늦으면 마감 |
| **추첨** | **리스크 관리** — 떨어질 걸 대비해 대안 준비 | 확률적 실패 |
| **단골우대** | **장기 투자** — 같은 곳을 계속 써야 우선권이 쌓임 | 안 쌓아두면 밀림 |

선착순은 주간 행동 제약(E16)과 직결된다. 행동을 2~3개만 할 수 있는데
그중 하나를 예약에 쓸 것인가가 딜레마가 된다.

#### 단골우대 ↔ 배분 공정성

**예약 안정성과 회원 배분이 정면으로 부딪힌다.**

| 전략 | 얻는 것 | 잃는 것 |
|---|---|---|
| 한 구장만 계속 사용 | 단골 우선권. 예약이 안정됨 | **먼 회원이 몇 년간 계속 손해** |
| 돌려가며 사용 | 회원들이 골고루 편해짐 | 어디서도 우대를 못 받아 예약이 불안정 |

별도 시스템 없이 이미 있는 두 개가 충돌한다.

#### 계절 × 예약 난이도

| 계절 | 선착순 | 추첨 | 단골우대 |
|---|---|---|---|
| 봄 · 가을 | **순식간에 마감** | 경쟁률 높음 | **여기서 값어치가 드러남** |
| 여름 | 보통 | 보통 | 보통 |
| 겨울 | 여유 | 거의 당첨 | 쓸모없음 |

**단골우대는 봄가을에만 값어치가 있다.** 그래서 *"겨울에 쌓아서 봄에 쓴다"* 는 계획이 성립한다.

#### 예약 실패와 취소

| 상황 | 결과 |
|---|---|
| 대안 구장으로 | 더 멀거나 비싸거나 나쁨 |
| 아무 데도 못 잡음 | **그 주 경기 없음** → 출전 기회 상실, 만족도↓ |
| 장마로 당일 취소 | **대관료 90% 환불.** 재정 타격은 작지만 **회원 불만이 오른다** |

장마 취소의 진짜 비용은 돈이 아니라 **만족도**다. 새벽에 나올 준비를 했는데 헛수고가 된
것이라, 손실이 회계 장부가 아니라 감정 쪽에 남는다. (2.6 "경기 취소" 입력)

#### 구장 선택 하나가 건드리는 것

```
구장 선택 ─┬─ 대관료      → 재정 → 경기 수
           ├─ 위치        → 참석 확률 + 배분 딜레마
           ├─ 잔디 × 계절 → 부상 → 다음 시즌 전력
           ├─ 시설        → 만족도 (특히 친목 성향)
           ├─ 규격 · 품질 → 경기 질
           ├─ 예약 방식   → 주간 행동 소모
           └─ 단골 누적   → 장기 예약 안정성 ↔ 배분 공정성
```

새 시스템을 만들지 않고 기존 것들을 엮기만 해서 나온 밀도다.

#### 구장 관리인 (E50) — 게이지가 아니라 태그다

**이 시스템에 통합하지 않는다.** 호감도 수치를 만들면 관리할 것이 하나 더 늘고,
단골 등급(4.8)과 하는 일이 겹친다.

**13.9의 상태 태그로 처리한다.** 이벤트가 태그를 남기고 태그가 다음 이벤트의 조건이 된다.

| 태그 | 붙는 계기 | 효과 |
|---|---|---|
| `관리인_안면` | 인사를 트거나 명절에 챙긴다 *(기회형 이벤트)* | **취소분 연락이 온다** — 추첨에서 떨어져도 자리가 나면 알려준다 |
| `관리인_불쾌` | 뒷정리를 안 하거나 시간을 넘긴다 | 예약 우선순위 하락. 슬롯이 "이미 찼다"고 한다 |

##### 단골 등급과 다른 일을 한다

| | 단골 등급 (4.8) | **관리인 태그** |
|---|---|---|
| 쌓이는 방식 | 누적 이용 — **자동** | 개별 사건 — **행동** |
| 대상 | 구장 | **사람** |
| 하는 일 | 슬롯 우선권 · 정기 예약 | **예외를 만들어준다** |

**관리인은 규칙 밖의 통로다.** 등급으로는 못 얻는 것을 사람으로 얻는다 —
S-09의 *"추첨 떨어짐 → 다 마감 → 경기 취소"* 경로에서 **한 번 살려주는 것**이 그것이다.

##### 구장을 옮기면 사라진다

태그는 **그 구장에 붙는다.** 싼 데를 찾아 옮겨 다니면 아무것도 안 쌓인다.
단골 등급과 같은 방향으로 작동한다 — **한 군데를 오래 다니는 것이 답이다.**

> 이 태그는 **화면에 표시하지 않는다.** 관리인이 연락을 주는 것으로 알게 되고,
> 안 주면 모른다. 2.8의 정보 공개 원칙과 같다.

### 3.7 상대팀 풀

#### 교류권 — 밀도가 아니라 거리로 넓힌다

| 범위 | 팀 수 |
|---|---|
| 연고 구 | 3~5 |
| 인접 구 (각각) | 3~5 |
| 더 먼 구 | **개척**하면 접근 가능 |

연고 구만으로는 선택지가 3~5개뿐이라 매번 같은 팀과 붙게 된다.
그래서 교류권을 넓히는 방향이 **지리적 확장**이 된다. 대신 거리 대가가 붙는다.

#### 홈 / 어웨이가 협상 포인트다

먼 팀과 붙기로 하면 어디서 할지를 정해야 한다(E35와 연결).

| | 우리 구장 | 상대 구장 |
|---|---|---|
| 대관료 | **우리 부담** | 절약 |
| 우리 회원 참석 | 편함 | **원정 부담 → 참석률↓** |

**돈을 아끼면 사람이 안 나오고, 사람을 챙기면 돈이 나간다.**
관계가 좋은 팀은 번갈아 가자고 하고, 나쁘면 자기 구장만 고집한다.

#### 팀 속성

| 속성 | 내용 |
|---|---|
| 전력 | 강 / 중 / 약 |
| 성격 | 거친 · 노장 · 젊은 · 매너좋은 (D5) |
| 소재지 | 구 → 원정 거리(3.2) |
| 우리와의 관계 | 친밀도 |
| 규모 | **그 팀도 인원이 모자란다** |

#### 상대팀도 인원 미달을 겪는다 🔶 *세부 미정*

> **우리 잘못이 아닌데 경기가 날아간다.**

플레이어가 아무리 잘해도 통제할 수 없는 실패가 생기고, 그게 주제(권한 없음)와 맞는다.

다만 **미리 알 수 있게** 하는 방향. 섭외 시점에 상대 사정이 일부 보인다.

| 관계 | 알 수 있는 것 |
|---|---|
| 좋음 | "요즘 사람이 없대" — **정확한 정보** |
| 보통 | 대략적인 낌새 |
| 나쁨 · 처음 | **모름** — 당일에 당한다 |

**관계 자체가 정보 자산**이 된다. 유입 채널의 정보↔비용 구조(6장)가 여기에도 적용된다.

팀 성격이 갈린다 — 매너 좋은 팀은 목요일에 미리 연락 주고, 아닌 팀은 일요일 아침에 통보한다.
**당일 취소가 관계 악화의 최대 원인**이며, 우리가 취소해도 똑같이 작동한다.

> 미정: 안내를 어느 시점에 어떤 형태로 줄 것인가 (예약 화면? 섭외 화면? 이벤트?)

#### 섭외 절차

```
주중 행동 소모 → 상대 선택 → 제안 → 수락 / 거절
```

거절 사유가 정보를 준다.

| 거절 사유 | 알게 되는 것 |
|---|---|
| 이미 일정 있음 | 인기 있는 팀. 미리 잡아야 함 |
| 관계가 나쁨 | 지난번 일이 안 풀렸음 |
| 전력 차가 큼 | 우리를 상대로 안 봄 |
| **평판이 나쁨** | **아무도 안 붙어준다** |

상대가 우리에게 제안하기도 한다(기회형 이벤트).

#### 관계 시스템

| 좋아지는 요인 | 나빠지는 요인 |
|---|---|
| 정정당당한 경기 | **당일 취소** |
| 뒤풀이 같이 함 | 거친 플레이 · 시비 |
| 인원 부족할 때 용병 빌려줌 | **회원 빼가기**(영입 권유, 6장) |
| 꾸준히 붙어줌 | 일방적 대승 후 매너 없음 |

- 좋으면 — 섭외 수락률↑, **용병을 빌려줌**(비용 절약), 좋은 시간대 양보
- 나쁘면 — 섭외 거절, **우리 회원을 빼감**, 경기가 거칠어짐

분열로 생긴 라이벌 팀(11장)은 **시작부터 최악**의 관계로 등장한다.

#### 강팀과 붙으면 뺏긴다

이탈 경로의 "타 구단 이적"(7장) 대상이 바로 이 상대팀 풀이다.

**표적이 되는 조건:**

| 조건 | 이유 |
|---|---|
| 능력이 높다 | 눈에 띈다 |
| 승부욕이 높다 | 더 강한 팀에서 뛰고 싶다 |
| **출전 시간이 적다** | **여기선 못 뛰니까** |
| 만족도가 낮다 | 흔들릴 준비가 됐다 |

세 번째가 아프다.

> 화목 축 추구 → 에이스 출전 감소 → **유출 위험↑** → 전력 손실

**승리 축은 유출 위험을, 화목 축은 유출 대상을 만든다.** 양쪽 다 대가가 있다.

단 **만족도가 높으면 흔들리지 않는다.** 회피 수단이 있어야 딜레마가 성립하고,
플레이어가 무력해지지 않는다.

회원 쟁탈은 **양방향**이다. 우리가 영입 권유를 하면 그 팀과 관계가 나빠지고,
그 팀도 우리에게 똑같이 한다.

#### 상대팀도 변한다 — 간이 시뮬레이션

세계가 정적이면 몇 시즌 만에 지겨워진다. 그렇다고 우리 팀처럼 정교하게 굴리면
비용이 폭발한다. **팀당 수치 3개만 돌린다.**

| 수치 | 변화 |
|---|---|
| 회원 수 | 매주 소폭 증감 |
| 전력 | 회원 수와 성적에 따라 |
| 사기 | 연패하면 하락 |

**인원이 계속 모자라면 팀이 해체된다.**

> "옆 동네 ○○FC 망했대. 거기 골키퍼 괜찮았는데."

해체된 팀의 회원이 **영입 시장에 나온다.**

- 교류권이 줄어든다 (상대가 하나 사라짐)
- 대신 영입 기회 — **GK 같은 희소 포지션이 나올 수도**
- 관계가 좋았다면 우리에게 먼저 연락이 온다

우리가 겪는 인원 미달을 남들도 겪고, 그 결과가 우리에게 기회로 돌아온다.
수치 3개짜리 시뮬레이션이 **이벤트 소스와 영입 경로를 동시에** 만들어낸다.

신생 팀도 같은 방식으로 생긴다. 우리 팀이 분열하면 그것도 신생 팀이 된다(12장).

#### 난이도 선택

| 상대 | 이기면 | 지면 | 부작용 |
|---|---|---|---|
| 강팀 | 만족도 크게↑ | 사기 하락 | **에이스 유출 위험** |
| 비슷한 팀 | 보통 | 보통 | — |
| 약팀 | 조금↑ (시시함) | 크게↓ (창피) | — |

약팀만 고르면 이기긴 하는데 승부욕 회원이 시시해한다.
강팀만 붙으면 계속 지고 사람을 뺏긴다.
여기에 **거친 팀**이 얹히면 부상 위험까지 곱해지는데, 그런 팀이 대개 제일 세다.

#### 평판의 두 번째 용도

E08(평판)은 지금까지 신규 회원 유입에만 쓰였는데, 여기서 두 번째 용도가 생긴다.

| 평판 | 회원 유입 | 상대 섭외 |
|---|---|---|
| 높음 | 지원자가 줄 섬 | 좋은 팀들이 먼저 연락 |
| 낮음 | 아무도 안 옴 | **경기 자체를 못 잡음** |

경기를 못 잡으면 출전 기회가 사라지고, 그러면 회원이 떠난다.
**평판 하락이 죽음의 나선을 만든다.** 인수 시작(D1)이 평판 바닥에서 출발하는 이유이기도 하다.

## 4. 구단

### 4.1 정체성은 물려받는 것이다

인수로 시작하므로(D1) **이름도 연차도 유니폼도 이미 있다.** 내가 만든 게 아니다.

그래서 *"내 팀으로 만들기 vs 물려받은 것 존중하기"* 라는 축이 생긴다.
바꿀 수는 있지만 **오래된 회원이 반발한다.**

| 항목 | 성격 | 기계적 효과 |
|---|---|---|
| **창단 연차** | 주어짐. 못 바꿈 | 리그 요건, 평판, 창단 멤버 |
| **유니폼** | 바꾸려면 비쌈 | 가입 일시금, 리그 요건, 도트 색상 |
| 팀 이름 | 바꿀 수 있음 | 거의 취향 |
| 엠블럼 | 바꿀 수 있음 | 순수 취향 |

앞의 둘이 기계적으로 중요하고, 뒤의 둘은 애착의 영역이다.

### 4.2 창단 연차 — 돈으로 못 사는 자산

인수 시점에 예컨대 12년차 팀을 물려받으면 **그 12년이 통째로 자산**이다.

- 리그 진입 요건 충족 (D2 — 팀 존속 기간)
- 평판에 기여
- **창단 멤버가 존재함**
- 창단 N주년 이벤트

**신생 팀은 이걸 못 산다.** 분열로 생긴 라이벌 팀(12장)은 전력이 비슷해도 연차에서 밀린다.

> 🔶 **미정:** 시작 연차를 플레이어가 고르게 할지, 고정할지.

### 4.3 창단 멤버 — 정체성의 수호자

이력(2.1)에 가입 시점이 남으므로 자연히 구분된다. 이들의 특징이 겹친다.

| | |
|---|---|
| 영향력 | 자연히 높음 — 오래 있었으니 |
| 친화력 | 관계가 두꺼움 (2.2 나이 곡선) |
| 애착 | 만족도 하락에 저항 |
| **능력** | **나이 들어 떨어짐** |
| 역할 | **팀 이름 · 유니폼을 바꾸면 반발** |

노장 아키타입(2.3)과 정확히 겹친다. **경기엔 못 쓰는데 팀엔 꼭 필요한 사람**이
정체성까지 지키고 있다.

이들이 떠나면 **역사가 끊긴다.** 12년차 팀인데 12년을 아는 사람이 아무도 없게 된다.

### 4.4 유니폼 — 첫 번째 저축 목표

전임 총무가 잠수를 탄 팀이다. 유니폼 관리가 됐을 리 없다.

> 명단 14명 중 제대로 된 유니폼이 있는 사람은 8명.
> 나머지는 색만 비슷한 옷을 입고 나온다.

**유니폼 통일은 회비를 모아서 달성하는 목표다.**

| | |
|---|---|
| 통일하려면 | 부족한 인원수만큼 구매 → **목돈** |
| 안 하면 | 리그 진입 불가(D2), 평판 소폭 하락 |
| 신입이 오면 | 가입 일시금으로 한 벌씩 (9장) |

#### 저축이 모든 지출 결정에 압력을 만든다

지금까지 재정은 수입−지출의 흐름이었는데, **목돈을 모으는 행위**가 추가되면서
모든 지출이 저축과 경쟁하게 된다.

| 저축을 빨리 하려면 | 대가 |
|---|---|
| 회비를 올린다 | 만족도↓, 여력 없는 회원부터 이탈 |
| 경기를 줄인다 | **출전 기회↓** → 자존심 높은 회원 불만 |
| 회식을 줄인다 | 친화력 높은 회원 불만 |

**저축 속도 ↔ 팀 유지가 정면으로 부딪힌다.** 돈을 모으는 동안 사람이 빠져나가면
모아봤자 쓸 사람이 없다.

리그 진입 요건(D2)에 등록비도 목돈이라, 1막은 상당 부분 **저축 게임**의 성격을 띤다.

#### 진행률로 다룬다

이분법이 아니라 부분 달성이 가능하다. *"이번 달은 두 벌"* 이 된다.
목표가 멀어도 진척이 보이므로 초반 동기가 유지된다.

통일이 끝나면 — 리그 요건 하나 충족, 평판 소폭↑, 회원 만족도 소폭↑,
그리고 나중에 **경기 화면에서 다들 같은 옷을 입는다**(시각적 보상, 13장 아트).

유니폼 색은 도트 스프라이트 색 교체로 구현되므로 **거의 공짜로 넣을 수 있다.**

### 4.5 바꾸면 대가가 있다

| 바꾸는 것 | 비용 | 반발 |
|---|---|---|
| 팀 이름 | 없음 | **창단 멤버 만족도 급락** |
| 유니폼 색 | 전원 재구매 (목돈) | 애착 있는 회원 반발 |
| 엠블럼 | 소액 | 소폭 |

> **"우리가 12년 쓴 이름인데."**

플레이어가 자기 색을 내려 할수록 물려받은 사람들과 부딪힌다.
기계적 이득은 없다. 그래도 하고 싶으면 하는 것이고, 그게 이 게임이 주려는 감정에 맞는다.

### 4.6 뉴게임 설정과의 관계 (E60)

3.1에서 "플레이어가 팀 이름과 구 이름을 입력한다"고 했는데 인수 시작과 모순처럼 보인다.

> 뉴게임에서 정하는 것은 **"내가 만드는 팀"이 아니라 "내가 물려받을 팀"의 설정**이다.

자기 동네를 고르고, 그 동네에 있을 법한 팀 이름을 짓고, 유니폼 색을 정한다.
그것이 12년 전부터 있던 것으로 취급된다. **시작한 뒤에는 바꾸는 데 대가가 든다.**

몰입은 살리면서 "물려받았다"는 설정도 깨지지 않는다.

#### 시작 명단 — 고정 캐릭터는 두지 않는다

**시나리오 고정 인물은 없다.** 9명 전부 매번 새로 생성된다(2.7).

다만 **로스터의 모양은 보장한다.** 특정 인물을 고정하는 게 아니라 분포에 제약을 건다.

| 보장 | 이유 |
|---|---|
| 최소 1명 능력 상위 | 잃을 것이 있어야 한다 — 이적 위험의 대상 |
| 최소 1명 성실함 하위 | 규칙 튜토리얼(8.9)의 대상 |
| 나이 분포에 폭 | 위계(2.11)가 작동해야 한다 |
| GK 적성 0~1명 | 병목을 첫 주부터 체감 |

**사람은 매번 다른데 역할은 존재한다.** 재플레이 다양성과 튜토리얼 안정성을 둘 다 얻는다.

### 4.6.1 튜토리얼 — 첫 4주가 겸한다 (E61)

**튜토리얼 화면을 만들지 않는다.** 설명문으로 시스템을 소개하는 대신
**첫 4주에 겪을 상황을 심어둔다.**

7.9가 이미 그 방식을 쓰고 있었다 — 유명무실한 규칙 처리가
*"설명문 없이 규칙 시스템의 3요소와 일관성 개념을 한 번에 겪게 만드는 구조"* 다.
**그것을 네 주로 늘린다.**

| 주 | 심어두는 상황 | 겪게 되는 것 |
|---|---|---|
| **1주** | 유명무실한 규칙 처리 (7.9) | 규칙 3요소 · 제재 · **일관성** |
| **2주** | 인원이 **정확히 1명 부족**하다 | 참석 판정 · 용병 · **경기 취소**(11.7) |
| **3주** | 첫 경기 — **교체 거부 1회 확정** | 전술 · 수용률 · **신뢰**(5.4) |
| **4주** | 회비 미납자 1명이 나온다 | 재정 · 제재 선택 · **예외의 대가** |

#### 심는 것이지 스크립트가 아니다

**시드를 고정해 상황만 배치한다**(1.2). 결과는 안 정한다 —
2주차에 용병을 부를지 취소할지, 3주차에 거부당하고 어떻게 할지는 전부 플레이어 몫이고,
**어느 쪽을 골라도 튜토리얼은 성립한다.**

4.6의 로스터 분포 보장이 여기에 쓰인다 — 성실함 하위 1명이 있어야 1주차가 돌고,
GK 적성 0~1명이라야 2주차의 인원 부족이 실감난다.

#### 5주차부터는 정상 시드

4주가 지나면 심어둔 것이 없다. **난이도 4축**(5.3 · E62)도 첫 4주에는 안 걸린다 —
캐릭터 생성에서 뭘 골랐든 같은 네 상황을 겪고, **그다음부터 갈린다.**

#### 툴팁은 첫 등장에 한 번

화면 요소가 처음 나올 때만 한 줄 뜨고 **닫으면 다시 안 뜬다.**
설정에서 전체를 끌 수 있다.

> **만족도 얼굴에는 툴팁을 달지 않는다.** 5단계의 뜻을 알려주면
> 2.6의 참을성 보정이 "속임수"로 읽히고, **관찰로 알아가는 구조가 첫 주에 무너진다.**
> 이것만은 플레이어가 스스로 알아채야 한다.

### 4.7 평판 — 2축

용도 3개를 하나의 수치가 통제하면 **"강한데 매너 없는 팀"을 표현할 수 없다.**
축을 둘로 나눈다.

| 축 | 뜻 | 올리는 것 |
|---|---|---|
| **실적** | "잘나가는 팀" | 승률, 연승, 규모, 연차, 승격 |
| **인심** | "괜찮은 팀" | 약속 지킴, 용병 대접, 매너, 규칙 일관성 |

#### 기질별로 보는 축이 다르다

2축을 쓰는 진짜 이유.

| 지원자 기질 | 보는 축 |
|---|---|
| 승부욕 높음 | **실적** — 강한 팀에서 뛰고 싶다 |
| 친화력 높음 | **인심** — 분위기 좋은 팀에 가고 싶다 |
| 자존심 높음 | 실적 낮은 팀 — 거기선 주전이 된다 |

**평판이 곧 어떤 사람이 오는지를 결정한다.** 그러면 팀 색깔이 자기강화된다.

> 승부 지향으로 운영 → 실적 평판↑ → 승부욕 높은 회원 유입 → 더 승부 지향

세 축(승리/화목/규모)의 자기강화 루프가 **평판을 통해 완성된다.**
"남은 회원 구성이 곧 팀 색깔"(00-concept)이 어떻게 굳어지는지가 여기서 설명된다.

#### 용도별로 보는 축

| 용도 | 주로 보는 축 |
|---|---|
| 회원 유입 | 둘 다 (기질에 따라) |
| 상대 섭외 | **인심** — 실적이 너무 높으면 오히려 피한다 |
| 용병 모집 | 인심 + 구장 품질 |

#### 깎는 것

| 행동 | 실적 | 인심 |
|---|---|---|
| **당일 경기 취소** | — | **크게↓** |
| 공고 취소 · 불러놓고 벤치 | — | ↓ |
| 거친 플레이 · 시비 | — | ↓ |
| 회원 빼가기 | — | ↓ |
| **방출 통보** | — | ↓ |
| 연패 | ↓ | — |
| 회원 대량 이탈 | ↓ | ↓ |

**천천히 오르고 빨리 떨어져야** 긴장이 생긴다. 한 번의 당일 취소가 몇 달치를 깎아먹는다.

#### 시작값 — 중간

**나쁘지도 좋지도 않은 상태**에서 출발한다.

바닥이면 "복구"가 초반의 전부가 되는데, 중간이면 **방치하면 떨어진다**가 된다.
후자가 더 능동적이다.

설정상으로도 자연스럽다 — 팀은 12년 됐고 회원도 남아 있으니 완전히 망하지 않았다.
전임의 잠수는 최근 일이라 소문이 아직 다 퍼지지 않았다.

#### 표시 방식

숫자보다 서술로. 회원 정보 표시(2.8)와 일관되게.

> 이 동네에서 나쁘진 않은 편. 다만 요즘 얘기가 좀 돈다.

### 4.8 주 구장과 장기 예약

**"홈구장"이라는 별도 개념은 두지 않는다.** 자주 예약해서 자연히 주로 쓰게 되는 구장이
있을 뿐이다. 선언이 아니라 **누적된 사용 이력의 결과**다.

#### 예약 단위 3종

단골 누적(3.6)이 쌓이면 장기 예약이 열린다.

| 단위 | 할인 | 조건 | 리스크 |
|---|---|---|---|
| 매주 | — | 언제나 | 매주 행동 소모, 실패 가능 |
| **월** | **10%** | 단골 누적 | 그 달 활용 못 하면 손실 |
| **년** | **20%** | 더 많은 누적 | 1년치 리스크 |

#### 장기 예약은 팀 상태에 대한 자신감의 표현이다

연 단위로 잡는다는 건 **"1년 내내 이만큼 경기할 수 있다"고 선언하는 것**이다.

- 팀이 안정적이면 → 연 단위로 20% 아낀다
- 불안하면 → 매주 잡아 유연성을 확보한다

**할인을 받으려면 팀 상태를 확신해야 하는데, 이 게임에서 확신할 수 있는 건 없다.**

초반에는 매주 예약할 수밖에 없고, 팀이 자리를 잡아야 장기 예약이 선택지가 된다.
**장기 예약을 걸 수 있게 됐다는 것 자체가 성장의 지표**다.

#### 페널티 — 예약해놓고 못 쓰면

| 상황 | 결과 |
|---|---|
| 매칭 실패 (상대 못 구함) | 구장이 빈다. **돈 날림** |
| 인원 미달 | 경기 취소. 돈 날림 + 만족도↓ |
| 반복되면 | 구장 측 신뢰 하락 → **갱신 거부 · 할인 축소** |
| 회원 눈에는 | *"돈만 나가네"* |

싸게 잡으려다 더 많이 잃는 구조라 **할인이 함정**이 될 수 있다.

#### 대가 — 유연성과 배분

장기 예약은 구장을 고정시킨다.

- **먼 회원이 계속 손해** — 매주 돌려가며 배려할 수 없다 (2.7 배분 딜레마 고착)
- **계절 대응 불가** — 겨울엔 굳이 좋은 구장이 필요 없는데 계약은 돼 있다(D4)
- 주간 행동 하나가 자유로워진다 (E16) ← 이건 이득

#### 시간이 지나면 안 맞게 된다

회원이 바뀌면 최적 위치도 바뀐다. 창단 멤버가 떠나고 신입이 다른 동네에서 들어오면,
몇 년 뒤 주 구장이 엉뚱한 데 있게 된다.

옮기려면 — 잔여 계약 손실 + **단골 누적 리셋**(3.6) + 창단 멤버 반발
(*"우리가 10년 쓴 구장인데"*). 4.5의 "바꾸면 대가가 있다"가 여기에도 적용된다.

#### 평판과 물리는 지점

> 좋은 주 구장 → 용병 모집력↑ + 상대 섭외 유리 → **인심 평판↑**
> 인심 평판↑ → 좋은 구장의 장기 예약을 따내기 쉬움

선순환이 돈다. 반대로 인심 평판이 낮으면 좋은 구장은 자리를 안 준다.

리그 진입 요건(D2)의 "홈 구장 정기 대관"은 **장기 예약을 걸어둔 상태**를 뜻한다.

### 4.9 구단 설정 — 상시 방침과 매주 판단을 나눈다

> **상시 방침은 설정으로 두고, 예외만 매주 판단한다.**

52주 × 몇 년이다. 매주 같은 결정을 손으로 반복하면 세션 시간 설계
(10장 *"평범한 주는 1~3분"*)가 성립하지 않는다.

| 설정 — 한 번 정하면 유지 | 매주 판단 |
|---|---|
| **경기 요일 · 시간대** | 라인업 |
| 회비 금액 · 방식 | 이번 주 경기 수 |
| **회식 주기** | 구장 · 슬롯 예약 (장기 예약이 없으면) |
| 규칙 (8장) | 이벤트 대응 |
| 예산 배분 | 신입 면접 |
| 유니폼 · 이름 · 엠블럼 | 상대 섭외 |

**설정을 바꾸는 것 자체가 하나의 결정**이 되고, 바꿀 때마다 회원 반응이 온다.

#### 경기 요일 · 시간대 — 누가 버티는가를 결정한다

평판(4.7)이 **누가 오는가**를 정한다면, 시간대는 **누가 버티는가**를 정한다.

프로필의 직업과 직결된다(2.7).

| 시간대 | 유리한 회원 | 불리한 회원 |
|---|---|---|
| 일요일 새벽 | 자영업(주말 대목 전에 끝남), 은퇴 | 젊은 층, 늦잠 |
| 일요일 오전 | 대부분 | 자영업 |
| 토요일 저녁 | 직장인 | 가족 있는 회원 |
| 평일 저녁 | 직장인, 학생 | 교대근무, 자영업 |

**기본값은 일요일 새벽**이다. 컨셉의 정체성(새벽 인조잔디)이 거기 있다.
바꿀 수 있지만 바꾸면 어떤 회원은 편해지고 어떤 회원은 못 나온다.

#### 회식 주기

친화력 높은 회원에게는 이것이 본체다.

- 매 경기 후 / 격주 / 월 1회 / 안 함
- 참석 강제성 — 다 오라고 할 것인가
- 비용 부담 — 회비에서 / 그날 각출 (E45)

#### 옵션 — 기본은 꺼져 있다

자동화 항목은 **옵션으로만** 둔다. 기본값은 꺼짐.

| 옵션 | 내용 |
|---|---|
| 용병 자동 호출 | 인원 N명 미만이면 자동으로 공고 |
| 신입 자동 거절 | 특정 조건(거리, 시한부)이면 면접 없이 거절 |

**자동화는 편하지만 이 게임의 결정을 대신해 준다.** 용병 호출 타이밍은
참석 확률에 대한 베팅(6장)이고, 신입 심사는 되돌리기 어려운 결정(00-concept)이다.
둘 다 게임의 핵심이라 기본으로 꺼두고, 반복이 지겨워진 플레이어만 켜게 한다.

### 4.10 장기 — 팀이 내 것이 되는 과정 (E54)

**엔딩도 게임 오버도 없는 게임에서 무엇을 보고 계속하는가.**

| 층 | 주기 | 목표 |
|---|---|---|
| 단기 | 매주 | 일요일에 11명 채우기 |
| 중기 | 시즌 | 리그 진입 · 승격 · 저축 목표 |
| **장기** | 몇 년 | **아래** |

단기와 중기는 이미 있다. 1막은 리그 게이트(D2)가 목표를 대신 정해주므로
**초반에는 방향 상실이 없다.** 문제는 그 이후다.

#### 물려받은 팀이 내 팀이 된다

인수로 시작했다는 것(D1)이 장기 서사의 전제다.

> 12년차 팀을 물려받았다. 명단 14명.
> 5년이 지나니 그때 있던 사람은 3명만 남았다.
> 나머지 20명은 전부 내가 받은 사람들이다.

**새 시스템이 필요 없다.** 창단 멤버 칭호(2.12)와 가입 시점 이력(2.1)이 이미 있다.
4.1 · 4.5의 *"물려받은 것 존중 vs 내 색깔 내기"* 갈등이 **몇 년에 걸쳐 자연히 해소된다.**

##### 명시적 지표로 보여준다

회원마다 **인수 시점 재적 여부**를 태그로 두고, 팀 화면에 비율을 표시한다.

```
물려받은 회원   3 / 14  (21%)
내가 받은 회원  20
```

물려받은 회원이 0이 되는 순간 이벤트가 발생한다.

> 이제 이 팀에 나보다 오래 있은 사람이 없다.

#### 회원의 인생을 끝까지 본다

20대에 들어온 회원이 결혼하고, 아이가 생기고, 40대가 된다.
창단 멤버가 무릎 때문에 명예회원이 된다(7장).

**사람이 들어오고 나가는 것 자체가 장기 콘텐츠**다.

#### 연대기 — 기록이 곧 보상

**엔딩이 없는 게임에서는 아카이브가 보상이다.**

시즌마다 자동으로 기록한다.

```
3년차 (2029)
  성적    12승 8무 14패 · 3부 6위
  들어옴  6명   나감  4명
  기억할 것
    - 창단 멤버 심기국, 무릎으로 명예회원 전환
    - 신입 이규민 첫 골
    - 8월, 인원 미달로 2경기 취소
```

몇 년 쌓이면 **내 팀의 역사**가 된다.
계속할 이유의 실체는 **다음 목표가 아니라 쌓여가는 것**이다.

##### 떠난 뒤에는 숫자를 공개한다

만족도는 진행 중에 **얼굴로만** 보이고, 참을성이 높으면 그마저 한 단계 가려진다(2.6).
**그런데 그 사람이 떠나고 나면 전부 보여준다** — 마지막 6개월의 출전 · 만족도 추이 ·
내가 만난 횟수 · 그동안 표시되던 얼굴까지.

```
배준영 · 2021~2023 · 31경기
  출전     1Q · 0Q · 0Q · 2Q · 0Q · 0Q
  만족도   44 → 38 → 31 → 25 → 19 → 12
  만난 횟수  0회
  표시되던 얼굴  "그저 그럼"   ← 참을성 71
```

**이미 늦었으니 보여줘도 된다. 그게 아프다.**
2.6의 참을성 보정이 **사후에 청구서로 돌아오는 유일한 지점**이고,
연대기가 정서적으로 작동하는 이유다.

#### 그만두는 순간 (E63)

**엔딩을 만들지 않는다.** 강제 종료는 톤에 안 맞는다 —
조기축구단 총무는 클리어하는 게 아니라 **어느 날 그만두는 것**이다.

대신 *"이제 됐다"* 싶은 지점을 **매듭**이라 부르고, 도달할 때마다 표시만 한다.
**그만둘지는 플레이어가 정한다.**

##### 매듭 4종

| 매듭 | 언제 | 성격 |
|---|---|---|
| **물려받은 회원 0명** | 인수 시점 회원이 전부 나감 | **완전히 내 팀이 됐다** |
| **창단 20주년** | 시간이 만든 것 | 아무것도 안 해도 온다 |
| 리그 최상위 도달 | 명확하지만 게임적 | 셋 중 유일하게 **실력의 결과** |
| **내가 명예회원이 될 나이** | 플레이어 50대 후반 (5.3) | 몸이 안 따라준다 |

매듭에 도달하면 이벤트가 뜨고 **계속 / 물려주기** 를 묻는다.
**계속을 골라도 아무 손해가 없다.** 매듭은 목표가 아니라 표지판이다.

##### 물려주기 — 시작이 인수였으니 끝은 인계다

**전임은 잠수를 탔지만 나는 제대로 넘긴다.** 주제가 여기서 닫힌다.

| 방식 | |
|---|---|
| 종료 | 연대기를 마지막으로 보고 끝낸다 |
| **계승** | **후계자를 지정하고 그 사람으로 계속한다** |

##### 계승은 새 시스템이 거의 아니다

구현 비용이 커 보였는데, 뜯어보니 **뉴게임 로직에 명단만 유지하면 된다.**

| 필요한 것 | 이미 있나 |
|---|---|
| 후계자 = 현재 회원 중 한 명 | ✅ 능력 · 기질 · 프로필이 다 있다 |
| 새 플레이어의 신뢰 | ✅ **0부터**(5.4) — 그 사람도 나처럼 시작한다 |
| 물려받은 회원 = 지금 명단 전원 | ✅ 4.10의 태그를 다시 매기면 된다 |
| 팀 평판 · 재정 · 구장 단골 | ✅ 그대로 이어진다 |
| **내가 명단에 남는다** | ✅ **명예회원**(E78)으로 |

마지막 줄이 이 설계의 값이다. **내가 물려받은 회원 중 하나가 된다.**
새 플레이어가 몇 년 뒤 물려받은 회원 비율을 보면, 그 안에 내가 있다.

##### 후계자를 고르는 것이 마지막 결정이다

지금까지 회원을 봐온 방식이 그대로 시험된다 —
**영향력이 높아야 사람이 따르고, 성실해야 회비가 안 새고,
친화력이 있어야 분위기가 산다.** 5.5 직책 위임과 같은 판단인데 규모가 다르다.

> 잘못 고르면 그 팀이 몇 년 안에 무너지는 것을 **구경하게 된다.**
> 명예회원이라 개입할 수 없다. 그게 인계의 진짜 대가다.

## 5. 플레이어

### 5.1 직함은 다 가졌는데 아무것도 못 시킨다

플레이어는 **회장 · 총무 · 감독을 전부 겸한다.** 위에 사람이 없다.

그런데도 권한이 없다. 위에 사람이 있어서가 아니라 **애초에 직함에 권한이 없기 때문**이다.

> 회장이면서도 형님한테 "오늘 빠지세요"라고 못 한다.

동호회에서는 **나이 위계와 인간관계가 직책보다 위**다. 직함은 일하는 사람 표시일 뿐이다.
그래서 E26(나이 위계 · 호칭)이 **실질 권력 시스템**이 된다 — 창단 멤버와 연장자가
진짜 영향력을 갖는다.

주장만 회원에게 임명할 수 있다(E47).

### 5.2 경기 참여 — 뛰되 불평하지 않는다

총무 겸 감독이라도 뛴다. 인원이 모자라면 특히.

**플레이어는 만족도를 갖지 않는다.** 자기가 자기 만족도를 관리하는 건 이상하다.
대신 **체력과 부상은 있다.**

> 플레이어는 불평하지 않지만 몸은 상한다.

인원이 모자라 매주 풀타임 뛰면 다친다. 다치면 한 명이 빠지고, 그게 자기 자신이다.
**자기희생이 기계적 대가를 갖는다.**

관리 활동은 부상 중에도 계속한다. 안 그러면 게임이 멈춘다.

### 5.3 캐릭터 생성 4축 = 난이도

능력 5 · 기질 6 · 포지션 적성 · 프로필 — **데이터 구조는 회원과 동일**하다.
뉴게임에서 직접 만든다. 네 축이 곧 난이도라 **별도 난이도 화면(E62)이 필요 없다.**

#### ① 나이 — 능력 ↔ 발언권

| 나이 | 선수로서 | 신뢰 얻기 |
|---|---|---|
| 30대 초반 | **능력 최상** | **어렵다** — 형님들이 말을 안 듣는다 |
| 40대 | 보통 | 보통 |
| 50대 | 떨어짐 | **쉽다** — 나이가 곧 발언권 |

**몸이 되면 말이 안 먹히고, 말이 먹히면 몸이 안 된다.**

노화는 계속 작동한다. 30대로 시작하면 몇 년 뒤 **능력이 떨어지면서 신뢰가 오르는 곡선**을
직접 겪는다.

#### ② 직업 — 주간 가용 슬롯

한 주는 **7일 × 아침 · 점심 · 저녁 = 21칸**이다(10장). 직업이 그중 어디를 잘라내는지 정한다.

| 직업 | 열리는 시간대 | 특이사항 |
|---|---|---|
| 은퇴 · 무직 | 거의 전부 | 나이가 많다는 뜻 |
| 자영업 | **평일 낮**이 열리고 **주말이 막힘** | 주말이 대목 |
| 프리랜서 | 유연하지만 불규칙 | 수입 불안정 → 회비 부담 |
| 사무직 | 평일 저녁 + 주말 | 야근이 저녁을 랜덤으로 깎음 |
| 교대근무 | **주마다 완전히 바뀜** | **계획을 못 세운다** |

**칸이 많아 보여도 직업이 대부분을 잘라낸다.** 그리고 회원 쪽도 같은 규칙이라
**서로 열린 시간대가 겹쳐야** 만날 수 있다.

교대근무는 **총량이 주마다 달라 계획이 안 선다.** 회원에게 요구하는 것(예측 가능성)을
정작 플레이어가 못 갖는 아이러니가 생긴다.

#### ③ 포지션 적성 — GK는 고를 수 없다

플레이어가 GK를 맡으면 **게임의 만성 문제(2.5 GK 병목)가 사라진다.**
그 긴장을 유지하기 위해 **GK 적성은 선택 불가**로 한다.

#### ④ 팀 경력 — 신뢰의 시작점

| 경력 | 신뢰 시작 | 관계 | 왜 총무를 맡았나 |
|---|---|---|---|
| **창단 멤버** | 높음 | 다 알고 지냄 | 어쩔 수 없이 떠맡음 |
| 중고참 (3~5년) | 중간 | 절반 정도 | 그나마 나은 사람 |
| 신입 (1년 미만) | 거의 0 | 아무도 모름 | 아무도 안 하려 해서 |
| **외부인** | **0** | 없음 | 지인 부탁으로 |

창단 멤버로 시작하면 신뢰는 있는데 **정체성 수호자들과 한편이라 개혁이 어렵다.**
외부인으로 시작하면 아무도 안 믿어주는 대신 **바꿀 때 얽매일 것이 없다.**

> 🔶 **미정:** 4종 전부 넣되, 시작 조건 차이가 큰 만큼 튜토리얼(E61) 설계 때 재검토.

### 5.4 신뢰 (E15)

**팀 평판은 물려받지만 개인 신뢰는 0부터다.**

| | 시작값 | 이유 |
|---|---|---|
| 팀 평판 (4.7) | 중간 | 12년 쌓인 것을 물려받음 |
| **플레이어 신뢰** | **낮음** | 개인은 방금 왔음 (경력에 따라 다름) |

> 팀은 알아도 나는 모른다.

회원들은 팀에는 애착이 있는데 **새 총무는 아직 못 믿는다.** 이것이 초반 압박의 정체다.

#### 신뢰가 하는 일

| 신뢰 낮으면 | |
|---|---|
| 규칙 | 만들어도 무시됨 (8.7) |
| **교체 지시** | **거부당함** — 컨셉의 핵심 장면 |
| 회비 인상 | 반발이 큼 |
| 규칙 제정 | 통과가 어려움 |

#### 만족도와 다르게 움직인다

**만족도는 그 사람에게 일어난 일**로 움직이고,
**신뢰는 내가 한 일이 일관적인가**로 움직인다.

| | 만족도 (2.6) | **신뢰** |
|---|---|---|
| 무엇이 움직이나 | 그 사람에게 일어난 일 | **내가 한 일** |
| 사람마다 | **다르게 움직인다** | **거의 같이 움직인다** |
| 기질의 역할 | **변동폭**을 바꾼다 | **관찰 감도**를 바꾼다 |
| 표시 | 숫자 비공개 · 얼굴 5단계 | **숫자로 보여준다** |

##### 신뢰는 숫자로 보여준다

만족도를 감춘 이유는 *"편해 보이는 사람이 사실 위험하다"* 를 세우기 위해서였다(2.6).
**신뢰에는 그 반전이 필요 없다.** 이건 남의 속마음이 아니라 **내 평판**이고,
뭘 잘못했는지 알아야 고칠 수 있다.

**회원별 목록 + 팀 평균 + 올리는 것 / 깎는 것**을 S-14에 전부 적는다.
목록만 있고 움직이는 방법이 없으면 플레이어가 신뢰를 관리할 수가 없다.

#### 변동값 🔢 *초안 — 구현 중 튜닝*

범위 `0~100`. **시작값 15~40** — 캐릭터 생성 4축(5.3)이 정한다.

##### 올리는 것 — 전부 작다

| 행위 | 변동 | 대상 |
|---|---|---|
| **약속 지키기** *(자기 규칙 준수)* | **`+1` / 주** | 전원 — **누적이 본체** |
| 일관된 집행 | `+2` / 건 | 전원 |
| 경기 성사 | `+1` | 참석자 |
| 경조사 챙김 | `+6` | 당사자 · 전원 `+1` |

##### 깎는 것 — 한 번에 몇 주치가 날아간다

| 행위 | 변동 | 대상 |
|---|---|---|
| 예외 두기 *(봐줌)* | `−4` | 전원 |
| **에이스만 봐줌** | **`−8`** | 전원 — 7.6이 "최악"이라 한 것 |
| 설정 자주 변경 | `−3` | 같은 설정을 **4주 안에** 다시 바꿀 때 |
| 방출 통보 | `−5` | 전원 · **친한 회원 추가 `−5`** |
| 경기 취소 — 인원 미달 | `−10` | 참석 예정자 `−14` |
| 경기 취소 — 구장 미확보 | `−5` | 운에 가깝다 (S-09) |
| **자기 규칙 위반** | **`−15`** | 전원 — **최대치** |

##### 자기 규칙 위반이 가장 크게 깎이는 이유

`+1`짜리를 **열다섯 주** 쌓아야 한 번 어긴 것을 메운다.

남을 벌하는 것보다 **자기가 한 말을 어기는 것**이 더 크게 깎여야
규칙이 회원을 통제하는 도구인 동시에 **플레이어를 통제하는 장치**가 된다.
7.5의 문장이 여기서 숫자가 된다.

> **권한 없는 사람이 권한을 만드는 방법은 자기를 묶는 것이다.**

묶으면 매주 `+1`이 붙고, 어기면 `−15`다.

#### 기질은 감도를 준다

변동폭이 아니라 **누가 그것을 보는가**를 바꾼다.

| 기질 | 효과 |
|---|---|
| 성실함 `70+` | **부정 변동 ×1.5** — 규칙 어기는 것을 제일 크게 본다 |
| 성실함 `30` 미만 | 부정 변동 ×0.5 — 원래 규칙에 관심이 없다 |
| 자존심 `70+` | **본인 관련 건** ×1.5 |
| **영향력 `70+`** | 이 사람의 신뢰 변동이 **주변에 30% 전파** |

**영향력이 만족도만이 아니라 신뢰에도 걸린다.**
7.8의 *"영향력 높은 회원의 동의를 미리 얻는 것이 규칙 제정의 실질적 절차"* 가
여기서 숫자로 나온다 — 그 사람 하나의 신뢰를 올리면 주변이 따라 올라간다.

#### 자연 회복 — 상한 50

아무것도 안 해도 **`+0.5` / 주.** 단 **50에서 멈춘다.**

같이 오래 있으면 익숙해지지만 **익숙함은 신뢰가 아니다.**
50 위로는 한 일이 있어야 올라간다.

#### 수용률로 넘어간다 (E82)

```
수용률 += (신뢰 − 50) × 0.4        신뢰 0 → −20 · 50 → ±0 · 100 → +20
```

**같은 포메이션 같은 숙련도인데 누가 지시했느냐로 20%가 갈린다.**
`4-4-2 · 숙련 62` 조합이 기본 50 + 숙련 18 = 68%인데,
신뢰 30이면 60%, 신뢰 80이면 80%가 된다.

교체 거부율 · 규칙 통과 · 회비 인상 반발도 같은 입력을 쓴다.

> 🔢 **위 값은 전부 초안이다.** 헤드리스 시뮬레이터(13.20)로
> **한 시즌을 돌려보면서 조정한다** — 지금 정확할 이유가 없고,
> 구조가 맞는지만 확인하면 된다.

### 5.5 직책 — 위임은 슬롯을 아끼되 리스크가 있다 (E46)

플레이어가 회장 · 총무 · 감독을 겸하므로(5.1) **총무보 같은 직책은 두지 않는다.**
넘길 수 있는 것은 셋이다.

| 직책 | 대신 해주는 것 | 필요한 자질 |
|---|---|---|
| **주장** | 회원 관리 일부 (10장) | 영향력 · 친화력 |
| **회계** | **회비 징수 · 독촉** (9.2) | 성실함 |
| **장비 담당** | **유니폼 발주 · 사이즈 취합** (9.3) | 성실함 |

> **장비 담당은 원래 "소모품 · 내구재 관리"였다.** 공 · 조끼 · 마커에는 결정이 없어
> **자동 구매로 내렸고**(05-ui.md S-07), 그러면서 이 직책이 할 일을 잃었다.
> 유니폼 발주로 재정의한다 — 사이즈를 취합해 발주하는 것은 실제 조기축구단의 일이다.

**지정과 해임은 [06-screens.md](06-screens.md) S-14에서 한다.**
행동 제약이 시간대인 게임(E16)에서 **위임은 그 제약을 푸는 유일한 장치**다.

#### 회계 위임이 감정적 부담을 넘긴다

9.2의 *"독촉하기 싫다"* 가 여기서 풀린다.

> 내가 나쁜 놈이 안 되고 회계가 한다.

**권한 위임이 슬롯 절약만이 아니라 악역을 넘기는 것**이기도 하다.

#### 리스크

부실한 사람에게 맡기면 회비가 새고 장비가 망가진다. 그리고 **그건 결국 내 책임**이 된다.
성실함이 낮은데 영향력이 높은 회원을 회계로 앉히면 최악이다 —
일은 안 하는데 자르기는 어렵다.

직책을 맡기면 그 회원의 만족도가 오른다(인정받음).
그래서 **달래기 수단으로 쓰고 싶어지는데, 자질을 안 보면 대가를 치른다.**

## 6. 로스터 유입

세 채널이 **정보 ↔ 비용** 축에서 갈린다. 서로 대체재라 상황에 따라 고른다.

| 채널 | 절차 | 사전 정보 | 치르는 비용 | 숨은 리스크 |
|---|---|---|---|---|
| **공개 모집** | 신청서 접수 → 면접 → 결과 | **가장 적음.** 신청서와 본인 진술뿐 | 없음 (평판이 곧 자원) | 뽑고 나서 안 맞는 걸 알게 됨 |
| **지인 소개** | 회원이 소개 → 면접 → 결과 | 중간. 소개자가 알려줌 | 소개자 만족도 | **파벌 · 연쇄 이탈** |
| **영입 권유** | 용병/타팀 회원에게 권유 → 수락 → 결과 | **가장 정확.** 뛰는 걸 봤음 | **타 팀과의 관계 악화** | 옮겨온 사람은 또 옮김 |

정보를 정확히 알수록 비용이 크다.

### 공개 모집 — 평판의 보상 창구

3번 축(규모·유명세)의 실질적 효용이 여기서 나온다.

- 무명 팀 → 한 달에 한 명 올까 말까. 오는 사람도 고를 처지가 아님
- 유명 팀 → 지원자가 줄을 섬. **골라 받을 수 있음**

평판의 보상이 트로피가 아니라 **선택권**이라서 톤에도 맞는다.

#### 공고에는 조건을 건다

**문구를 고르는 게 아니라 조건을 건다.** 실제 조기축구 공고가 그렇다 —
*"수비수 한 분 구합니다"* 는 어느 동네 게시판에나 있다.

| 조건 | 선택지 | 효과 |
|---|---|---|
| **포지션** | 무관 / GK / DF / MF / FW | 좁히면 지원 수 ↓, 해당 POS 비율 ↑ |
| **연령대** | 무관 / 20~30대 / 30~40대 / 40대 이상 | 나이 곡선(2.2)상 능력 분포가 갈린다 |
| **경력** | 무관 / 초보 환영 / 경력자 | 초보는 능력 낮되 성실함·친화력 경향 |
| **성향** | 무관 / 친목 위주 / 진지하게 | **승부욕·자존심 분포가 바뀐다** |
| **회비 명시** | 함 / 안 함 | 명시하면 지원 ↓, 미납 위험 ↓ |

**조건을 많이 걸수록 지원자가 준다.** 이것이 트레이드오프의 전부다.

> 인원이 급하다 → 조건 없이 올린다 → **아무나 온다** → 몇 달 뒤 문제가 된다
> 조건을 건다 → **안 온다** → 인원 미달 → 경기 취소 (11.7)

**공고문은 조건에서 자동 생성한다.** 플레이어는 조건만 고르고,
게임이 조각을 조합해 실제 게시글을 보여준다 — 결과물이 눈에 보여야 조건의 의미가 산다.

```
관악구 대신동FC입니다.
수비수 한 분 모십니다. 30~40대 환영, 초보도 괜찮습니다.
즐겁게 뛰실 분. 회비 월 3만원.
일요일 오전 6시 상평체육공원.
```

**GK 병목(2.5)이 여기서 실감된다.** `포지션: GK`를 걸어도 적성자 비율이 낮아
지원이 거의 안 붙는다.

### 지인 소개 — 관계를 타고 들어오고, 관계를 타고 나간다

- 소개자와 신입은 궁합이 보장됨 (친구니까) — 즉시 이득
- 소개자가 탈퇴하면 신입도 흔들림
- 소개자가 여럿 데려오면 **파벌이 생기고, 덩어리째 빠져나갈 수 있다**

지인 소개로 키우면 빠르고 화목한데 붕괴 위험을 같이 산다.
공개 모집은 서로 남남이라 안 무너지는 대신 궁합이 랜덤이다.

### 면접

플레이어가 **거절할 수 있다.** 이게 입구 통제의 전부다.

- 공개된 정보는 일부뿐이고 **본인 진술은 과장 가능**
- 거절에도 비용이 있다 (소개자 서운함, 평판)
- 한번 받으면 못 내보내므로 **되돌리기 어려운 결정**이다

### 용병 — 모집 공고 방식

인원이 모자랄 때 부르는 임시 인력. 경기 취소를 막는 안전망.

**우리가 고르는 게 아니라 올리고 기다린다.** 사이트에 *"같이 축구하실 분"* 공고를 내고
지원을 받는 방식이라, 통제권이 한 단계 더 빠진다. 이 게임의 주제와 맞다.

```
사이트에 공고 작성 → 지원자가 붙음 → 우리가 고름 → 확정
```

#### 공고에 들어가는 것

| 항목 | 영향 |
|---|---|
| 날짜 · 시간 | |
| **장소 (구장)** | 멀거나 나쁘면 안 온다 |
| 필요 포지션 | GK 구하면 잘 안 붙는다 |
| 참가비 | 받을지 말지 (아래) |
| 인원 | |

#### 타이밍 딜레마 — 정보와 선택지가 반대로 움직인다

**공고를 언제 올리느냐가 전부다.**

| 공고 시점 | 지원자 | 우리 인원 파악 |
|---|---|---|
| 일주일 전 | **많다.** 고를 수 있다 | **모른다.** 몇 명 필요한지 미정 |
| 3~4일 전 | 보통 | 대략 |
| 금 · 토 | **적다.** 급한 사람만 | **정확히 안다** |
| 일요일 아침 | 거의 없다 | 확정 |

**일찍 올리면 좋은 사람을 고를 수 있는데 몇 명 필요한지 모른다.
늦게 올리면 필요 인원은 아는데 사람이 없다.**

이것이 게임의 시그니처 장면(일요일 아침 공개, 10장)과 물린다.
용병 호출이 인원 보충이 아니라 **참석 확률에 대한 베팅**이 된다.

여기서 정보의 가치가 생긴다. 회원의 성실함 · 직업 · 거주지를 잘 알수록
**누가 안 나올지 예측이 정확해진다.** 교대근무 김씨는 이번 주 야간이고,
자영업 박씨는 주말이 대목이고, 강서구 사는 이씨는 겨울에 잘 안 나온다.

**회원을 잘 아는 것이 곧 베팅 정확도다.**

#### 참가비 — 용병이 낸다

용병에게 사례비를 주는 일은 없다. **그냥 축구하고 싶어서 오는 사람들**이고,
**그날 뛰는 값으로 참가비를 낸다.** 구장비 갹출 성격이다.

레버는 **금액**이다.

| 참가비 | 지원자 | 재정 |
|---|---|---|
| 높게 | **적다** | 구장비를 많이 회수 |
| 낮게 | 많다 | 조금 회수 |

구장 속성이 여기에 곱해진다. **좋은 구장이면 비싸도 오고, 맨땅이면 싸도 안 온다.**

##### 회비 방식과의 관계 (9장)

용병 참가비는 회원의 회비 방식에 따라 자연스럽게 형평이 맞는다.

| 회원 회비 방식 | 용병 | 형평성 |
|---|---|---|
| 월 정액 | 참가비만 낸다 | 회원은 이미 월회비를 냈다 |
| 경기당 참가비 | **회원과 같은 금액** | 그날 뛴 사람이 똑같이 낸다 |
| 혼합 | 참가비만 낸다 | |

회원보다 적게 받으면 *"쟤는 왜 싸게 뛰어"* 가 된다. **회비 정책과 따로 놀게 두면 안 된다.**

##### 용병을 재정 수단으로 쓸 수 있나

참가비가 수입이므로 용병이 많을수록 구장비 부담이 준다. 그러나 자기 제한이 걸려 있다.

- 용병이 늘수록 **우리 회원이 벤치에 앉는다** → 만족도 하락
- *"저긴 맨날 용병이더라"* → 평판 하락

돈은 벌리는데 팀이 상한다. 재정만 보고 굴리면 로스터가 무너진다.

#### 구장이 모집력을 결정한다

공고에 장소가 들어가므로 **구장 속성(3.6)이 그대로 작용한다.**

| 우리 구장 | 지원자 |
|---|---|
| 천연잔디 · 샤워실 · 주차장 · 역세권 | 많이 온다 |
| 맨땅 · 시설 없음 · 외곽 | **아무도 안 온다** |

싼 구장을 잡으면 대관료는 아끼는데 **용병이 안 와서 인원 미달이 난다.**
구장 선택의 여덟 번째 연결.

#### 평판이 여기에도 작용한다

**팀 평판(E08) 하나로 통일한다.** 별도 사이트 평판을 두지 않는다.

| 올리는 요인 | 깎는 요인 |
|---|---|
| 매너 좋음 | **공고 취소** — 지원자가 헛걸음한다 |
| 용병도 실제로 뛰게 해줌 | **불러놓고 벤치** |
| 뒤풀이 챙김 | 거칠게 함 |

"불러놓고 벤치"가 특히 아프다. 인원이 넘칠까 봐 부른 용병을 안 쓰면 그 사람은
헛걸음한 것이고, 그게 평판에 남는다. **일찍 올리는 전략의 숨은 비용이다.**

이로써 평판은 **세 가지 공급을 동시에 통제한다.**

| 평판 | 회원 유입 | 상대 섭외 | 용병 모집 |
|---|---|---|---|
| 높음 | 지원자가 줄 섬 | 좋은 팀이 먼저 연락 | 잘 붙는다 |
| 낮음 | 아무도 안 옴 | 경기를 못 잡음 | **아무도 안 옴** |

평판이 떨어지면 회원도 상대도 용병도 동시에 마른다. **죽음의 나선이 여기서 완성된다.**

#### 익숙한 사람

반복 지원자가 생긴다.

- **실력과 성격을 알게 된다** — 처음 오는 사람은 본인 진술뿐(과장 가능)
- 궁합이 조금씩 쌓여 팀워크 페널티가 완화된다
- 급할 때 와준다
- **영입 후보** — 영입 권유의 정보 우위(3.7)가 여기서 나온다

#### 용병 = 무소속 회원

데이터 구조를 그대로 재사용한다.

- 능력 5 · 기질 6 · 포지션 적성 · 프로필 — **회원과 동일**
- 다른 점은 **소속이 없다**는 것과 **궁합이 비어 있다**는 것뿐

궁합이 없으므로 **능력치가 같아도 실제 기여가 낮다.** 별도 페널티 로직 없이
"돈으로 전력을 사는 것"이 자연스럽게 막힌다.

거주지가 있으니 먼 데 사는 용병은 자주 못 오고, 직업이 있으니 교대근무 용병은
예측이 안 된다. 회원에게 적용되는 규칙이 그대로 작동한다.
영입하면 소속이 생길 뿐이라 **전환이 매끄럽다.**

#### 성향별 반응 — 정당성이 크기를 결정한다

| 상황 | 반감 |
|---|---|
| 10명 나왔는데 용병 1명 | **거의 없음** — 안 불렀으면 경기가 취소됐다 |
| 12명 나왔는데 용병 1명 | 중간 — 굳이? |
| 13명 나왔는데 용병 2명 | **큼** — 내 자리를 뺏었다 |
| **용병이 나보다 못하는데 뛴다** | **최악** |

기질별로도 갈린다 — 승부욕 높으면 반긴다(이기니까), 자존심 높으면 싫어한다(내 자리),
친화력 높으면 싫어한다(우리 팀 같지가 않다).

**같은 결과라도 명분이 있으면 받아들여진다.** 규칙 시스템의 "독단 vs 절차"(8장)와
같은 구조다.

#### 급할 때는 인맥

3.7에서 정한 "관계 좋은 팀에서 빌림"은 사이트와 병행한다.

- **사이트** = 주 경로. 공고 올리고 기다림
- **팀에서 빌림** = 급할 때 부탁. 확실하지만 관계를 소모

일요일 아침에 취소가 터지면 사이트는 늦다. 그때 쓰는 것이 인맥이다.

#### 장기 효과 — 근본 문제를 덮는다

- **회원들이 "나 없어도 되네"를 느낀다** → 참석 동기 하락
- 팀 정체성이 희석된다 → 친화력 높은 회원 불만
- 상대팀 눈에도 보인다 → *"저긴 맨날 용병이더라"* → 평판

용병으로 인원 미달을 막을수록 **진짜 원인(만족도 하락)은 그대로 곪는다.**
그리고 곪을수록 용병이 더 필요해진다.

*단기 처방이 장기 병을 키운다* 는 이 게임의 반복 문법. (맨땅 구장 3.6, 겨울 무리 D4와 같은 형태)

## 7. 로스터 이탈

**입구는 통제되고 출구는 통제되지 않는다.** 5가지 경로.

| # | 경로 | 플레이어 책임 | 비용 |
|---|---|---|---|
| 1 | **방출 통보** | 전적으로 있음 | **매우 비쌈.** 남은 회원 만족도 급락, 친한 회원 연쇄 이탈, 평판 하락 |
| 2 | 스스로 탈퇴 | 있음 (만족도 관리 실패) | 만족도 바닥 → 자연 발생 |
| 3 | **단체 탈퇴 (분열)** | 있음 | 파벌이 통째로 나가서 **라이벌 팀 결성** |
| 4 | 규칙 미준수 반복 | **없음 (절차)** | 낮음. 오히려 성실한 회원은 반김 |
| 5 | 자연 이탈 | **없음** | 없음. 이사, 결혼, 육아, 부상, 나이 |

1번과 4번은 결과가 같지만 **정당성이 다르다.** 독단은 감독이 나쁜 놈이 되고,
규칙 위반 누적은 본인이 자초한 일이 된다. 이 차이가 규칙 시스템의 존재 이유다.

5번(플레이어 잘못이 아닌 이탈)이 반드시 있어야 **"만족도 관리가 전부"라는 느낌**을 피한다.

### 여섯 번째 경로 — 명예회원 (상실이 아닌 퇴장)

위 다섯은 전부 **상실**이다. 하나를 더 둔다.

조기축구에서는 실제로 그렇다. 나이가 들어 못 뛰게 돼도 나와서 구경하고
뒤풀이는 같이 한다.

| | 현역 | **명예회원** |
|---|---|---|
| 출전 | 함 | 안 함 |
| 참석 | 경기 | 가끔 나와서 구경 |
| **영향력** | 있음 | **유지** |
| 회비 | 냄 | 안 내거나 소액 |
| **인원 계산** | 포함 | **제외** |

노장 아키타입(2.3)에게 **품위 있는 마무리**를 준다. 능력이 바닥나도 쫓아내지 않고,
본인이 물러나되 팀에 남는다.

전환 조건 — 나이 · 부상 누적 · 본인 의사. **플레이어가 강제할 수 없다**(5.1).
"이제 그만 뛰시죠"는 방출 통보와 다를 게 없다.

영향력이 유지되므로 명예회원은 **여전히 규칙 제정과 여론에 영향을 준다**(8.8).
안 뛰는데 발언권은 있는 사람이 늘어나는 것 자체가 하나의 상황이 된다.

## 8. 규칙 시스템

**감독의 진짜 권한.** 개별 지시는 거부당하지만 미리 세워둔 규칙은 통한다.

### 트레이드오프

| | 엄격한 규칙 | 느슨한 규칙 |
|---|---|---|
| 질서 | 지각 · 무단결석 감소 | 만연 |
| 방출 | **정당하게 가능** | 독단밖에 방법 없음 |
| 진입 | 문턱 높음. 부담스러워 안 옴 | 문턱 낮음. 사람 잘 모임 |
| 이탈 | 못 견디는 사람이 나감 | 성실한 회원이 질려서 나감 |
| 유리한 축 | **승리** | **규모** |

느슨하면 사람은 모이는데 일요일 아침에 안 나온다. 엄격하면 나오는 사람은 확실한데
애초에 사람이 안 온다. **양쪽 다 인원 미달로 가는 길**이라 중간을 찾아야 한다.

### 화목은 엄격함이 아니라 일관성에서 나온다

느슨해도 일관되면 불만이 없고, 엄격해도 예외를 두면 갈등이 터진다.

### 간판 상황: 에이스가 규칙을 어겼을 때

- **규칙대로 처리** → 전력 손실. 승부욕 높은 회원 불만
- **봐준다** → 규칙이 무너짐. 다른 회원들이 "쟤는 되고 나는 안 되냐".
  이후 위반이 늘어남

한 장면이 세 축을 동시에 찌른다. 이벤트 시스템의 간판으로 쓴다.

### 7.1 규칙의 3요소

```
조건 (무엇이 위반인가) → 기준값 (얼마나 엄격한가) → 제재 (어떻게 할 것인가)
```

플레이어가 조정하는 것은 **기준값과 제재**다.

### 7.2 규칙 목록 (8종)

**굵은 값이 시작값**이다 — 전임 회장이 남겨놓고 아무도 안 지키는 상태(7.9).

| 규칙 | 기준값 (약 → 강) | 시작 단 (선택) | 최대 도달 | 통제하는 것 |
|---|---|---|---|---|
| **사전 통보** | 없음 / **1일** / 2일 / 3일 전 | 경고 · **공개** · 벌금 | 쿼터 삭감 | **인원 예측 가능성** |
| **무단결석** | 없음 / 5회 / **3회** / 2회 | 공개 · 벌금 · **잡무** | **제명** | 참석률 |
| **지각** | 없음 / 15분 / **10분** / 5분 | **경고** · 벌금 · 잡무 | 쿼터 삭감 | 시간 |
| **회비 미납** | 없음 / 6개월 / **3개월** / 2개월 | 공개 · **출전 제한** | **제명** | 재정 |
| **출전 배분** | **없음** / 최소 1쿼터 / 2쿼터 | — *(7.5)* | 신뢰 급락 | **라인업 자유** |
| **회식 참석** | **자유** / 권장 / 의무 | 경고 · **잡무** | 공개 | 친목 |
| **당번** | **없음** / 순번제 | **잡무 가중** · 벌금 | 공개 | 잡무 |
| **매너** | 없음 / **퇴장만** / 경고 2회+ | **결장** · 쿼터 삭감 | 직책 박탈 · 제명 | 상대팀 관계 |

**사전 통보 규칙이 특히 중요하다.** 인원 예측 가능성이 곧 용병 호출 베팅(6장)의
정확도다. 통보 의무가 없으면 토요일 밤에도 아무것도 모른다.

##### 규칙마다 반발하는 사람이 다르다

O-7 개정 화면과 S-10 규칙 목록이 **이름 목록으로** 표시하는 근거다(06-screens.md).

| 규칙 | 환영 | 반발 |
|---|---|---|
| 사전 통보 | 성실함 높음 | **여유 없는 직업**(2.7) — 주말 근무·교대 |
| 무단결석 | 성실함 높음 | 참석률 낮은 사람 |
| 지각 | 성실함 높음 | 이동 시간 긴 사람 |
| 회비 미납 | — | **여유 없는 직업** |
| 출전 배분 | 자존심 높음 · 저출전자 | **승부욕 높은 주전** |
| 회식 참석 | 친화력 높음 | 친화력 낮음 · 자녀 있음 |
| 당번 | 성실함 높음 | **전원 소폭** — 좋아하는 사람이 없다 |
| 매너 | — | 승부욕 높음 · 참을성 낮음 |

**영향력 높은 회원이 반대편에 있으면 통과 자체가 어렵다**(7.8).

##### 매너만 사다리 밖에서 시작한다

다른 규칙은 구두 경고부터 밟고 올라가지만 **매너는 첫 위반이 결장**이다.
상대팀 관계(3.7)가 걸려 있어 우리 안에서 끝나는 문제가 아니다 —
경고 한 장이 다음 경기 섭외를 막는다.

##### 회비 미납에는 벌금이 없다

돈이 없어서 못 낸 사람에게 돈을 더 물리면 **회수도 안 되고 그냥 나간다.**
출전 제한으로 가는 이유이고, 그래서 이 규칙만 사다리가 짧다.

### 7.3 제재 7종 — 비용이 어디로 가는가

**같은 위반에 어떤 제재를 붙이느냐가 그 비용을 누가 내는지를 정한다.**
이것이 규칙 설계를 선택으로 만든다.

| 제재 | 재정 | 본인 만족도 | 팀 · 남 |
|---|---|---|---|
| **구두 경고** | — | `−1` | — |
| **단톡방 공개** | — | **자존심 비례** `−2 ~ −8` | 분위기 `−1` · **영향력으로 번진다** |
| **벌금** | **수입 +** | `−3` | — |
| **잡무 부담** | — | `−4` | **당번 해소 +** |
| **쿼터 삭감** | — | `−8` | 전력 − |
| **결장 1경기** | — | `−14` | 전력 −− |
| **제명** | 회비 − | — | 인원 − · 성실한 회원 + · 친한 회원 − |

**직책 박탈**은 주장 · 회계 · 장비 담당(5.5)에게만 붙는 별도 제재다.
자존심 타격이 크고 **그 직책이 공백이 된다** — 21칸이 다시 빡빡해진다.

##### 출전 관련 제재가 무거운 이유

`쿼터 삭감 −8` · `결장 −14`가 벌금의 서너 배인 것은 자의적인 값이 아니다.
**출전 시간이 만족도의 최대 입력값**이라고 2.6이 정했으므로,
출전을 건드리는 제재는 다른 어떤 제재보다 크게 작동해야 앞뒤가 맞는다.

**그리고 팀도 같이 손해를 본다.** 벌금은 팀에 이득이지만 결장은 전력 손실이라,
*"이 사람을 벌하면 이번 주에 우리가 진다"* 는 판단이 매번 생긴다.

##### 단톡방 공개 — 돈이 안 드는데 제일 위험하다

재정 비용 0, 팀 전력 손실 0. **그래서 남용하기 쉽다.**

대신 **자존심에 비례**해서 깎이고, **영향력을 타고 남에게 번진다**(2.3).
자존심 80 · 영향력 70인 사람을 단톡방에서 지적하면
본인이 `−8`이고 주변 서너 명이 같이 내려간다.

##### 잡무 부담 — 벌금 함정을 피하는 유일한 길

벌금과 같은 단인데 **재정에 안 잡힌다.** 7.4의 함정을 피하려면 이쪽이다.
대신 본인이 더 상하고(`−4` vs `−3`) — **돈을 안 받는 대신 감정을 받는 셈**이다.

당번 규칙과 물린다. 잡무를 제재로 쓰면 **원래 당번이 편해진다** —
누군가의 벌이 남의 이득이 되는 유일한 제재다.

### 7.3.1 사다리 — 같은 규칙을 또 어기면 한 단 오른다

```
구두 경고 → 단톡방 공개 → 벌금 / 잡무 → 쿼터 삭감 → 결장 → 제명
```

**플레이어가 정하는 것은 "몇 단에서 시작하는가"** 다.

| 지각 규칙을 | 1차 | 2차 | 3차 | 4차 |
|---|---|---|---|---|
| **경고**에서 시작 | 경고 | 공개 | 벌금 | 쿼터 삭감 |
| **벌금**에서 시작 | 벌금 | 쿼터 삭감 | 결장 | — *(상한)* |

같은 규칙인데 **강하게 걸면 두 번 만에 결장에 닿는다.**
규칙의 "엄격함"이 기준값만이 아니라 **시작 단으로도** 조절된다.

**규칙마다 상한이 다르다**(7.2 표). 지각으로 제명하지는 않는다 —
사다리를 다 올라도 쿼터 삭감에서 멈춘다.

##### 누적은 리셋된다

`없음 / 1년 / 6개월` 중에서 고른다. **이것이 실질 강도를 정한다** —
무단결석 3회 제명이라도 리셋이 6개월이면 사실상 반년에 두 번은 봐주는 규칙이다.

제명이 사다리 끝에 걸려 있는 것이 핵심이다.
**규칙 없이 내보내면 독단이고, 규칙 위반 누적이면 절차다.**

### 7.4 벌금의 함정 (E41)

벌금은 제재인데 **재정에 도움이 된다.** 여기서 함정이 생긴다.

> 지각비로 구장비를 낸다.

그러면 **규칙을 엄격하게 유지할 재정적 유인**이 생기는데, 그것이 분위기를 망친다.
회원들은 *"돈 뜯긴다"* 고 느낀다.

**벌금 수입 비중이 높아질수록 만족도가 깎인다.** 돈이 되는 규칙일수록 위험하다.

#### 임계값

```
벌금 수입 / 총 수입  ≥ 15%   →  전원 만족도 −2 / 월
                    ≥ 25%   →  전원 만족도 −5 / 월 + "돈 뜯긴다" 이벤트
```

**규칙 세 개를 벌금으로 걸면 자연히 이 구간에 들어간다.**
회비 30,000 × 12명 = 360,000에 벌금이 54,000(15%)이면
지각 5,000짜리가 한 달에 열 번쯤 걸린 것이다 — 조기축구에서 어렵지 않은 숫자다.

**빠져나가는 길은 7.3의 잡무 부담**이다. 같은 무게인데 재정에 안 잡힌다.
대가는 그 사람이 더 상하는 것(`−4` vs `−3`)이고,
**돈을 안 받는 대신 감정을 받는다**는 교환이 여기서 성립한다.

##### 스폰서가 이 함정을 키운다

총 수입이 크면 비중이 낮아지므로 스폰서(9.1)를 받으면 벌금을 더 걷어도 안 걸린다.
**그런데 스폰서는 출전 압력을 같이 데려온다** — 함정을 피하려다 다른 함정에 들어간다.

### 7.5 출전 배분 — 4쿼터로 확정

지금까지 "출전 시간"이 추상적이었는데, **쿼터로 세면 구체적이 된다.**

조기축구는 인원이 많으면 경기를 쿼터로 나눠 로테이션한다.
**90분을 4쿼터(22.5분)로 쪼갠다.** 각 쿼터마다 11명이 뛰고 나머지는 쉰다.

##### 2쿼터가 아니라 4쿼터인 이유

| | 2쿼터 | **4쿼터** |
|---|---|---|
| 경기당 슬롯 | 22 | **44** |
| 회원 20명일 때 인당 평균 | 1.1 | **2.2** |
| 만족도 해상도 | **뛰었나 / 안 뛰었나** — 사실상 이진값 | 0~4의 5단계 |

2쿼터면 20명 중 절반이 아예 못 뛰고,
**"출전 배분을 고르게"라는 지시(11.5) 자체가 성립하지 않는다.**

4쿼터면 인당 평균이 2.2라 GDD가 이 시스템의 출발점으로 든 대사가
정확히 평균선에 놓인다 — *"나도 두 쿼터는 뛰고 싶은데."*

> 화면도 이미 4쿼터를 전제로 그려져 있다. S-02 · S-04의 출전 열
> `최근 4주 16Q` 는 **4경기 × 4쿼터 개근**을 뜻한다.

#### 회원마다 기대 쿼터가 있다

> *"나도 두 쿼터는 뛰고 싶은데."*

이것을 **규칙으로 보장할지, 개별 요구로 그때그때 판단할지**가 선택지다.

| 방식 | 내용 | 대가 |
|---|---|---|
| 규칙 없음 | 매번 플레이어가 판단 | 자유롭지만 **매주 불만 처리** |
| 최소 보장 | "전원 최소 N쿼터" | 예측 가능하지만 **라인업 자유 상실** |
| 성실도 연동 | 많이 나온 사람에게 우선권 | 성실함에 보상. 실력과 무관해짐 |

기대 쿼터 수는 기질과 이력이 정한다 — **자존심**이 높으면 더 원하고,
개근에 가까우면 더 원하고, 연차가 오래면 더 원한다.

#### 기대 쿼터 산출

```
기대 = 2  (기본)
  +1  자존심 70+            −1  자존심 30 미만
  +1  최근 8주 출석률 80%+   −1  최근 8주 출석률 40% 미만
  +1  재적 3년+              −1  체력 40 미만
                                              clamp 1 ~ 4
```

##### 실력은 들어가지 않는다

의도적이다. **기대가 실력에 비례하면 갈등이 사라진다** —
잘하는 사람이 많이 뛰고 못하는 사람이 적게 뛰는 것에 아무도 불만이 없어진다.

기대는 **"내가 이 팀에 얼마나 걸었나"** 로 만들어진다.
매주 나오고, 오래 있었고, 자존심이 있으면 기대한다. 잘하는 것과는 상관없다.
**그래서 못하는 고참이 가장 어려운 문제**가 된다.

체력만 예외로 −1을 준다. 본인도 4쿼터는 무리라는 것을 안다.

#### 만족도 계산

```
Δ만족도 = (실제 쿼터 − 기대 쿼터) × 3 × 자존심계수
자존심계수 = 0.5 + 자존심 / 100        (0.5 ~ 1.5)
```

경기마다 적용한다. 기대 4인데 0쿼터면 `−4 × 3 × 1.5 = −18`,
두 경기 연속이면 **좋음(60~79)에서 안 좋음(20~39)까지 떨어진다.**

> 검산 — S-02의 곽진수는 3주 연속 벤치에 최근 4주 3쿼터고
> 화면에 **안 좋음**으로 표시된다. 위 식으로 그 자리에 온다.

**만족도는 실제 출전 쿼터 − 기대 쿼터로 계산된다**(2.6). 추상적이던 값이 셀 수 있게 됐다.

#### 자기가 만든 규칙에 자기가 묶인다

"최소 보장"을 규칙으로 걸면 급한 경기에서 어기고 싶어진다.
어기면 **신뢰 급락**이다.

> **권한 없는 사람이 권한을 만드는 방법은 자기를 묶는 것이다.**

규칙은 회원을 통제하는 도구인 동시에 플레이어를 통제한다.
"감독의 진짜 힘은 규칙 제정"(00-concept)이 여기서 대가를 드러낸다.

### 7.6 일관성을 추적한다

| 상황 | 결과 |
|---|---|
| 규칙대로 처리 | 신뢰↑, 성실한 회원 만족↑ |
| 봐줌 (1회) | 해당 회원 만족↑, 나머지 소폭↓ |
| 봐줌이 반복 | **규칙이 무의미해짐.** 위반 증가 |
| **에이스만 봐줌** | **최악** — 편중이 드러난다 |

봐준 횟수보다 **누구를 봐줬는지**가 더 중요하다.

### 7.7 신뢰가 없으면 규칙도 안 통한다 (E15)

| 신뢰 | 규칙 |
|---|---|
| 낮음 | 만들어도 무시된다. 제재가 안 먹힌다 |
| 높음 | 실제로 작동한다 |

그리고 **일관된 집행이 신뢰를 올린다.** 규칙과 신뢰가 서로를 강화한다.

### 7.8 규칙 제정에는 반발이 따른다

동호회라 일방적으로 정할 수 없다.

| 회원 | 반응 |
|---|---|
| 성실함 높음 | **환영** — 나만 지키는 게 억울했다 |
| 성실함 낮음 | 반발 |
| **영향력 높음** | **이 사람이 반대하면 통과가 어렵다** |
| 자존심 높음 | 출전 배분 규칙에 민감 |

**영향력 높은 회원의 동의를 미리 얻는 것**이 규칙 제정의 실질적 절차가 된다.
이것도 "권한 없는 사람"이 일하는 방식이다.

### 7.9 시작 상태 — 유명무실한 규칙들

인수 시작이라 전임이 만든 규칙이 남아 있다. **다만 아무도 안 지킨다.**

> 회칙에는 "무단결석 3회 제명"이 적혀 있는데, 최근 1년간 제명된 사람은 없다.
> 다들 그런 규칙이 있는지도 잊었다.

**이 처리가 튜토리얼을 겸한다.** 시작 시 선택지를 준다.

| 선택 | 결과 |
|---|---|
| **되살린다** | 위반자가 무더기로 나온다. 한꺼번에 제명하면 팀이 반토막 |
| **없앤다** | 정리는 되는데 통제 수단이 사라진다 |
| **완화해서 다시 만든다** | 현실적인데 *"물타기"* 로 보일 수 있다 |

**첫 번째 규칙 결정이 곧 첫 번째 정치다.** 신뢰가 중간에서 시작하므로(4.7)
무리한 집행은 바로 역풍을 맞는다.

설명문 없이 규칙 시스템의 3요소(조건 · 기준값 · 제재)와 일관성 개념을
한 번에 겪게 만드는 구조다.

## 9. 재정

### 9.0 기준 금액

**모든 수치가 여기에 붙는다.** 벌금은 회비의 분수로, 예산은 대관료의 배수로 잡는다.

| 항목 | 기준값 | 비고 |
|---|---|---|
| **월 회비** | **30,000** | 기본값. 플레이어가 조정(O-7) |
| 대관료 | 45,000 ~ 60,000 | 2시간 · 구장 등급별(3.6) |
| **용병 참가비** | **10,000** | **수입** — 구장비 갹출(6장) |
| 회식 | 인당 15,000 ~ 20,000 | |
| 유니폼 | 인당 30,000 ~ 40,000 | 가입 일시금 · 적립 목표 |
| **벌금 단위** | **5,000 / 10,000 / 20,000** | 회비의 ⅙ · ⅓ · ⅔ |

##### 회비 하나로 한 경기가 안 돈다

12명 × 30,000 = 360,000. 월 4경기면 대관료만 180,000 ~ 240,000이고,
소모품과 회식을 얹으면 **적자에 가깝다.**

이것이 의도한 출발점이다 — **용병 참가비와 스폰서가 그 틈을 메우고**,
둘 다 대가가 붙어 있다. 용병은 우리 팀으로 이긴 게 맞나는 질문을 만들고(S-11),
스폰서는 출전 압력을 데려온다(9.1).

### 수입 · 비용 구조

**수입**

| 종류 | 무엇에 비례하나 |
|---|---|
| 회비 | 회원 수 (월 정액) 또는 출전 수 (경기당 참가비) |
| **용병 참가비** | **부른 용병 수** — 구장비 갹출 성격 (6장) |
| 스폰서 · 후원 | E42 미설계 |
| 벌금 (지각비 등) | E41 미설계 |

**비용**

| 종류 | 예시 | 무엇에 비례하나 |
|---|---|---|
| 경기당 비용 | 구장 대관료, 상대팀 섭외 | **경기 수** |
| 인당 비용 | 회식, 소모품, 물품 | **회원 수** |
| 가입 일시금 | 유니폼 | 신입 받을 때만 |

> 용병비는 **지출이 아니라 수입**이다. 용병에게 사례비를 주지 않고,
> 용병이 그날 뛰는 값으로 참가비를 낸다(6장).

아래 식은 용병을 뺀 정상 상태 기준이다. 용병 참가비는 경기당비용을 상쇄하는
방향으로 작용해 실효 경기당비용을 낮춘다.

정상 상태에서:

```
경기 수      = 회원 수 × (회비 − 인당비용) / 경기당비용
1인당 출전량 = 슬롯 × (회비 − 인당비용) / 경기당비용     ← 회원 수는 상쇄됨
```

**회원 한 명의 재정 기여는 회비 전액이 아니라 순마진(회비 − 인당비용)이다.**
이 값이 0에 가까우면 사람을 모아도 경기를 못 늘리고, **음수면 회원이 늘수록 가난해진다.**

### 회비가 진짜 레버다

- **높이면** → 경기 많이 잡음 → 골고루 뛴다. 대신 가입 문턱 ↑, 기존 회원 만족도 ↓
- **낮추면** → 사람 잘 모임 → 규모 ↑. 대신 경기를 못 잡아 뛸 기회가 없음

**"사람은 많은데 경기가 없는 팀"과 "경기는 많은데 사람이 적은 팀"** 사이의 조절.
양극단 다 망하는 방향이라 정답이 하나로 굳지 않는다.

### 회비 방식 (플레이어 선택)

| 방식 | 재정 | 부작용 | 유리한 축 |
|---|---|---|---|
| 월 정액 | 안정적. 유령 회원도 납부 | 안 나오는 사람이 "돈만 내고 못 뛴다" → 이탈 | 화목 (경기 수 확보) |
| 경기당 참가비 | 참석률에 직결. 불안정 | 인원 적은 날 적자. 경기 늘리기 어려움 | 규모 (문턱 낮음) |
| 혼합 | 절충 | 계산이 복잡해 회원이 체감 못 함 | — |

### 9.1 스폰서 — 돈을 받으면 권한이 더 줄어든다 (E42)

**자영업 회원이 후원한다.** 프로필(2.7)과 직결된다.

| 형태 | 예 |
|---|---|
| 현금 | 구장비 보조 |
| 물품 | 유니폼 · 공 · 조끼 |
| 장소 | 뒤풀이를 자기 가게에서 |

**유니폼에 가게 이름이 들어간다.** 조기축구 고증이고, 4.4의 유니폼 저축 목표를 앞당긴다.

여기서 대가가 나온다.

> **"김사장님이 유니폼 값 대주셨는데, 그 형을 벤치에 앉힐 수 있나?"**

**후원자는 출전 압력이 된다.** 돈을 받으면 눈치를 더 봐야 한다 —
코어 판타지("권한 없는 사람")를 강화하는 방향이라 잘 맞는다.

그리고 **후원자가 나가면 재정에 구멍**이 난다.
그 사람 만족도 관리가 곧 재정 관리가 된다.

### 9.2 회비 미납 (E43)

규칙(8.2)에 *"미납 N개월 → 제명"* 이 있는데, 그 **전 단계**가 비어 있었다.

| 대응 | 대가 |
|---|---|
| 독촉한다 | **슬롯 소모 + 그 사람 만족도↓** |
| 안 한다 | 재정이 새고, **다른 회원이 "왜 쟤는 안 내?"** |

**형평성 불만이 미납자 본인보다 더 큰 문제**가 된다.
미납 확률은 직업(여력)이 정한다 — 학생 · 취준생이 자주 걸린다.

13.11의 심화 뿌리 *"회비 부담"* 이 여기서 굴러간다.
독촉은 **회계에게 넘길 수 있다**(5.5).

### 9.3 장비와 소모품 (E44)

**소모품과 내구재를 나눈다.** 지출의 성격이 다르다.

#### 소모품 — 매주 나간다

| 품목 | 없으면 |
|---|---|
| 생수 · 이온음료 | 여름에 치명적. 만족도↓ |
| 얼음 | 여름 필수 |
| 파스 · 밴드 · 콜드스프레이 | 가벼운 부상이 악화 |
| 테이핑 | 노장에게 중요 |

**인당 비용**(위 구조)에 들어간다. 회원이 늘면 비례해서 는다.

#### 내구재 — 노후화된다

| 품목 | 없으면 |
|---|---|
| **조끼** | 팀 구분이 안 됨 → 경기 질↓ |
| 공 | 남의 것을 빌린다 (창피) |
| **구급함** | 부상이 악화됨 |
| 아이스박스 | 여름에 힘들다 |
| 펌프 | 공 바람이 빠진 채로 |
| 라바콘 · 마커 | 구장에 없으면 |
| 천막 · 우산 | 비 오는 날 |

**안 사도 당장은 티가 안 나다가 어느 순간 문제가 된다.**
훈련(2.10)과 같은 패턴 — *장기 투자는 눈에 안 보인다.*

관리는 당번제(8.2)로 넘기거나 **장비 담당**을 임명한다(5.5).

### 9.4 회식 — 갹출 방식이 반발하는 쪽을 뒤집는다 (E45)

**주기는 설정이고**(4.9 — 매 경기 후 / 격주 / 월 1회 / 안 함)
**갹출 방식이 미정이었다.** 인당 `15,000 ~ 20,000` 이므로 12명이면 한 번에 약 `200,000` 이다.

| 방식 | 누가 내나 | 반발하는 쪽 |
|---|---|---|
| **회비에서** | 팀 계좌 전액 | **안 오는 사람** — 내 회비로 남들 밥값을 낸다 |
| **그날 각출** | 온 사람이 나눠서 | **자주 오는 사람** — 친화력 높은 사람이 매번 낸다 |
| 반반 | 절반씩 | 반발이 작은 대신 **재정도 절반 샌다** |

#### 회비 징수 방식과 같은 모양이다

O-7에서 회비를 **월 정액 ↔ 경기당 갹출**로 바꾸면 반발하는 쪽이 정반대로 뒤집힌다(7.2).
**회식 갹출도 정확히 같은 구조**다 — 그래서 **같은 화면에서 바꾼다.**

```
회비   월 정액 ↔ 경기당    →  자주 나오는 사람 ↔ 가끔 나오는 사람
회식   회비에서 ↔ 각출     →  안 오는 사람     ↔ 자주 오는 사람
```

**공통 원리** — 공동 부담으로 돌리면 **안 쓰는 사람이 화내고**,
사용자 부담으로 돌리면 **많이 쓰는 사람이 화낸다.** 중립이 없다.

#### 주기 × 방식이 곱해진다

| | 회비에서 | 그날 각출 |
|---|---|---|
| **매 경기 후** | **재정 파탄** — 월 4회 × 200,000 | **참석률 하락** — 매주 2만원이 부담된다 |
| 월 1회 | 감당 가능 | 무난 |
| 안 함 | 재정 여유 · **궁합이 안 오른다** | — |

**2.9의 "로테이션 팀은 회식으로 메울 수 있다"에 가격표가 붙는다.**
고르게 뛰게 하려면 회식을 자주 해야 하고, 자주 하면 **재정이 죽거나 사람이 안 온다.**

> **회식 참석을 "의무"로 걸면**(7.2 규칙) 참석률 문제는 풀리는데
> 친화력 낮은 회원과 자녀 있는 회원이 반발한다. **세 번째 뒤집기**다.

#### 기본값

**월 1회 · 반반.** 인수 시점에 전임이 그렇게 해오고 있었다 —
아무도 특별히 좋아하지 않지만 아무도 크게 화내지 않는 상태다.

## 10. 주간 루프

게임의 시간 단위는 **1주일**. 일요일 경기가 기준점.

```
주중 (관리)  →  토요일 밤 (참석 확정)  →  일요일 아침 (경기)  →  결과 반영
```

### 주중 단계에서 하는 일

전부 **하나의 축으로 수렴**한다: *"일요일에 몇 명이 나오는가"*

| 행동 | 일요일에 미치는 영향 |
|---|---|
| 회원 모집 / 면접 | 머릿수 증가. 단 **정보가 불완전** |
| 회원 관리 (연락, 달래기) | 만족도 조정 |
| 회비 금액 · 방식 조정 | 재정 ↔ 만족도 |
| 예산 배분 (경기 vs 회식) | 성향별로 반대 방향 |
| **경기 수 · 종류 결정** | 출전 기회 총량과 승리의 무게 |
| 소모임 / 회식 | 만족도 ↑, 궁합 ↑, **다음날 컨디션 ↓** |
| 경조사 참석 | 해당 회원 만족도 크게 ↑ |
| 구장 예약 | 시간 · 위치가 참석률에 영향 |
| 상대팀 섭외 | 난이도 선택. 너무 센 팀 = 사기 하락 |
| 규칙 제정 · 적용 | 질서 ↔ 문턱 |

**시스템 10개가 아니라, 하나의 시스템에 입력 10개다.** 이 원칙을 지켜야 만들 수 있는
크기가 된다.

### 행동 제약 — 개수가 아니라 일정이다 (E16)

**행동 개수 제한은 두지 않는다.** 대신 **시간대 × 상대의 가용성**이 실질 제약이 된다.

#### 한 주는 7일 × 3시간대 = 21칸

```
        아침(06~12)   점심(12~18)   저녁(18~22)
  월        □             □             □
  화        □             □             □
  수        □             □             □
  목        □             □             □
  금        □             □             □
  토        □             □             □
  일        □             □             □
```

구장 시간대(3.6의 2시간 슬롯 8개)가 이 위에 얹힌다 — 아침 3슬롯, 점심 3슬롯, 저녁 2슬롯.

**경기는 아무 칸에나 잡힐 수 있다.** 일요일 아침 고정이 아니다.
4.9에서 정한 요일·시간대는 **기본값**이고, 개별 경기는 섭외 협의로 달라진다.

| 경기 시간대 | 성격 |
|---|---|
| 주말 아침 | 기본. 조기축구의 정체성 |
| 주말 낮 | 덥고 비싸다. 대신 참석률 높음 |
| **평일 저녁** | 조명 있는 구장 필요. 직장인 유리 |
| 평일 아침 | 거의 불가 |

> 이번 주는 상대가 평일 저녁밖에 안 된다는데, 우리 형님들은 그 시간에 못 나온다.

**섭외가 곧 시간대 협상**이 된다(3.7).

#### 왜 포인트제가 아닌가

포인트 예산은 **나 혼자만의 문제**다. 그런데 실제로는 회원을 만나려면 **그 회원도
시간이 돼야 한다.**

> 달래야 할 형님이 있는데 이번 주엔 시간이 안 맞는다.

이것이 조기축구단 총무의 진짜 고충이고, **이미 있는 데이터(회원 직업 프로필, 2.7)로
공짜로 굴러간다.** 포인트제로는 나올 수 없는 상황이다.

#### 양쪽 모두 직업에 묶인다

플레이어의 가용 칸은 5.3 참조. 회원 쪽도 같은 원리로 작동한다.

| 회원 직업 | 열리는 시간대 |
|---|---|
| 사무직 | 평일 저녁 (야근 주엔 어려움) + 주말 |
| 자영업 | **평일 낮.** 주말은 대목이라 막힘 |
| 교대근무 | **주마다 완전히 다름** |
| 학생 | 거의 전부 |
| 은퇴 | 거의 전부 |

**같은 칸이 열려야 만난다.** 사무직 플레이어와 자영업 회원은 평일 저녁이 안 맞아
좀처럼 못 만난다. "이번 주엔 김씨를 못 만난다"가 생기고, 쌓이면 방치가 된다.

교대근무 회원이 **관리하기 제일 어려운 사람인데 정작 참석도 제일 불안정하다.**
이중고가 자연스럽게 생긴다.

#### 무게 차이는 슬롯 소모 여부로

| 행동 | 슬롯 | 효과 | 제약 |
|---|---|---|---|
| **단톡방 공지** | 0 | 낮음 | 없음 |
| **개별 카톡** | 0 | 낮음 | **반복하면 효과 감소** |
| 전화 | 0~1 | 중간 | 상대가 받아야 |
| **만나서 한잔** | 1 | **높음** | **시간이 겹쳐야** |
| 경조사 참석 | 1 | **매우 높음** | 날짜 고정 |
| 구장 · 슬롯 예약 | 1 | — | — |
| 상대 섭외 | 1 | — | — |
| 신입 면접 | 1 | — | 지원자 시간도 맞아야 |

카톡이 공짜지만 성의가 없고, 만나면 확실한데 시간이 든다 — 상식적이라 설명이 필요 없다.
카톡 무제한이 악용되지 않도록 **반복 시 효과를 감소**시킨다. *"맨날 카톡만 보내네."*

#### 규모의 제약이 여기서 실현된다

명단이 30명이 돼도 **한 주는 여전히 21칸**이고, 그중 직업이 열어주는 건 몇 칸뿐이다.
만날 수 있는 사람은 3~5명이고 나머지는 단톡방으로만 관리된다.

그리고 방치되는 건 대개 **조용한 사람**(참을성 높음, 2.3)이다.
소리 내는 사람부터 만나게 되니까.

**D6의 "규모의 숨은 비용"이 여기서 기계적으로 구현된다.**

#### 주장 임명 (E47)

슬롯을 늘려주는 게 아니라 **주장이 일부 회원을 대신 만나준다.**

> "형님은 제가 얘기해 볼게요."

권한 위임이 숫자 보너스가 아니라 실제 행동으로 표현된다.

### 단톡방 (E56)

**메인 화면이 아니라 채널 하나다.** 진행 방식 중 하나로 존재한다.

**자유 대화는 구현하지 않는다.** 고정 메시지를 보내고 **반응을 관찰**한다.
구현 비용은 1/10인데 얻는 것이 더 많다.

#### 메시지 4종

| 종류 | 예시 | 응답 |
|---|---|---|
| **수요조사** | "이번 주 일요일 6시 ○○구장, 되시는 분?" | 참석 / 불참 / 미정 / **무응답** |
| **공지** | "이번 달 회비 안내" | 없음. **읽음만** |
| **여론조사** | "회비 올리는 거 어떻게 생각하세요?" | 찬성 / 반대 / 상관없음 |
| 친목 | 지난 경기 사진, 잡담 | 반응 |

#### 여론조사는 권한 없는 사람의 도구다

**설정을 바꾸기 전에 물어볼 수 있다.** 회비 인상, 시간대 변경, 규칙 제정 —
전부 반발이 따르는 것들인데(4.9, 8.8) 미리 여론을 확인하고 결정할 수 있다.

> 명령이 아니라 여론 확인.

**단, 물어봐 놓고 반대를 무릅쓰고 강행하면 신뢰가 더 크게 깎인다.**
묻는 것 자체가 약속이 된다. 안 물어보고 그냥 하는 것보다 나쁠 수 있다.

#### 읽음 상태가 정보다

| 반응 | 읽히는 것 |
|---|---|
| 바로 답함 | 적극적 |
| 늦게 답함 | 미지근 |
| **읽었는데 답 없음 (읽씹)** | **명확한 회피** |
| 안 읽음 | 바쁘거나 관심 없음 |

##### 읽씹이 조용한 사람의 유일한 신호다

기질에 참을성을 넣으면서 이런 구조를 만들었다(2.3).

> 참을성 높음 → 조용히 삭인다 → **어느 날 그냥 사라진다**

그런데 **조용한 사람의 불만을 알아챌 방법이 없었다.** 말을 안 하니까.
2.3에 "플레이어가 먼저 살펴야 한다"고 적었지만 살펴볼 수단이 없었다.

**읽씹이 그 수단이다.** 말로는 아무 불만도 표현하지 않는 사람이 참석 조사를 읽고
아무것도 안 누른다. **가기 싫은데 말은 못 하겠는 상태**가 화면에 드러난다.

##### 조용해진 사람이 이탈 예고가 된다

> 3개월 전엔 항상 제일 먼저 "참석"을 눌렀는데, 요즘은 읽고 아무것도 안 누른다.

컨셉 톤 가이드라인의 **"그냥 시들해짐, 연락이 뜸해짐"**이 그대로 구현된다.
비극이 아니라 아쉬움으로.

#### 응답과 실제는 다르다

"참석" 12명이 12명이 아니다. 응답 신뢰도가 사람마다 다르다.

| 응답 | 실제 참석 확률 |
|---|---|
| 참석 | 높음 — 단, **성실함에 따라 다름** |
| 미정 | 중간 |
| 무응답 | 낮음 |
| 불참 | 거의 0 |

**누구의 "참석"을 믿을 수 있는지**를 아는 것이 실력이 된다.
그리고 이것이 용병 호출 베팅(6장)의 입력이 된다.

#### 단톡방은 스캐너, 개별 만남은 정밀 진단

정보 획득에 층이 생긴다.

| | 대상 | 슬롯 | 얻는 것 |
|---|---|---|---|
| **단톡방** | 전체 | **0** | **얕고 넓은 신호** — 읽씹, 응답 패턴 |
| **개별 만남** | 1명 | **1** | **깊은 정보** — 진짜 이유 |

> 단톡방에서 이상 신호를 발견하고 → 슬롯을 써서 만나러 간다.

**개별 연락은 메시지 형식이 아니라 이벤트로 진행한다.** 만나서 얘기하고 결과를 본다.
단톡방처럼 버튼을 누르는 게 아니라 상황과 선택지가 있는 장면이다.

#### 정보 공개 범위가 여기서 풀린다 (E58)

2.8에서 *"관찰로 드러나는 방식이 유력한데 UI 비용이 든다"* 고 미뤄뒀다.

**단톡방이 그 UI다.** 만족도를 숫자로 보여주지 않고 단톡방 반응으로 추론하게 한다.
별도 관찰 시스템을 만들 필요가 없다.

> 🔶 **미정:** 반응 추이를 어디까지 보여줄 것인가.
> 회원별 최근 N주 응답 이력을 표로 제공하는 정도가 유력하다 —
> **데이터는 주되 해석은 플레이어 몫**으로. "최근 조용해진 회원 3명" 같은 요약 알림은
> 게임이 대신 찾아주는 것이라 관찰의 재미를 죽인다. 옵션(E69)으로만 검토.

### 경기 종류

| 종류 | 교체 | 승리의 무게 | 유리한 축 |
|---|---|---|---|
| 친선경기 | 자유롭게 (무제한에 가까움) | 낮음 | **화목** |
| 일반 리그전 | 제한적 | 중간 | 절충 |
| 대회 / 토너먼트 | 엄격 | 높음 | **승리** |

"이번 달은 친선 위주로 돌리자"는 시스템 선언이 아니라 **그냥 운영 결정**이다.
그런데 결과적으로 팀 성격이 그쪽으로 굳는다. 목표 선택 화면 없이 방향이 잡힌다.

### 경기 수의 상한

돈만이 상한이 아니다. 실제 제약:

1. **회원의 여력** — 주말 아침에 몇 번까지 나올 수 있나. *가장 강한 상한으로 추정*
2. 구장 예약 — 새벽 인조잔디는 자리 자체가 경쟁
3. 상대팀 섭외 — 혼자 못 하는 것
4. 인원 미달 위험이 경기마다 발생 — 경기를 늘리면 미달 경기도 비례해 늘어남

> **취재 확인 항목:** 실제 조기축구단은 주에 몇 번 모이는가. 팀마다 다른가,
> 사실상 주 1회 고정인가. 여기 답에 따라 "경기 수 조절"이 핵심 레버가 될지
> 거의 못 건드리는 상수가 될지 갈린다.

### 참석 확정

참석은 **확정이 아니라 확률**이다. 그리고 결과는 **일요일 아침에 공개된다.**

토요일에 12명이 "참석"이라 찍어도 아침에 취소 연락이 온다.
**이 순간이 게임의 시그니처 장면이다.**

### 세션 시간 설계

**고정 15분이 아니라 가변이어야 한다.**

| 주 | 실제 소요 | 내용 |
|---|---|---|
| 평범한 주 | 1~3분 | 참석 확인하고 경기 스킵 |
| 사건이 있는 주 | 15~20분 | 인원 미달 위기, 회원 갈등, 라이벌전, 경조사 |

평균 5분, 체감 밀도 15분. **경기 배속/스킵은 필수 기능이다.**

## 11. 경기

> **⚠️ 방침 변경.** 이 장은 원래 "연출형 — 정밀 시뮬레이션을 만들지 않는다"였다.
> **매치 엔진을 실제로 만드는 것으로 바꾼다.** `02-scope.md` 의 스코프 방어선
> "정밀 물리 경기 시뮬레이션: 안 함" 도 함께 폐기했다.
>
> 이 결정은 **단일 항목으로 이 프로젝트에서 가장 큰 작업**을 추가한다.

### 11.1 매치 엔진과 매치 뷰어를 둘 다 만든다

둘은 다른 물건이다. 섞어서 생각하면 비용 추산이 틀어진다.

| | 하는 일 | 산출물 |
|---|---|---|
| **매치 엔진** | 결과를 **결정**한다 | 틱 단위 상태 기록 |
| **매치 뷰어** | 결과를 **재생**한다 | 화면 |

**엔진이 뷰어를 모르고, 뷰어가 엔진을 모른다.** 1장 아키텍처 원칙 그대로다.
엔진은 순수 GDScript이고 헤드리스로 돌아간다.

### 11.2 매치 엔진 — 틱 기반 에이전트 시뮬레이션

FM 수준의 전술 시뮬레이션을 만들지는 않는다.
**22명이 각자 판단하고 움직이되, 판단 규칙은 단순하게 유지한다.**

#### 틱 구조

```
1틱 = 게임 내 0.2초  →  90분 = 27,000틱
매 틱마다:
  1. 공 소유자 판단 (패스 / 드리블 / 슛)
  2. 나머지 21명의 목표 위치 갱신
  3. 이동 적용
  4. 접촉 · 경합 판정
  5. 이벤트 발생 시 기록
```

#### 선수 상태

| 항목 | 내용 |
|---|---|
| 위치 · 속도 | 연속 좌표 (105 × 68 m 기준) |
| 역할 존 | 포지션(2.5)이 정하는 기본 활동 구역 |
| 잔여 체력 | 이동 거리만큼 소모. 능력의 **체력**이 소모율을 정함 |
| 상태 | 대기 / 이동 / 볼 소유 / 압박 / 넘어짐 |

#### 판단은 효용 함수로

각 선택지에 점수를 매기고 가장 높은 것을 고른다. 트리나 상태 기계보다
**능력치를 반영하기 쉽고 디버깅이 쉽다.**

| 선택 | 점수에 들어가는 것 |
|---|---|
| 패스 | 받는 사람까지의 거리 · 사이 수비 수 · **궁합**(2.9) · 기술 |
| 드리블 | 앞 공간 · 상대 거리 · **스피드** · 기술 |
| 슛 | 골대까지 거리 · 각도 · 압박 · **기술** |

성공 판정은 **능력 대 능력 + 난수**다. 시드 고정(1.2)을 따르므로 재현된다.

#### 능력치가 실제로 작동한다

지금까지 능력 5개(2.2)가 "결과 공식의 계수"였는데, 엔진이 생기면 **행동으로 나타난다.**

| 능력 | 엔진에서 |
|---|---|
| 기술 | 패스 · 슛 성공률, 볼 컨트롤 |
| 체력 | 소모율, 후반 속도 저하 |
| 피지컬 | 경합 승률, GK 선방 |
| 스피드 | 이동 속도 |
| **센스** | **판단 품질** — 좋은 선택지를 고를 확률 |

센스가 특히 중요해진다. 노장이 안 뛰는데 공이 그 앞으로 오는 이유가
**실제로 좋은 위치를 고르기 때문**이 된다(2.2 나이 곡선).

#### 궁합이 패스 정확도에 들어간다

2.9의 궁합 누적이 여기서 값을 한다. **손발이 맞는 둘 사이의 패스가 실제로 잘 간다.**
오래 함께한 팀이 강하다는 것이 수치가 아니라 경기로 드러난다.

#### 조기축구 고증은 파라미터로 넣는다

엔진이 생겨도 **주제는 그대로다.**

- 기본 활동량이 낮다 — 대부분 걷고 있다
- 후반 체력 저하가 급격하다
- 압박이 느슨하다 (수비 라인이 안 맞는다)
- 실수 확률이 높다

**프로 축구 파라미터를 낮춘 게 아니라, 다른 파라미터 세트다.**
"이 오합지졸을 어떻게든 굴러가게 만들기"라는 주제는 엔진 위에서 더 잘 드러난다.

### 11.3 매치 뷰어 — 바둑알

> **방침 변경.** 원래 "도트 캐릭터(HGSS 수준)"였다.
> **바둑알(FM 2D 방식)을 기준선으로 내리고, 도트는 선택 항목으로 올린다.**
> 이유는 하나다 — **바둑알로 만든 상태가 이미 완성품**이기 때문이다.
> 도트를 목표로 잡으면 에셋이 안 나오는 동안 경기 화면 전체가 미완성으로 남는다.

#### 기준선 — 원과 숫자

선수를 원으로 그린다. **스프라이트가 한 장도 필요 없고 전부 `_draw()` 로 그린다.**

| | |
|---|---|
| 선수 | 원 + 등번호. 부감 15px / 근접 30px |
| 팀 구분 | 색 — 우리 파랑 · 상대 빨강 · GK 노랑 |
| 이름 | **우리 팀만 이름, 상대는 번호** — 11.8이 요구하는 "사람 이름" |
| 볼 소유 | 흰 테두리 |
| 필드 | 잔디 스트라이프 + 라인. 코드로 그린다 |

#### 체력 링

**원 둘레가 체력 게이지다.** 이 게임에서 가장 중요한 정보가
"누가 숨차서 못 뛰는가"인데, 그게 필드 위에 직접 그려진다.
FM에는 없는 표현이고 **소재에서 곧바로 나온 것**이다.

- 체력에 따라 링이 줄고 색이 바뀐다 (초록 → 노랑 → 빨강)
- 지시를 무시하는 중인 선수는 **주황 테두리 + `✗`** (11.5)
- 우측 패널의 체력 바와 **같은 색으로 대응**한다

#### 배율 2종

| | 근접 | 부감 |
|---|---|---|
| 원 크기 | 30px | 15px |
| 보이는 것 | 공 주변 + 이름 | 22명 전부 |
| 용도 | 결정적 장면 · 골 | 기본 |

부감이 기본이다. 카메라 추적 코드가 필요 없어 **10안 중 구현이 가장 싸다.**

#### 도트는 선택 항목

바둑알과 도트는 **같은 좌표 데이터를 읽는다**(11.4). 그리는 함수만 갈아끼우면 되므로
**바둑알로 먼저 만들어도 나중에 도트로 바꾸는 비용이 거의 없다.**

도트로 갈 경우의 스펙 — **탑다운 3/4 시점, 4방향**(좌=우 뒤집기 → 실작업 3방향),
실작업 **15~18프레임**. 배경은 레이어 조합(하늘·중경·트랙·필드·소품)으로
구장 종류를 만든다. **여유가 생기면 하고, 안 해도 게임이 완성된다.**

#### 포기하는 것

무릎 아픈 쉰여덟이 숨차서 걷는 모습을 **그림으로는 못 보여준다.**
링이 28%로 줄어드는 것과 실제로 걸어가는 뒷모습은 다른 물건이다.
그 짐은 텍스트 로그가 진다 — 11.8이 이미 "사람 이름이 계속 나와야 한다"고 맡겨뒀다.
링 28%가 `"심기국, 이제 뛰지 않는다. 걸어서 복귀 중"` 이라는 문장의 근거가 된다.

#### 화면 구성

`05-ui.md` S-M2. 좌측 필드 + 우측 고정 패널(출전 명단 · 체력 · 주의 · 로그) +
하단 컨트롤(배속 · 건너뛰기 · 텍스트 모드 · 교체).

#### 구현 순서

| 단계 | 만드는 것 | 이유 |
|---|---|---|
| 1 | **텍스트 로그** | `events` 만 읽는다. 엔진이 도는지 이걸로 검증 |
| 2 | **전술 오버레이** | 효용 값 표시. 11.2 튜닝에 필수 |
| 3 | **바둑알 + 체력 링 + 패널** | **여기가 출시 가능한 상태** |
| 4 | 확대 · 골 연출 | 극적인 순간 |
| 선택 | 도트 교체 | 여유가 생기면 |

### 11.4 엔진 → 뷰어 인터페이스

**뷰어를 나중에 붙일 수 있게** 엔진이 기록만 남긴다.

```
MatchLog {
  ticks: [ { t, players:[{id,x,y,pose,facing}], ball:{x,y} } ... ]
  events: [ { t, type, actors, detail } ... ]
}
```

- 초기에는 `events` 만 읽어 **텍스트 로그**로 출력한다
- 뷰어가 완성되면 `ticks` 를 재생한다
- **데이터가 같으므로 엔진을 안 건드리고 뷰어만 갈아끼운다**

틱 전체를 저장하면 용량이 크므로, 실제로는 재생 시 **엔진을 같은 시드로 다시 돌린다.**
결정론(1.2)이 이것을 보장한다.

### 11.5 전술

전술의 축을 **깊이가 아니라 수용률**에 둔다.
지시는 적고 단순하되, **누가 따르고 누가 무시할지가 게임**이다.
"지시가 확실히 전달되지 않는 것이 이 게임의 정체성"을 그대로 시스템으로 만든 것이다.

#### 포메이션 + 지시 4종

지시는 각 3단, 기본값 있음. **하나도 안 만져도 경기가 된다.**
전부 엔진 파라미터 1~2개라 구현 비용이 거의 없다.

> **포메이션은 지시와 성격이 다르다.** 지시 4개는 3단 세그먼트라 경기 중에도 바꿀 수 있지만,
> 포메이션은 8종 중 하나를 고르는 것이고 **경기 중에는 못 바꾼다**(11.5).
> 화면에서도 갈라져 있다 — 포메이션은 카드 8장, 지시는 세그먼트 4줄이다.
> 아래 표에 한 줄로 같이 두는 것은 **엔진 파라미터로는 나란히 놓이기 때문**이다.

| 지시 | 선택지 | 엔진에서 (11.2) | 의미 |
|---|---|---|---|
| 포메이션 | 8종 (아래) | 역할 존 배치 | 숙련도가 쌓인다 |
| 수비 라인 | 올림 / 보통 / 내림 | 수비 존 `x` 오프셋 | 올리면 뒷공간, 내리면 체력 절약 |
| **활동량** | 강하게 / 보통 / **아끼기** | 이동 속도 계수 · 체력 소모율 | **가장 중요한 지시.** 후반까지 버틸지 |
| 압박 | 강하게 / 보통 / 안 함 | 상대 접근 임계값 | 뺏지만 먼저 지친다 |
| **출전 배분** | 고르게 / 균형 / 이길 사람 위주 | 교체 제안 로직 | **전술이 아니라 정치다.** 목표 3축이 충돌 |

**개인 지시는 최대 2개.** "김상수한테 몰아줘" 같은 것. 더 늘리면 FM이 된다.

#### 포메이션 8종

난도가 다르다. 조기축구에서 3-4-3을 굴리려면 센스와 체력이 둘 다 필요하고,
없으면 자리를 못 지킨다. **포메이션 자체가 수용률에 기본값을 준다.**

**난도 보정은 4-4-2를 `0`으로 놓은 상대값이다.** 기본 포메이션이 기준점이다.

| 포메이션 | 난도 | 보정 | 요구 조건 | 엔진 영향 |
|---|---|---|---|---|
| **4-4-2** | 쉬움 | `0` | 없음 — **기준점** | 표준 역할 존 |
| **5-3-2** | 쉬움 | `-2` | 없음 | 수비 존 5개 · 체력 소모 **-15%** |
| **4-4-1-1** | 보통 | `-10` | FW 중 센스 `55+` 1명 | 처진 FW 존 |
| **4-3-3** | 보통 | `-10` | 측면 체력 `60+` 2명 | 윙 존 넓음 · 소모 **+20%** |
| **4-1-4-1** | 보통 | `-12` | 수비형 MF 적임 1명 | DM 존 고정 · 중원 차단 상승 |
| **3-5-2** | 어려움 | `-22` | DF 3명 평균 센스 `60+` | 수비 존 3개 · 측면 뒷공간 노출 |
| **4-2-3-1** | 어려움 | `-25` | 팀 평균 센스 `55+` | 4개 라인 · 간격 유지 판정 추가 |
| **3-4-3** | 어려움 | `-28` | 센스 `58+` · 체력 `60+` | 극단 전진 · 소모 **+30%** · 역습 취약 |

**요구 조건을 못 채워도 고를 수 있다.** 막지 않고 수용률만 깎는다 —
3-4-3을 고집하다 5실점하는 것도 이 게임의 이야기다.

> **인원 미달용 포메이션은 만들지 않는다.** 11명을 못 채우면 진형을 바꾸는 게 아니라
> 경기를 취소한다 (11.7).

#### 포메이션 숙련도

포메이션마다 **팀 숙련도**가 쌓인다. 새 포메이션은 처음엔 안 굴러가고 몇 경기 지나야 자리를 잡는다.

**숙련도는 `0~100`으로 저장하고 경기당 `+5`씩 오른다** — 20경기면 만렙이다.
수용률 기여는 `× 0.3` 이므로 최대 `+30`이다.

```
포메이션 수용률 = 50                        기본
                + 난도 보정                 -28 ~ 0
                + 숙련도 × 0.3              0 ~ +30
                + 요구 조건                 충족 +8 / 미달 -10
                + (신뢰 − 50) × 0.4         5.4
                + (친화력 − 50) × 0.2  +  (센스 − 50) × 0.2
                − 변경 직후                 지난주와 다르면 -8 (1경기)
                                                       clamp 5 ~ 95
```

> **검산** — S-04 목업의 `4-4-2 · 숙련 62`:
> `50 + 0(난도) + 18.6(숙련) + 0(요구 조건 없음) = 68%`.
> 화면 패널의 분해 표와 일치한다.

**숙련도는 팀 단위**다. 회원이 절반 이상 바뀌면 절반으로 감쇄한다 —
사람이 바뀌면 손발이 다시 안 맞는다 (2.9 궁합과 같은 원리).

**"변경 직후 패널티"가 핵심 장치다.** 상대에 맞춰 매주 갈아끼우는 플레이를 막는다.
결과적으로 **"우리 팀은 4-4-2 팀이다"** 라는 정체성이 생긴다 (4장 구단 정체성).

#### 수용률

지시 종류마다 **걸리는 기질이 다르다.**

| 지시 | 걸리는 것 | 전형적인 반발 |
|---|---|---|
| 포메이션 | 친화력 · 센스 · 숙련도 | 센스 낮으면 자리를 못 지킨다. 반발이 아니라 **능력 부족** |
| 수비 라인 | 친화력 · 센스 · 나이 위계 | 나이 많은 수비수가 안 올라온다 |
| 활동량 아끼기 | **승부욕** · **자존심** | **"내가 뛰어야 이긴다"고 믿는 사람은 아끼라고 해도 뛴다.** 그러다 후반에 죽는다 |
| 압박 | 성실함 · 체력 | 체력 30%면 지시와 무관하게 못 한다 |
| 출전 배분 고르게 | **자존심** · 친화력 · 만족도 | **벤치를 못 견디는 사람이 반발한다.** 못하는 사람이 안 나오면 이탈 |
| 개인 지시 | **신뢰** · 나이차 · 만족도 | 나보다 열 살 많은 창단 멤버는 잘 안 듣는다 (2.11) |

> **승부욕과 자존심을 구분해서 쓴다**(2.3). 출전 배분에 반발하는 것은 **자존심**이다 —
> 승부욕만 높은 사람은 "내가 빠지는 게 낫겠네" 하고 순순히 벤치에 앉는다.
> 활동량 아끼기를 무시하는 것은 **둘 다 높은 사람**이다.

#### 수용률 계산 🔢 *초안 — 구현 중 튜닝*

**회원별 · 지시별로 따로 계산한다.** 화면에 뜨는 %는 팀 평균이다.

```
수용률 = 50                        기본
       + 20                        중립 선택지일 때 (기본 · 보통 · 균형)
       + (신뢰 − 50) × 0.4         전 지시 공통 (5.4)
       + (친화력 − 50) × 0.2       전 지시 공통
       + 지시별 기질 보정           아래 표
       − 나이차 패널티              (상대 나이 − 내 나이) × 0.6, 최대 -18 (2.11)
       − 만족도 패널티              40 미만이면 (40 − 만족도) × 0.5, 최대 -20
       ± 영향력 전파                마지막 단계 · 아래
                                                       clamp 5 ~ 95
```

##### 극단 선택지는 20%p를 잃고 시작한다

가운데(`기본` · `보통` · `균형`)를 고르면 `+20`이 붙는다.
**"많이"도 "아끼기"도 둘 다 극단이라 양쪽 다 안 듣는다.**

이 하나로 **가운데를 고르면 말을 잘 듣는다**가 구조가 된다.
전술로 이기려면 극단으로 가야 하는데, 극단은 안 듣는다.

##### 상한 95

**완벽한 전술이 없다.** 전원이 100% 따르는 조합을 못 만들게 하는 장치이고,
"수용률이 항상 100% 미만"이라는 원칙(아래 FM 방지 표)의 실제 구현이다.

##### 지시별 기질 계수

`(기질값 − 50) × 계수` 로 더한다.

| 지시 | 기질 | 계수 |
|---|---|---|
| 수비 라인 **올림** | 나이 *(40 초과분)* | `-0.5` |
| | 센스 | `+0.2` |
| 활동량 **많이** | 성실함 | `+0.2` |
| | 체력 *(50 미만분)* | `-0.4` |
| **활동량 아끼기** | **승부욕** | **`-0.3`** |
| | **자존심** | **`-0.3`** |
| 압박 **강하게** | 성실함 | `+0.2` |
| | 체력 *(50 미만분)* | `-0.5` |
| **출전 배분 고르게** | **자존심** | **`-0.4`** |
| | 친화력 | `+0.2` |
| 출전 배분 **이길 사람 위주** | 자존심 | 주전 `+0.2` / 저출전자 `-0.4` |
| 개인 지시 | 나이차 | **×2 가중** |

##### 활동량 아끼기에만 둘이 같이 걸린다

승부욕 80 · 자존심 80이면 `-18`이고, 극단 선택지라 `+20`도 못 받는다.
**38%** — 2.3의 *"내가 뛰어야 이긴다"* 가 숫자로 나온다.
그러다 후반에 죽는 것까지 한 세트다.

##### 출전 배분에는 승부욕이 걸리지 않는다

**자존심만 `-0.4`다.** 승부욕만 높은 사람은
*"내가 빠지는 게 낫겠네"* 하고 순순히 앉는다 —
반발하는 것은 **자기가 뛰어야 한다고 믿는 사람**이지 이기고 싶은 사람이 아니다.

#### 영향력 전파 — 무시가 두 배로 번진다

기질 중 **영향력만은 본인의 수용률이 아니라 남의 수용률에 걸린다**(2.3).
그래서 위 식에 안 들어가고 **판정 뒤에 따로 돈다.**

```
1. 각자 수용률 계산
2. 판정                    ← 킥오프 1회 · 시드 고정
3. 영향력 70+ 인 사람의 결과를 본다
     무시했으면   주변 − (영향력 − 50) × 0.4
     따랐으면     주변 + (영향력 − 50) × 0.2
   대상 = 궁합 양수 + 같은 라인
4. 주변만 재판정            ← 1회. 연쇄 없음
```

**비대칭이 의도적이다.** 나쁜 쪽이 두 배로 번진다.

그래서 두 가지가 동시에 성립한다 — **한 명만 설득하면 되는 경우**가 생기고,
**영향력자를 방치하면 라인 하나가 통째로 무너진다.**
이것이 전술 화면의 숨은 공략점이다.

**연쇄는 없다.** 3단계를 한 번만 돌린다. 연쇄를 허용하면
영향력 하나로 팀 전체가 뒤집혀서 다른 입력이 의미를 잃는다.

#### 판정 — 3구간

```
roll = rand(0, 100)          시드 고정

roll < 수용률                    → 따름
수용률 ≤ roll < 수용률 + 20      → 반반   상황에 따라 다르게 행동한다
그 이상                          → 무시   S-M2에서 주황 테두리 + ✗
```

S-04 수용 예측 패널의 `따를 · 반반 · 무시` 3열이 이 구간이다.

**판정은 경기 시작 시 1회.** 시드 고정(1.2)이므로 재현된다.
따르기로 한 사람은 그 경기 내내 따른다 — **매 틱 굴리지 않는다.**
한 경기 안에서 오락가락하면 플레이어가 인과를 못 읽는다.

**경기 중 지시를 바꿔도 재굴림하지 않는다.** 안 듣던 사람은 계속 안 듣는다.
이것이 "지시가 확실히 전달되지 않는다"를 가장 정확하게 구현하는 방식이다.

#### 경기 중 개입

- 교체 지시 가능. 단 **거부당할 수 있다** (만족도 · 위계, 2.11)
- 지시 변경 가능. 단 수용률은 그대로
- 선수 조작은 없다 (11.6)

> **자동 교체 조건을 만들지 않는다.** `체력 30% 이하면 자동 교체` 같은 규칙을 두면
> **"교체는 거부당할 수 있다"가 무력해진다** — 자동화가 거부를 삼켜버리고,
> 이 게임에서 가장 중요한 순간(심기국이 교체를 거부하고 계속 뛰는 장면)이 사라진다.
> 교체는 매번 플레이어가 판단하고, 매번 거부당할 수 있다.

#### 경기 후 결산

지시를 무시한 것이 그냥 넘어가지 않는다. **신뢰가 장기 축이 된다.**

| 상황 | 결과 |
|---|---|
| 무시했는데 **이겼다** | 그 사람 만족도 ↑ · **플레이어 신뢰 ↓** — "감독 말 안 들어도 되네" |
| 무시했는데 **졌다** | 신뢰 ↑ · 다음 경기 수용률 ↑ |
| 따랐는데 이겼다 | 신뢰 ↑↑ · 팀 전체 수용률 상승 · **포메이션 숙련도 +2** |
| 따랐는데 졌다 | 신뢰 ↓ · **"그러게 내 맘대로 할 걸"** 이벤트 가능 |
| 아끼라 했는데 무시 → **부상** | 본인 만족도 ↓↓ · 신뢰 ↑ · 다음부터 잘 듣는다 |

초반에는 아무도 말을 안 듣고, 판단이 맞아떨어지는 게 쌓이면 수용률이 오른다.
**"팀이 내 것이 되는 과정"(4.10)이 전술에도 걸린다.**

#### FM이 되지 않게 하는 장치

| 장치 | 효과 |
|---|---|
| 지시 4개 + 포메이션 + 개인 2개 | 더 늘리지 않는다. **슬라이더 15개짜리 화면은 만들지 않는다** |
| 각 3단만 | 0~20 스케일이 아니다. 조기축구 감독은 그렇게 말하지 않는다 |
| 수용률이 항상 100% 미만 | 완벽한 전술이 없다. **최적해를 찾는 게임이 안 된다** |
| 포메이션 변경 패널티 | 상대마다 갈아끼우는 플레이를 막는다 |
| 경기 중 재굴림 없음 | 실시간 미세조정으로 이기는 길을 막는다 |
| 출전 배분이 여기 있음 | 전술 화면이 **승리 최적화가 아니라 사람 관리**가 된다 |

### 11.6 화면 방침

- 관전 전용. 플레이어가 선수를 조작하지 않는다
- 대부분의 시간에는 아무 일도 안 일어난다 — 다들 서 있고, 한 명은 숨차서 걷고 있다.
  **이것이 조기축구의 실제 모습이며, 엔진 파라미터로 그렇게 만든다**
- **배속 · 건너뛰기는 필수** (10장 세션 시간 설계)

### 11.7 인원 미달 — 경기 취소

> **방침 변경.** 원래 "7~10명이면 수적 열세로 경기"였다.
> **11명을 못 채우면 경기를 취소한다.** 미달 상태로 뛰는 경로를 없앤다.

**11명 미만이면 경기가 성립하지 않는다.** 진형을 바꾸는 게 아니라 취소한다.
그래서 **6장 용병 시스템에 실제 압박이 실린다** —
용병은 "있으면 편한 것"이 아니라 **경기를 성립시키는 수단**이 된다.

#### 성립 흐름

| 단계 | 내용 |
|---|---|
| 참석 조사 | 단톡방 공지 → 회신. 이번 주는 9명 |
| 부족 인지 | 라인업 화면에 빈 자리. 상태 바에 "인원 2명 부족" 상시 노출 |
| 메우기 | ① **용병 공고**(6장) — 남은 날짜에 따라 응답률이 다르다 ② 무응답자 직접 접촉(행동 1) ③ 불참자 설득 |
| 경기 전날 | **확정 시점.** 11명이면 성립 |
| 못 채우면 | **취소 통보** |

**포메이션 선택 자체가 잠긴다.** 미달용 대안을 주지 않고
인원을 채울 수단과 취소 버튼만 남긴다.

#### 취소의 대가

| 항목 | 내용 |
|---|---|
| 대관료 | **90% 환불** (D 결정). 10%는 날아간다 |
| 회원 만족도 | **전원 하락.** 나오기로 했던 사람이 특히 크게 — 시간을 비워뒀다 |
| 상대팀 관계 | **악화.** 다음에 경기를 잘 안 잡아준다. 반복되면 기피 대상 |
| 구단 평판 | 하락. **용병 응답률과 신입 지원이 준다** — 악순환이 붙는다 |
| 연속 취소 | 2주 연속이면 별도 이벤트. "이 팀 계속 할 수 있는 거 맞아요?" |

**경기 취소가 이 게임의 실질적 패배다.** 게임 오버는 없지만 아프다.
9명으로 어영부영 뛰는 도피처가 사라지면서 **인원을 채우는 것 자체가 매주의 과제**가 된다.

#### 취소 경로는 둘이다

인원만이 아니다. **구장을 못 잡아도 경기가 없다**(3.6).

```
선착순 늦음 / 추첨 떨어짐 → 다른 구장 시도 → 다 마감 → 취소
```

| | **인원 미달** | **구장 미확보** |
|---|---|---|
| 회원 만족도 | 크게 하락 | **작게 하락** — 총무 잘못이라기보다 운이다 |
| 상대팀 관계 | 악화 | **똑같이 악화** |
| 대관료 | 90% 환불 (10% 손실) | 해당 없음 — 예약 자체가 없다 |
| 구단 평판 | 하락 | 하락 |

**단골 등급이 이 위험을 줄인다.** 3년 이상 한 구장을 쓰면 **정기 예약**으로 넘어가
매주 잡을 필요가 없어진다 — 초반에만 겪는 사고다.

#### 경기 중 인원 감소

부상·퇴장으로 줄어드는 것은 **다른 문제다.** 이건 취소할 수 없다.

| 상황 | 처리 |
|---|---|
| 교체 대기 있음 | 교체 제안. **거부당할 수 있다** (11.5) |
| 대기 없음 | **10명 이하로 계속.** 엔진이 남은 선수의 역할 존을 넓혀 자동 보정 |
| 알림 | 텍스트로만 — `"윤현빈 무릎. 교체 없이 10명으로 간다"` |

플레이어 선택은 없다. 포메이션 목록에 미달용이 없는 것과 일관된다.

### 11.8 경기 산출물 (E31~E37)

초기 구현은 텍스트 로그뿐이다. 그러면 **산출물이 곧 읽을거리**다.

```
6:12  김상수 선제골 (이현찬 도움)
6:31  박현범 경고
7:04  최승철 교체 거부 — 그냥 계속 뜀
7:20  심기국 무릎 통증으로 교체
종료  3-2 승
```

**사람 이름이 계속 나와야** 한다. 스코어만 나오면 로그가 아니라 결과 통보다.

#### 득점자 · 도움 (E31)

| 쓰이는 곳 |
|---|
| 개인 기록 누적(E28) → 칭호 `결승골의 사나이`(2.12) |
| 만족도 — 골을 넣으면 기분이 좋다 |
| 승부욕 높은 회원의 동기 |

**"3년 만에 첫 골"** 같은 순간이 여기서 나온다. 기록이 쌓여야 서사가 생긴다.

#### 부상 (E32)

발생 조건의 절반은 3.6에서 이미 정해졌다.

| 입력 | 영향 |
|---|---|
| **잔디 × 계절** | 3.6 — 맨땅 겨울이 최악 |
| 나이 | 회복 속도, 발생률 |
| 체력 | 낮으면 후반에 다친다 |
| 연속 출전 | 누적 피로 |
| **상대팀 성격** | 거친 팀(3.7) |
| 훈련 | 하락 지연 + 부상 저항(2.10) |

**부상은 인원 미달로 직결된다.** 한 명 다치면 몇 주 빠지고, 그동안 다른 사람이 더 뛰고,
그 사람도 다친다. **연쇄가 생긴다.**

#### 경고 · 퇴장 (E33) — 상대 성격 × 우리 기질

**양쪽을 다 반영한다.**

| 입력 | |
|---|---|
| 상대팀 성격 | 거친 팀이면 발생률↑ (3.7) |
| **우리 회원 참을성** | 낮으면 욱한다 (2.3) |

여기서 라인업 판단이 하나 생긴다.

> 오늘 상대가 거친 팀인데, `욱하는 성격` 김씨를 뺄까?

칭호(2.12)가 장식이 아니라 **실제 기용 판단**이 된다.

결과:

- 경고 → 매너 규칙(8.2)에 따라 제재 → 다음 경기 결장
- 퇴장 → 수적 열세 + **상대팀 관계 악화**(3.7)
- 반복되면 **인심 평판 하락**(4.7) → 붙어줄 팀이 줄어든다

**이기려고 세게 나가면 다음에 경기를 못 잡는다.**

#### 당일 날씨 (E34) — 예보는 확률이다

계절(D4)과 별개로 그날의 날씨.

| 날씨 | 효과 |
|---|---|
| 맑음 | — |
| 비 | 참석률↓, 맨땅이면 진흙탕 |
| **폭우** | **취소** — 대관료 90% 환불 + 불만(3.6) |
| 폭설 · 한파 | 참석률 급락, 부상↑ |
| 폭염 | 체력 소모↑ |

##### 예보를 미리 볼 수 있다. 단, 틀린다

토요일에 **확률로** 나온다. 확정 정보가 아니라 판단 재료다.

> 일요일 강수확률 60%. 용병을 부를까?

예보가 빗나가면 헛돈이고, 안 부르면 인원 미달이다.
**불확실성 위에서 또 베팅**하는 구조라 용병 호출(6장)에 층이 하나 더 생긴다.

#### 홈 / 어웨이 (E35) — 별도 보정 없음

섭외 협상 포인트로는 3.7에 이미 있다. **경기력 보정은 두지 않는다.**

조기축구에서 홈 어드밴티지는 크지 않고, **참석률 차이가 곧 홈 이점**이며
그것은 이미 거리로 계산된다(3.2). 중복해서 보정할 이유가 없다.

#### 심판 (E36) — 자체 심판

**정식 심판 고용은 두지 않는다.** 조기축구는 자체 해결이다.

| 방식 | 결과 |
|---|---|
| 우리 쪽 사람이 봄 | 상대가 불만 → 관계 악화 위험 |
| 상대 쪽이 봄 | 우리가 불만 |
| 번갈아 / 제3자 | 무난 |

**판정 시비가 상시 존재하는 관계 악화 원인**이 된다. 매너 좋은 팀은 시비를 안 걸고,
거친 팀은 건다(3.7). 이벤트 소재로도 쓰인다.

#### 상대팀 전력 산출 (E37)

3.7의 간이 시뮬 3수치(회원 수 · 전력 · 사기)로 **상대 선수 11명을 생성한다.**

매치 엔진이 생겼으므로 합산치 비교가 아니라 **실제로 뛸 선수가 필요하다.**
다만 상대 선수는 우리 회원처럼 정교할 필요가 없다.

| 우리 회원 | 상대 선수 |
|---|---|
| 능력 5 + 기질 6 + 프로필 + 궁합 + 이력 | **능력 5 + 포지션만** |
| 영속적 | 경기 때 생성, 팀 전력에서 파생 |

라이벌 팀(12장)처럼 반복해서 만나는 상대만 **선수를 고정 보관**한다.
"저 팀 9번이 매번 우리를 괴롭힌다"가 성립하려면 그렇다.

## 12. 라이벌 팀

분열(이탈 경로 3번)로 나간 무리가 **새 팀을 만들어 계속 남는다.**

- 우리 팀 회원을 역으로 빼가려 함 (영입 권유의 반대 방향)
- 경기에서 만난다 — 서사가 세다
- 지역 내 신규 유입을 두고 경쟁

이로써 영입 권유의 "타 팀과 사이가 나빠진다"가 추상적 페널티가 아니라
**구체적인 상대**를 갖게 된다.

## 13. 이벤트 시스템

**이 게임의 최대 작업량은 코드가 아니라 글이다.** 텍스트가 재미없으면 다른 게 다 좋아도
실패하고, 텍스트가 좋으면 그래픽이 조악해도 팔린다.

### 13.1 물량으로는 못 이긴다

```
52주 × 5년 = 260주,  하루에 여러 건
이벤트 20개  →  3시즌이면 전부 봄
```

200개를 써도 5년이면 바닥난다. **답은 적은 수로 다양하게 보이게 하는 구조다.**

### 13.2 이벤트의 무게는 사건이 아니라 대상이 정한다

| 같은 사건 | 대상 | 느껴지는 것 |
|---|---|---|
| 당일 아침 불참 | 원래 안 나오던 사람 | 또야 |
| 당일 아침 불참 | **개근왕 3년차** | **"무슨 일 있나?"** |
| 이적 문의 | 지난달 신입 | 가라 그럼 |
| 이적 문의 | **창단 멤버 형님** | **12년을 같이 했는데** |

**사건 20개 × 대상 30명 = 조합 600개**, 텍스트는 한 벌이다.

```
[사건]  ×  [대상]  ×  [시점]  ×  [맥락]
```

### 13.3 대상 유형 4종

대상이 한 명이라고 가정하면 표현할 수 없는 것이 많다. **네 가지로 나눈다.**

| 유형 | 대상 | 예 |
|---|---|---|
| **개인** | 1명 | 김씨가 이적 문의를 받았다 |
| **관계** | 2명 | 사이 나쁜 둘이 같이 뛴 뒤 시비가 붙었다 |
| **집단** | 조건 만족 N명 | 젊은 회원 셋이 따로 뭉친다 |
| **구성** | 팀 전체 분포 | **40대 이상이 과반이 됐다** |

#### 관계형 — 두 사람 사이

| 조건 | 나오는 사건 |
|---|---|
| 궁합 나쁨 + 같이 출전 | 시비, 패스 안 줌 |
| 궁합 좋음 + 한쪽 이탈 | 나머지도 흔들린다 |
| **나이 어린 쪽이 주전** | 형이 불편해한다 (2.11) |
| 같은 포지션 | 경쟁 또는 서로 챙김 |
| 소개자 ↔ 피소개자 | 파벌의 씨앗 (6장) |
| 같은 동네 | 카풀, 같이 빠짐 |

#### 집단형 — 조건을 만족하는 무리

| 조건 | 나오는 사건 |
|---|---|
| 참을성 낮은 사람 3명↑ + 연패 | 집단 불만 |
| 젊은 회원 4명↑ + 나이차 큼 | 따로 뭉친다 |
| 벤치 오래된 사람 3명↑ | 출전 요구가 동시에 |
| 같은 동네 3명↑ | 카풀 문화, 그들끼리 친해짐 |

#### 구성형 — 로스터 분포가 임계값을 넘을 때 ← 새로운 축

**로스터 자체가 이벤트 소스가 된다.**

| 조건 | 나오는 사건 |
|---|---|
| **40대 이상 과반** | *"요즘 우리 팀 평균 나이가…"* 노령화 자각 |
| 20~30대 과반 | 형님들이 소외감을 느낀다 |
| **GK 0명** | 위기 (2.5) |
| **창단 멤버 2명 이하** | *"옛날 사람이 나밖에 없네"* |
| 신입 과반 | 정체성 희석. 분위기가 낯설어진다 |
| 특정 기질 편중 | 팀 분위기가 한쪽으로 고착 |
| 명단 30명 초과 | 서로 이름을 모른다 (D6) |

**아무 사고도 없는데 이벤트가 발생한다.** 사람이 들고 나면서 구성이 바뀐 것만으로.
지역 유형(3.4)이 유입 프로필을 정하므로
**연고지가 장기적으로 어떤 구성형 이벤트를 볼지까지 정한다.**

### 13.4 발생 조건 8축

| 축 | 예 |
|---|---|
| **대상** | 개인 · 관계 · 집단 · 구성 (13.3) |
| **시점** | 요일 × 시간대 (10장) |
| **날씨** | 맑음 · 비 · 폭염 · 한파 |
| **계절** | 봄여름가을겨울 (D4) |
| **팀 상태** | 재정 · 평판 · 인원 · 연승/연패 |
| **관계** | 회원 간 궁합 · 타팀 관계 |
| **직전 사건** | 지난 경기 결과 · 최근 이벤트 |
| **장소 · 상대** | 구장 속성 · 상대팀 성격 |

같은 이벤트라도 조건이 다르면 다른 장면이 된다.

> `회식 제안` + 연승 + 여름 + 재정 여유 → **"오늘 한잔 하시죠"**
> `회식 제안` + 연패 + 겨울 + 재정 마이너스 → **"이럴 때일수록 모여야죠"**

### 13.5 통보 시점이 곧 정보다

같은 "불참"도 언제 알려주느냐로 완전히 다르다.

| 통보 | 할 수 있는 것 | 알게 되는 것 |
|---|---|---|
| 목요일 저녁 | 용병 공고 올릴 시간 있음 | 배려심 있음 |
| 토요일 밤 | 급하게 인맥 동원 | 보통 |
| **경기 당일 아침** | **아무것도 못 함** | **염치 없거나 사정이 급했거나** |

**사전 통보 규칙(8.2)이 여기서 실체를 갖는다.** 질서라는 추상어가 아니라
"용병 부를 시간이 있느냐"로 체감된다.

### 13.6 분류 4종

| 종류 | 선택 | 비율 | 주로 언제 |
|---|---|---|---|
| **결정형** | 있음. 결과가 갈림 | 10% | 평일 — 대응할 시간이 있을 때 |
| 통보형 | 없음. 그냥 벌어짐 | 25% | 아무 때나. **경기 당일 아침이 최악** |
| 기회형 | 받을지 말지 | 15% | 평일 |
| **색깔형** | 없음. 상태 변화도 없음 | **50%** | 경기 다음날 · 뒤풀이 |

**색깔형이 절반이어야 한다.** 매번 결정을 요구하면 피로하고
"평범한 주는 1~3분"(10장)이 무너진다.

> 월요일 아침. 단톡방에 어제 경기 사진이 올라왔다.
> 형님들이 *"내 배 왜 이렇게 나왔냐"* 고 난리다.

아무것도 안 바뀌는데 **게임이 살아 있게 된다.** 그리고 제일 싸게 쓸 수 있다.

### 13.7 데이터 구조

코드 수정 없이 리소스 파일로 추가 가능해야 한다.

```
id          : morning_no_show
분류        : 통보형
대상 유형   : 개인
발생 시점   : [경기일 아침]
트리거      : 참석 판정 실패
조건        : 필수   — 해당 경기 불참자
              가중치 — 성실함↓ 거리↑ 날씨 나쁨
텍스트      : 템플릿 (변수 치환)
선택지      : (결정형만)
결과        : 만족도 / 신뢰 / 관계 / 태그
쿨다운      : 같은 대상 4주
톤 태그     : 코믹 | 짠함 | 현실
```

**필수 조건**이 안 맞으면 발생 자체가 안 되고, **가중치**는 여러 후보 중 누가 더 잘
걸리는지를 정한다. 3.7의 "이적 표적이 되는 조건"이 그대로 가중치가 된다 —
**설계가 이미 데이터로 번역되어 있다.**

### 13.8 트리거 4종

| 종류 | 언제 |
|---|---|
| **정기** | 지정된 시간대마다 판정 |
| **조건** | 상태가 임계값을 넘으면 |
| **연쇄** | 다른 이벤트가 **날짜를 지정해** 예약 |
| **일정** | 특정 날짜 (창단 기념일, 시즌 종료) |

시점이 일·시간대 단위라 **"모레 답 준대"** 가 가능하다.

### 13.9 상태 태그 — 짧은 이야기가 데이터로 생긴다

이벤트 결과가 회원에게 태그를 남기고, 그 태그가 다음 이벤트의 조건이 된다.

```
화 저녁   이적 문의를 받았다      →  태그: 이적_고민중
목 저녁   훈련에 안 나온다        ←  조건: 이적_고민중
토 낮     형님이 조용히 부른다    ←  조건: 이적_고민중
+9일      결정                    ←  연쇄 (날짜 지정)
```

스크립트를 쓰는 게 아니라 **태그가 이어지는 것**이라 데이터만으로 서사가 나온다.
태그가 있으면 **다른 이벤트도 다르게 반응**한다 — 이적 고민 중인 사람에게
회식을 제안하면 반응이 다르다.

### 13.10 상한 없음, 우선순위만

| 규칙 | |
|---|---|
| 상한 | **없음** |
| 우선순위 | 결정형 > 기회형 > 통보형 > 색깔형 |
| 같은 대상 | 같은 시간대에 한 번 |

상한이 없으니 **사건이 몰리는 주**가 생긴다. 그것이 10장의 "사건 있는 주는 15~20분"의
실현이다. 평범한 주엔 색깔형 한둘만 뜬다.

### 13.11 단계적 심화 — 반복이 서사가 된다

**같은 이벤트를 또 보는 게 아니라, 같은 문제의 다음 단계를 본다.**

260주를 굴리면 반복은 못 피한다. 완전히 막는 대신 **반복을 악화로 바꾼다.**

#### 5단계 사다리 (공통 구조)

모든 뿌리 문제가 같은 사다리를 탄다.

| 단계 | 성격 | 분류 | 되돌리기 |
|---|---|---|---|
| **1** | 낌새 | 색깔형 | 쉬움 |
| **2** | 표현 | 통보형 | 쉬움 |
| **3** | 행동 변화 | 통보형 | 보통 |
| **4** | 최후통첩 | **결정형** | 어려움 |
| **5** | 실행 | 통보형 | **불가** |

무게가 단계마다 올라가고, **결정형은 4단계에만 나온다.** 그래서 결정형 비율 10%(13.6)가
자연스럽게 지켜진다.

##### 예: 출전 불만

| 단계 | 장면 |
|---|---|
| 1 | 단톡방에 *"요즘 경기 재밌었나요?"* 하고 슬쩍 올린다 |
| 2 | *"형, 저 언제쯤 뛸 수 있을까요?"* |
| 3 | 훈련에 안 나오기 시작한다 |
| 4 | **"저 그냥 다른 팀 알아볼까 봐요"** |
| 5 | 탈퇴 |

**2단계에서 개입하면 되돌릴 수 있고, 4단계까지 가면 늦다.**
초기 신호를 읽는 것이 실력이 된다.

#### 뿌리 문제 8종

| 뿌리 | 누적 지표 | 관련 기질 |
|---|---|---|
| **출전 불만** | 기대 쿼터 − 실제 쿼터 누적 (8.5) | 자존심 |
| **회비 부담** | 납부액 대비 여력 | — (직업이 좌우) |
| **인생 변화** | 결혼 · 육아 · 이사 진행 | — (프로필) |
| **분위기 불만** | 궁합 하락, 소외 | 친화력 |
| **승부 불만** | 연패 누적 | 승부욕 |
| **규칙 불만** | 불공정 집행 누적 (8.6) | 성실함 |
| **관계 악화** | 특정 회원과의 궁합 | 친화력 |
| **신체** | 부상 누적 · 노화 | — (나이) |

각 뿌리 × 5단계 = **40개.** 이벤트를 40개 쓰는 것과 같은 작업량인데
**낱개가 아니라 이야기 8줄**이 된다.

한 사람이 여러 뿌리를 동시에 진행할 수 있다. 출전 불만 3단계 + 회비 부담 2단계면
복합적으로 위험하다.

#### 참을성이 진행 속도와 **건너뛰기**를 정한다 ← 핵심

2.3에서 이렇게 적었다.

> 참을성 높음 → 조용히 삭인다 → **어느 날 그냥 사라진다**

**"어느 날 갑자기"가 여기서 기계적으로 구현된다.**

| 참을성 | 사다리를 타는 방식 |
|---|---|
| **낮음** | 빨리 오른다. 2~3단계에서 크게 터진다. **신호가 명확하다** |
| 보통 | 순서대로 |
| **높음** | 1단계에 오래 머문다. 그러다 **2·3단계를 건너뛰고 4~5로 점프** |

조용한 사람은 **표현 단계를 생략한다.** 그래서 플레이어가 보는 건 1단계 낌새뿐이고,
그다음이 바로 탈퇴 통보다.

**그 1단계 낌새를 잡는 유일한 수단이 단톡방 읽씹**(10장)이다. 두 시스템이 여기서 맞물린다.

#### 되돌리기

플레이어의 개입이 단계를 내린다.

| 개입 | 효과 |
|---|---|
| 만나서 얘기 (슬롯 1) | **1단계 하락** |
| 근본 해결 (출전을 늘려줌 등) | **크게 하락** |
| 단톡방 카톡 | 미미 |
| 방치 | 계속 상승 |

**말로 달래는 건 시간을 벌 뿐이다.** 근본 원인을 안 건드리면 다시 오른다.

#### 단계는 숫자로 보여주지 않는다

2.8의 원칙대로 수치를 노출하지 않는다. **이벤트 자체가 신호**이고,
단톡방 반응이 보조 지표다.

### 13.12 텍스트 변형 4종

| 방법 | 내용 | 비용 |
|---|---|---|
| **변수 치환** | 이름 · 호칭 · 구장 · 상대팀 | 거의 0 |
| **조건부 조각** | 계절 · 날씨 · 관계에 따라 문장이 끼어듦 | 낮음 |
| **동의 표현 풀** | 같은 뜻 여러 표현 중 선택 | 낮음 |
| **어투** | 화자에 따라 말투가 다름 | 중간 |

### 13.13 어투 — 같은 대사도 사람마다 다르다

**어투 템플릿 몇 개로 모든 대사가 개인화된다.**

같은 내용("이번 주에 못 나갈 것 같다")이 이렇게 갈린다.

| 화자 | 대사 |
|---|---|
| 50대 · 친화력 높음 | "야 총무, 내가 이번 주는 좀 그렇다. 미안하다 진짜." |
| 50대 · 자존심 높음 | "이번 주는 안 되겠네." |
| 30대 · 친화력 높음 | "형! 저 이번 주에 일이 생겨서요ㅠㅠ 죄송해요" |
| 20대 · 참을성 낮음 | "저 못 가요" |

**나이 × 기질**로 어투가 정해진다. 이미 있는 데이터이고, 2.11의 호칭 시스템과 한 몸이다.

### 13.14 결과도 변한다

같은 선택이 늘 같은 결과면 몇 번 만에 외운다.

| 같은 선택 | 상태 | 결과 |
|---|---|---|
| "좀만 참아봐" | 신뢰 높음 | 수긍한다 |
| | 신뢰 낮음 | **"말로만 그러시잖아요"** |
| | 나보다 나이 많음 | 씨알도 안 먹힌다 (2.11) |
| | 참을성 낮음 | 그 자리에서 터진다 |

**정답이 상황마다 달라져서** 암기가 안 된다.

### 13.15 쿨다운과 감쇠

| 층 | 내용 |
|---|---|
| **이벤트 쿨다운** | 같은 이벤트 N주 금지 (하드) |
| **대상 쿨다운** | 같은 사람에게 N주 금지 |
| **가중치 감쇠** | 최근에 본 것은 확률↓, 시간이 지나면 회복 (소프트) |
| **미출현 보너스** | 아직 안 본 이벤트에 가산점 |

마지막이 중요하다. **안 본 것을 먼저 보여주면 다양성이 자동으로 확보된다.**
전체를 한 번씩 보기 전에는 반복이 거의 생기지 않는다.

### 13.16 톤도 쿨다운이 필요하다

컨셉 톤 가이드라인은 *"아쉬움만 다룬다"* 인데,
**짠한 이벤트가 연속으로 나오면 우울해진다.**

| 톤 | 비율 |
|---|---|
| 코믹 · 유쾌 | 50% |
| 현실 · 담백 | 30% |
| **짠함** | **20% — 연속 금지** |

짠한 이벤트 뒤에는 몇 회 동안 코믹 쪽 가중치를 올린다. **가끔 나와야 짠하다.**

톤 태그는 13.7 데이터 구조에 이미 있으므로 자동으로 관리된다.

### 13.17 페이싱 — 세션 시간에서 역산한다

10장의 목표(*평범한 주 1~3분, 사건 있는 주 15~20분*)에서 거꾸로 계산한다.

| 분류 | 소요 |
|---|---|
| 색깔형 | 읽고 넘김. 10~20초 |
| 통보형 | 읽고 반응. 30초 |
| 기회형 | 판단. 1분 |
| **결정형** | **고민. 2~3분** |

| 주 | 구성 |
|---|---|
| 평범한 주 | 색깔형 3~5 + 통보형 1 |
| 사건 있는 주 | **결정형 2~3** + 나머지 |

주당 총량 **5~15건**, 대부분이 색깔형이다.

#### 색깔형은 멈춰 세우지 않는다

| 분류 | 표시 |
|---|---|
| 색깔형 | **단톡방 로그로 흘러감** — 안 읽어도 된다 |
| 통보형 | 알림. 확인만 |
| 기회형 · 결정형 | **멈춰 세운다** |

**절반이 그냥 흘러가므로 세션이 길어지지 않는다.** 읽고 싶은 사람만 읽는다.

#### 규모가 커지면 세션도 길어진다

로스터가 크면 사건도 많다. **규모의 네 번째 비용**이다.

| 규모의 비용 | 어디 |
|---|---|
| 벤치 불만 | 00-concept |
| 개별성 상실 | D6 |
| 관리 슬롯 부족 | 10장 |
| **세션 시간 증가** | **여기** |

색깔형이 흘러가므로 견딜 만하지만 **결정형은 비례해서 늘어난다.**

#### 밀도 곡선

| 시기 | 밀도 |
|---|---|
| **인수 직후** | 높음 — 문제가 산적해 있다 |
| 안정기 | 낮음 |
| 위기 | **몰림** (상한 없음, 13.10) |

인수 시작(D1)이라 **처음부터 사건이 많다.** 튜토리얼이 따로 필요 없는 이유이기도 하다.

### 13.18 작성 물량 목표

| 단계 | 개수 | 구성 |
|---|---|---|
| **프로토타입** | 40~60 | 심화형 40 + 색깔형 약간 |
| 최소 출시 | 200~300 | 색깔형 절반 |
| 여유 | 400~500 | |

**심화형 8뿌리 × 5단계 = 40이 뼈대**다. 이것만 있어도 게임이 굴러간다.

### 13.19 데이터 포맷 — 물량과 복잡도를 나눈다

| | 색깔형 | 결정형 · 심화형 |
|---|---|---|
| 물량 | **많음** (50%) | 적음 |
| 조건 | 단순 | **복잡** |
| 선택지 · 결과 · 분기 | 없음 | **있음** |
| 포맷 | **CSV / 스프레드시트** | **개별 파일** |

성격이 정반대라 같은 포맷으로 다루면 한쪽이 불편해진다.
색깔형을 파일 100개로 만들면 손이 못 따라가고, 결정형을 표에 넣으면 분기를 못 담는다.

#### 색깔형 — 스프레드시트

| id | when | require | weight | tone | text |
|---|---|---|---|---|---|
| chat_photo_1 | 경기다음날.아침 | 경기함 | 1 | 코믹 | {회원}이 어제 사진을 올렸다… |
| cold_morning_2 | 경기일.아침 | 계절=겨울 | 2 | 현실 | 다들 패딩을 입고 나왔다… |

7열이면 끝난다. 그리고 스프레드시트라서:

- 톤별 정렬로 **비율을 눈으로 확인**
- 계절별 필터로 **겨울 이벤트가 몇 개인지** 즉시 파악
- 복사·붙여넣기로 변형본 대량 생산
- 빈 셀이 곧 미작성 표시

*하루 30분씩 축적*(아래 운영 방침)에 이 형태가 압도적으로 빠르다.

#### 결정형 · 심화형 — 한 이벤트 한 파일

```
id: leaving_hint_4
root: 출전불만
stage: 4
type: 결정형
target: 개인
when: 평일.저녁
require: 출전불만_단계>=4
tone: 짠함
cooldown: 대상 8주
---
{호칭}이 조용히 부른다.
"{대사_이적고민}"

[계절=겨울] 밖은 어둡고 춥다.
---
choice 잡는다  -> 신뢰>=50 ? 만족도+8, 태그해제 : 만족도+2
choice 보낸다  -> 태그:이적_확정
```

- 헤더는 `key: value`, 본문은 `---` 뒤
- `[조건]` 으로 문장 조각을 끼워넣는다 (13.12)
- **git diff가 깨끗하다** — 이벤트 하나를 고치면 한 파일만 바뀐다

파서는 100줄이면 된다. YAML/JSON은 여러 줄 한글 텍스트가 지저분해진다.

#### 작성 포맷과 런타임 포맷을 분리한다

```
CSV · 텍스트 파일  →  임포트 스크립트  →  .tres 리소스  →  런타임
   (사람이 씀)         (tools/)          (엔진이 읽음)
```

**런타임에 CSV를 파싱하지 않는다.** 임포트 때 한 번 변환하고 게임은 리소스만 읽는다.
소스는 git에 남아 diff가 된다.

### 13.20 검증 — 헤드리스로 발생 횟수를 센다

```
시드 100개  ×  각 5시즌  →  이벤트 발생 로그  →  리포트
```

1장의 순수 시뮬레이션 층과 1.2의 시드 고정이 있어야 가능하다. **UI 없이 돌려야 한다.**

| 리포트 항목 | 잡아내는 문제 |
|---|---|
| **발생 0회 목록** | **조건 충돌** — 절대 안 나오는 이벤트 |
| 심화 단계별 도달률 | 4~5단계가 0이면 도달 불가 |
| 발생 빈도 상하위 | 특정 이벤트가 전체의 20% |
| 분류 비율 | 색깔형 50%가 지켜지나 (13.6) |
| 톤 분포 | 짠함이 20%를 넘나 (13.16) |
| 주당 평균 건수 | 세션 시간 목표와 맞나 |
| **치환 실패** | 렌더링 후 `{호칭}`이 그대로 남음 |

#### 발생 0회가 제일 중요하다

이벤트를 200개 쓰면 **조건이 잘못돼 평생 안 나오는 것이 반드시 생긴다.**
손으로는 못 찾고, 플레이해서도 못 찾는다 — 안 나오는 것을 어떻게 알아채겠는가.

> 이벤트 200개 중 17개가 5시즌 × 100시드 동안 한 번도 안 나옴

이 한 줄이 몇 주치 작업을 구제한다.

문제를 발견하면 **그 시드로 다시 돌려** 같은 상황을 재현한다(1.2).
디버깅이 추측이 아니라 확인이 된다.

#### 이벤트 전용 도구가 아니다

같은 하네스로 밸런싱도 한다 — 만족도 곡선, 이탈률, 재정 추이, 인원 미달 빈도.
**이벤트 검증은 그 리포트의 한 섹션**이다. 15장 구현 초안의 "헤드리스 시즌 시뮬레이터"와 같은 것이다.

**요구량이 매우 적다.** 주중이 메뉴 UI이고, 경기가 바둑알이라서.

초상화도 **보류로 내렸다.** 파츠 18장(머리 8 × 얼굴 6 × 안경 4)이면
수백 명을 만들 수 있지만, **그 18장이 지금 필수 아트 전체보다 크다.**
30명을 구분하는 일은 이름이 이미 하고 있고, 초상화가 주는 것은 **정서적 애착**이다 —
있으면 좋지만 없어도 게임이 성립한다. 바둑알과 같은 판단이다.

붙일 때 화면을 다시 만들 필요는 없다. S-03 프로필 패널의 빈 칸을 채우면 된다.

**단, 프로토타입 단계에서는 아무것도 그리지 않는다. 네모와 글씨로 한다.**

**아트가 병목이 되지 않는다.** 경기 화면이 바둑알이므로 엔진만 돌면 화면이 나온다.
도트는 나중에 붙여도 되고, 안 붙여도 게임이 완성된다 (11.3).

> 해상도는 낮추지 않는다. 텍스트 밀도가 필요한 장르라 1920x1080 + Nearest 필터로 간다.
> 상세는 [03-tech.md](03-tech.md).

### 14.1 UI 체계

**데이터 밀집형(FM 계열)으로 확정.** 골격 하나에 스킨 4종을 얹고,
기본값은 **C 새벽**(짙은 남색 + 가로등 주황 — 조기축구의 시간대)이다.
A 클래식 · B 현대 · D 잔디도 설정에서 고를 수 있다.

화면은 트리 14 + 경기 3 + 오버레이 7 = **24개**(+설정 25),
탭까지 세면 구현 단위 **41개**. 섹션은 약 180개다.

> 처음에는 57개였다. **검토 1회차에서 열두 화면의 16탭을 지웠다** —
> 정렬 · 필터 · 집계 · 확대는 탭이 할 일이 아니고,
> 탭은 **다른 질문**에 답할 때만 쓴다. 상세는 [06-screens.md](06-screens.md).

이벤트(13장)는 모달이 아니라 **상태 바 위 드로어**로 나온다.
명단이 가려지지 않아 선택지를 고르는 동안 그 회원의 수치를 계속 볼 수 있다.

**경기 화면(S-M2)도 같은 색 토큰을 쓴다.** 바둑알의 팀 색과 체력 링이
주중 화면의 상태색 체계와 이어진다.

> 골격 · 화면 목록 · 컴포넌트 · 색 토큰 · 상호작용 전체는 [05-ui.md](05-ui.md).

## 15. 구현 범위 (보류 — 기획 완료 후 재작성)

> ⏸ **이 장은 지금 유효하지 않다.**
>
> 구현 단계 구분(M1 / M2 …)은 **기획이 끝난 뒤에** 정하기로 했다.
> 무엇이 존재하는지 모르는 상태에서 무엇을 먼저 만들지는 정할 수 없기 때문이다.
>
> 아래는 초안 시점의 판단이며, **참고용으로만 남겨둔다.**
> 그때는 회원 모델이 "스탯 4~5개 + 성향 3종"이었고 지금은 능력 5 + 기질 6 + 프로필로
> 바뀌었다. 요소는 76개에서 **82개**로 늘었고, 미설계는 45개에서 **18개**로 줄었다.
> 이 목록은 다시 짜야 한다.
>
> 진행 상황은 [02-scope.md](02-scope.md) 와 [04-elements.md](04-elements.md) 를 볼 것.

### 검증하려는 것 (여전히 유효)

> **"세 축 사이에서 조율하는 게 재미있는가?"**

재미없으면 일찍 멈춘다. 재미있으면 그때부터 진짜 게임을 만든다.
**프로토타입으로 먼저 확인한다는 원칙 자체는 유지한다.** 언제·어떤 범위로 할지만 미정이다.

### 예산 (초안 시점 값 — 재확인 필요)

3개월 / 약 100시간 (주 5~10시간 기준)

### 넣는 것 (초안 — 무효)

- 회원 12~16명, 스탯 4~5개 + **성향 3종**
- 4~8주 분량 시즌
- 만족도 시스템 (성향별 가중치 포함)
- **궁합: 단순화형** — 전체 행렬 대신 명시적 관계 몇 쌍(친한 3쌍 / 나쁜 3쌍)
- 참석 확률 판정 + 일요일 아침 공개
- 출전 라인업 구성
- **경기 수 결정 + 최소 재정** (회비 수입 − 경기당비용 × 경기 수 − 인당비용 × 인원)
- 경기: **텍스트 로그만**
- 유입: **공개 모집 1채널만** (평판 비례 지원자)
- 이탈: 만족도 바닥 + 자연 이탈
- 이벤트 20개
- 인원 미달 → 경기 취소

### 넣지 않는 것 (초안 — 무효)

- **규칙 시스템** — 매력적이지만 M1 가설 검증에 필수는 아님
- **지인 소개 · 영입 권유 · 용병**
- **라이벌 팀 · 분열**
- 전체 궁합 행렬, 궁합 발견 시스템
- 회비 방식 선택 (M1은 월 정액 고정)
- 경기 종류 3종 (M1은 1종)
- 핸드폰 경기 화면
- 도트 그래픽 전부 (네모와 글씨)
- 예쁜 UI (못생겨도 된다)
- 구장 예약, 상대팀 섭외
- 사운드

**재정과 경기 수를 넣었던 이유 (여전히 유효한 통찰):** 이게 없으면 "골고루 뛰게 하기"의
비용이 사라져 축들이 충돌하지 않는다. 딜레마가 성립하려면 최소한의 재정이 필요하다.
구현 범위를 다시 짤 때도 이 조건은 지켜야 한다.

### 진행 순서 (초안 — 구현 시점에 재작성)

아래 순서 자체보다 **"1~3단계에 화면이 없다"는 원칙**이 핵심이다. 그건 유지한다.

| # | 작업 | 비고 |
|---|---|---|
| 0 | **취재** | 용병 참여 2~3회. **1~3단계와 병행** (크리티컬 패스에 두지 말 것) |
| 1 | 회원 데이터 모델 + 성향 + 만족도 계산 | 순수 GDScript. UI 없음 |
| 2 | 헤드리스 시즌 시뮬레이터 | 콘솔 출력만. 100시즌 돌려 밸런싱 |
| 3 | 참석 판정 + 라인업 + 재정 로직 | 여전히 UI 없음 |
| 4 | 최소 UI | 이제야 Godot 노드 등장. **`ItemList` / `Button` / `RichTextLabel` 3종만. 커스텀 Theme·애니메이션 금지** |
| 5 | 이벤트 시스템 + 20개 작성 | |
| 6 | 경기 텍스트 로그 | |
| 7 | **직접 플레이. 재미 판정** | 여기가 진짜 목적지 |

1~3단계에 화면이 없는 게 핵심이다. 매니지먼트 게임은 **UI 없이도 작동 가능한 상태**를
먼저 만드는 쪽이 훨씬 빠르고, 밸런싱을 눈이 아니라 데이터로 하게 된다.

UI 단계는 예산의 30~40%를 먹을 수 있는 구간이다. 노드 3종 제한이 가드레일이다.

## D1. 시작 상황 — 인수(재건)

창단이 아니라 **망가진 팀을 떠맡는다.**

> 전임 총무가 잠수를 탔다. 회원 명단에 14명이 있는데 최근 3주 평균 출석은 9명.
> 회비 통장은 비어 있고, 에이스는 옆 동네 팀에서 연락받았다는 소문이 돈다.

창단을 택하지 않은 이유: 회원이 3명이면 **만족도 · 궁합 · 라인업이 전부 놀게 된다.**
이 게임의 재미는 사람들 사이에서 나오는데 사람이 없으면 아무 일도 안 일어난다.
튜토리얼 구간이 길고 지루해진다.

인수는 첫 주부터 인원 미달 위기를 체감시키고, 관계가 이미 깔려 있어 이벤트가 바로 돈다.
"내가 만든 팀"이 아니라 "떠맡은 팀"이라는 게 코어 판타지(권한 없는 사람)와도 맞는다.

## D2. 리그를 게이트 뒤에 둔다

초반 1~2년차는 **친선경기 위주**. 이후 요건을 갖추면 리그에 진입한다.

이 구조가 만들어내는 것:

- **규모 축에 강력한 보상.** 기존에는 "지원자가 많아져 골라 받을 수 있음"뿐이라 약했다
- **승리 축이 잠겼다 열린다.** 축의 무게중심이 시간에 따라 이동한다
  - 1막 (친선기) — 화목 · 규모가 주도. 승부형 회원은 답답해함
  - 2막 (리그기) — 승리가 본격화. 출전 경쟁이 심해져 출전형이 힘들어짐
- **1막의 목표가 명확해진다.** "목표를 게임이 안 정해줌 = 방향 상실" 리스크가
  초반에는 해소된다. 리그 진입 후에 자유로워지는 구조

### 참가 요건 후보 (미확정)

요건이 여러 시스템을 동시에 요구하게 잡으면 1막이 알차진다.

| 요건 | 건드리는 시스템 |
|---|---|
| 등록 선수 최소 인원 | 유입 채널 |
| 연회비 · 등록비 | 재정 (목돈) |
| 통일 유니폼 | 가입 일시금. 전원분은 큰 지출 |
| 홈 구장 정기 대관 | 구장 예약 |
| 팀 존속 기간 | **시간 — 돈으로 못 산다** |

마지막 항목이 있으면 부자 플레이어도 시간은 못 사서 1막을 건너뛸 수 없다.

## D3~D4. 52주 연중 + 계절

**비시즌은 없다.** 겨울에도 구장을 빌려 연중 돌아간다.

> **실내 구장은 기획에서 뺀다.** 전부 야외 기준으로 간다.
> 경기 규격이 두 벌 필요해지는 걸 피한다.

계절은 배경이 아니라 **시스템 입력**이다. 이게 52주가 단조롭지 않은 이유다 —
매주 같은 판단의 반복이 아니라 계절마다 압력의 성격이 바뀐다.

| 계절 | 구장 예약 | 참석률 | 부상 | 주된 압력 |
|---|---|---|---|---|
| 봄 | **경쟁 심함** | 높음 | 낮음 | 자리 확보 |
| 여름 | 보통 | 중간 (더위) | 낮음 | 장마 취소, 체력 소모 |
| 가을 | **경쟁 심함** | 높음 | 낮음 | 자리 확보 |
| 겨울 | **쉬움** | **낮음** | 약간 높음 | 사람 끌어내기 |

핵심은 **봄가을과 겨울이 정확히 뒤집혀 있다는 것**이다.

> 봄가을 — **사람은 나오는데 자리가 없다**
> 겨울 — **자리는 있는데 사람이 안 나온다**

같은 "구장 예약" 행동이 계절마다 정반대 문제가 된다. 겨울에 예약이 쉬운 게
공짜 이득이 아닌 이유는, 정작 그 자리를 채울 사람이 안 모이기 때문이다.

겨울 부상 위험은 딱딱한 그라운드와 근육 경직 때문이며, 실내 선택지가 없으므로
**회피 수단이 없는 상수 압력**이다. 대응은 출전 로테이션과 경기 수 조절뿐.

### 부상 시스템의 목적

부상은 지금까지 데이터 필드로만 있었는데 여기서 역할이 생긴다.
그리고 이 게임의 반복되는 문법과 맞는다.

> **단기 처방이 장기 병을 키운다.**

겨울에 인원을 맞추겠다고 무리하게 경기를 잡으면 **봄에 부상자가 쌓인다.**
정작 좋은 계절에 전력이 빈다. 용병(인원 미달을 돈으로 때우다 근본 문제가 곪음)과
같은 구조다.

부상은 나이와도 엮인다. 노장은 회복이 느리고, 톤 가이드라인의 "사용함" 목록에
이미 **무릎**이 있다.

## D5. 상대팀 성격 (방향만)

같은 상대와 반복해서 만나므로 팀마다 성격을 주면 경기와 이벤트가 풍부해진다.

| 팀 성격 | 경기에서 | 파생 이벤트 |
|---|---|---|
| 거친 팀 | 부상 위험 ↑ | 시비, 회원들이 붙기 싫어함 |
| 노장 팀 | 전반은 강한데 후반에 무너짐 | 뒤풀이가 좋다 |
| 젊은 팀 | 체력 압도 | 우리 노장들 자존심 |
| 매너 좋은 팀 | 인원 부족 시 배려 | 용병 빌려주기, 친선 잡기 쉬움 |

라이벌 팀(분열로 생긴)이 이 안에 섞인다. 구현은 뒤로 미루더라도 자리는 지금 만들어둔다.

## D6. 종목 — 11인제 축구 (풋살 기각)

풋살(5인제)을 대안으로 검토했으나 축구로 확정. 근거를 남긴다.

| 기준 | 축구 (11인제) | 풋살 (5인제) |
|---|---|---|
| 최소 인원 | 11명 (7명 미만 몰수) | 5명 |
| 참석률 50% 시 필요 명단 | **22명+** | 10명+ |
| 한 명 결석의 무게 | 1/11 | 1/5 |
| 미달 발생 빈도 | **높음** | 낮음 |
| 궁합 쌍 (명단 30명) | 435쌍 | — |
| 개발 비용 | 높음 | 낮음 |

### 기각 사유

**1. 코어 루프가 축구를 전제로 한다.** 이 게임의 심장은 "일요일 아침에 몇 명 나오는가"다.
5명만 있으면 되는 종목에서는 인원 미달이 잘 안 일어나고, 용병 · 몰수 · 명단 관리가
전부 헐거워진다.

**2. 소재의 문화적 무게.** "조기축구"는 한국에서 그 자체로 밈이다 — 새벽, 아저씨, 회비,
단톡방, 뒤풀이, 해장국. 단어 하나에 이미지가 통째로 딸려온다. 풋살은 더 젊고 캐주얼하고
무색무취하다. **"니치지만 대체재가 없다"는 강점이 여기서 나온다.**

풋살로 바꾸면 구체적으로 잃는 것:

- **"조기"** — 새벽에 나가는 고통. 풋살은 저녁에 하는 경우가 많음
- **아트 전략** — "중년 남성이라 머리숱과 뱃살만으로 구분된다"는 유머가 통째로 사라짐
- **연령대** — 무릎, 노화, 창단 멤버 3년차 같은 서사가 젊은 층에서는 약함

**3. 계절 메커닉이 무의미해진다.** 풋살은 실내가 기본이라 계절 영향이 거의 없다.

### 다만 풋살 검토가 남긴 유효한 지적: 명단이 30명이면 너무 많다

로스터 규모가 **장르를 바꾼다.**

| 명단 | 플레이어 체험 | 장르 |
|---|---|---|
| 30명 | 절반은 이름만 아는 데이터 | 관리 게임 (FM 계열) |
| 12~20명 | 전원을 기억하고 각자의 사연을 앎 | **캐릭터 드라마** |

"최대 작업량은 코드가 아니라 글"인 게임이라면 작은 쪽이 유리하다.
궁합 쌍도 12명 66쌍 / 30명 435쌍으로, 후자는 플레이어가 파악 불가능하고 작성도 불가능하다.

→ **명단을 작게 유지한다** (상세는 다음 항목 "인원 규모"에서).

### 파생: 규모 축의 숨은 비용

규모를 키우면 **캐릭터 개별성을 잃는다.** 30명이 되면 플레이어도 다 기억하지 못한다.
"많은 회원을 가진 팀"의 대가가 친밀함의 상실이다.

지금까지 규모 축의 비용은 벤치 불만뿐이었는데, 이게 더 아픈 대가일 수 있다.
그리고 플레이어가 그 변화를 체감하는 것 자체가 콘텐츠가 된다.

## D7. 인원 규모

| 항목 | 값 |
|---|---|
| 시작 인원 | **9명** (본인 제외) |
| 대략적 범위 | 11 ~ 30명 |
| 하드 캡 | **없음** |

### 시작 9명이 튜토리얼 훅이다

본인 포함 10명 → **11명에서 한 명 모자람** → 첫 경기를 아예 못 뛴다.

튜토리얼 목표가 저절로 생긴다: *"일단 한 명이라도 더 구해라."*
설명문 없이 게임이 뭘 하는 건지 알려주고, 실패 조건(인원 미달)을 첫 주에 체감시킨다.

### 상한을 두지 않는 이유

하드 캡이 없어도 자연 상한이 작동한다.

- 사람이 늘면 인당 비용이 늘어 재정 압박
- 벤치가 늘어 만족도 하락 → 저절로 이탈
- 캐릭터 개별성 상실 (D6)

셀프 리미팅이라 인위적 제한이 불필요하다. 궁합도 전체 행렬이 아니라 명시적 관계만
쓰기로 해서 30명이 넘어도 데이터가 폭발하지 않는다.

## D8. 포지션 — 적성 매칭 방식

**GK / DF / MF / FW** 4종. 단, *엄격하게 채워야 하는 슬롯*이 아니라 **적성 매칭**으로 다룬다.

조기축구의 현실은 이렇다.

> "오늘 수비 할 사람이 없네. 형님이 좀 봐주세요."

작동 방식:

- 포메이션이 자리를 요구한다 (4-4-2 → GK 1 / DF 4 / MF 4 / FW 2)
- 회원마다 포지션 적성이 있다 (**주포지션 / 가능 / 못함**)
- **적성 없는 자리에 세우면** → 팀 성능 하락 + **그 사람 만족도 하락**

"자리를 못 채워서 경기 못 함"이 아니라 "억지로 채웠는데 삐걱거림"이 된다.
실패가 벽이 아니라 비용이라 게임이 막히지 않는다.

### GK가 병목이다

명단 14명 중 GK 적성자가 1명이면 **그 사람 결석 = 매주 위기**다.

- GK 없으면 필드 플레이어가 억지로 서고, 그 사람 만족도가 크게 깎임
- GK 1명 의존도가 극단적. 결혼하거나 이사 가면 팀이 휘청
- 영입 시장에서 GK는 희소재. **실력이 떨어져도 데려온다**

"GK 한 명 더 확보"라는 명확한 중기 목표가 생긴다.
포지션이 단순한 라인업 제약이 아니라 **영입 전략을 규정**한다.

### 포메이션

**초기 구현은 4-4-2 고정.** 포메이션 선택은 나중에.

포메이션 선택은 "정교한 전술 지시"에 가까워 컨셉과 충돌한다
(*주제는 전술이 아니라 오합지졸을 굴러가게 만들기*). 라인업 UI도 훨씬 단순해진다.

## D9. 플레이어의 경기 참여 (미정)

플레이어 본인이 명단에 포함되는 건 확정. **경기에 뛰는지는 미정.**

| | 뛴다 | 안 뛴다 |
|---|---|---|
| 정체성 | 총무 (같이 뛰는 사람) | 감독 (관리자) |
| 파생 | **자기희생 딜레마** — 내가 빠지면 남이 한 명 더 뛴다 | 없음 |
| 장기 | 플레이어도 늙는다. 몇 년 뒤 자기가 벤치 후보 | 없음 |
| 단순함 | 낮음 | **높음** |

권장: **뛰는 쪽.** 자기 출전 시간도 배분 대상이 되는 게 주제와 맞는다.
"권한 없는 사람"이 자기 몫까지 양보하는 구조.

## D10~D13. 회원 데이터 모델

**본문 2장으로 이관 완료.** 상세는 거기를 볼 것.

| 결정 | 위치 |
|---|---|
| 3층 분리 (능력 / 기질 / 프로필) | 2.1 |
| 능력 5 + 나이 곡선 | 2.2 |
| 기질 6 | 2.3 |
| 조합이 성격을 만든다 | 2.4 |
| 포지션 적성 | 2.5 |
| 만족도 (기질이 가중치) | 2.6 |
| 프로필 (직업 · 거주지 · 가족 · 나이) | 2.7 |
| 표시 방식 (수치는 내부, 문장으로 요약) | 2.8 |

### 폐기된 안

- **성향 3종 분류 (승부형 / 출전형 / 친목형)** — 라벨이 캐릭터를 뭉갠다.
  경계에 있는 사람이 대부분인데 3칸으로는 안 담긴다. 수치 조합으로 대체.
- **자기표현 (별도 기질)** — 참을성과 겹쳐 참을성 하나로 통합.
  낮으면 터지고 높으면 조용히 삭인다.
- **출전 욕심** — 승부욕과 혼동되어 **자존심**으로 개명.
