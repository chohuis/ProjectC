# 기획서 PDF

`docs/` 여덟 문서를 **읽는 순서로 다시 엮은 것**이다.
화면 하나하나의 스크린샷과 섹션 명세는 [../screens/](../screens/) 화면설계서에 있다.

```
.\build.ps1              # ProjectC_기획서.pdf 생성
.\build.ps1 -KeepHtml    # 합쳐진 plan.html 을 남긴다
```

## 조각

| 파일 | 담는 것 |
|---|---|
| `src/g1.html` | CSS + 표지 + **0. 무엇을 만드는가** |
| `src/g2.html` | 1. 세계 · 2. 회원 |
| `src/g3.html` | 3. 플레이어 · 4. 구단 |
| `src/g4.html` | 5. 규칙과 제재 · 6. 재정 |
| `src/g5.html` | 7. 경기 · 8. 이벤트 |
| `src/g6.html` | **9. UI 구성** · 10. 진행 현황 |

조각을 나눈 이유는 편집 단위를 작게 두기 위해서다.
한 장을 고치려면 해당 조각만 열면 된다.

## 스타일

CSS는 **화면설계서(`../screens/src/p1.html`)에서 가져와 복제한 것**이다.
두 문서가 같은 시각 언어를 쓰되 빌드는 독립이다 —
한쪽을 고쳐도 다른 쪽이 안 깨진다.

`.skel`(골격 다이어그램) · `.axis`(세 축) · `.loop`(주간 루프) · `.st`(상태 칩)은
기획서 전용으로 추가했다.

## 두 문서의 역할

| | 기획서 | 화면설계서 |
|---|---|---|
| 답하는 질문 | **무엇을 만드는가** | **어떻게 보이는가** |
| 분량 | 23쪽 | 39쪽 |
| 스크린샷 | 없음 — 골격 다이어그램만 | **12장** |
| 읽는 사람 | 처음 보는 사람 | 화면을 구현할 사람 |

**기획서를 먼저 읽고 화면설계서로 내려간다.**
