5규칙과 제재GDD 7장

규칙을 만드는 것이 플레이어의 유일한 실질 권한이다. 그리고 규칙은 회원을 통제하는 도구인 동시에 플레이어를 통제한다 — 권한 없는 사람이 권한을 만드는 방법은 자기를 묶는 것이기 때문이다.

5.1규칙 8종

굵은 값이 시작값이다 — 전임이 남겨놓고 아무도 안 지키는 상태.

규칙기준값 (약 → 강)반발하는 쪽
사전 통보없음 / 1일 / 2일 / 3일 전여유 없는 직업 — 주말 근무 · 교대
무단결석없음 / 5회 / 3회 / 2회참석률 낮은 사람
지각없음 / 15분 / 10분 / 5분이동 시간 긴 사람
회비 미납없음 / 6개월 / 3개월 / 2개월여유 없는 직업
출전 배분없음 / 최소 1쿼터 / 2쿼터승부욕 높은 주전
회식 참석자유 / 권장 / 의무친화력 낮음 · 자녀 있음
당번없음 / 순번제전원 소폭 — 좋아하는 사람이 없다
매너없음 / 퇴장만 / 경고 2회+승부욕 높음 · 참을성 낮음
규칙에는 반드시 반발이 따른다. 무단 불참 벌금을 세우면 성실한 사람은 좋아하고 바쁜 사람은 싫어한다. 영향력 높은 회원이 반대편에 있으면 통과 자체가 어렵다 — 그 사람의 동의를 미리 얻는 것이 규칙 제정의 실질적 절차가 된다.

5.2제재 7종 — 비용이 어디로 가는가

같은 위반에 어떤 제재를 붙이느냐가 그 비용을 누가 내는지를 정한다. 이것이 규칙 설계를 선택으로 만든다.

제재재정본인팀 · 남
구두 경고—−1—
단톡방 공개—자존심 비례분위기 − · 영향력으로 번진다
벌금수입 +−3—
잡무 부담—−4당번 해소 +
쿼터 삭감—−8전력 −
결장 1경기—−14전력 −−
제명회비 −—인원 − · 성실한 회원 + · 친한 회원 −

출전 제재가 벌금의 서너 배인 것은 자의적인 값이 아니다 — 출전 시간이 만족도의 최대 입력이라고 정했으므로 그래야 앞뒤가 맞는다. 그리고 결장은 팀도 같이 손해라서 "이 사람을 벌하면 이번 주에 우리가 진다"는 판단이 매번 생긴다.

단톡방 공개는 돈이 안 드는데 제일 위험하다. 재정 0 · 전력 0이라 남용하기 쉬운데, 자존심에 비례해 깎이고 영향력을 타고 번진다.

잡무 부담이 벌금 함정을 피하는 유일한 길이다. 같은 무게인데 재정에 안 잡힌다 — 돈을 안 받는 대신 감정을 받는 셈이고, 누군가의 벌이 남의 이득이 되는 유일한 제재다.

5.3사다리 — 또 어기면 한 단 오른다

구두 경고 → 단톡방 공개 → 벌금 / 잡무 → 쿼터 삭감 → 결장 → 제명

플레이어가 정하는 것은 "몇 단에서 시작하는가"다.

지각 규칙을1차2차3차4차
경고에서 시작경고공개벌금쿼터 삭감
벌금에서 시작벌금쿼터 삭감결장— (상한)

엄격함이 기준값만이 아니라 시작 단으로도 조절된다. 매너만 사다리 밖에서 시작한다 — 상대팀 관계가 걸려 있어 우리 안에서 끝나는 문제가 아니다. 회비 미납에는 벌금이 없다 — 돈이 없어 못 낸 사람에게 돈을 더 물리면 회수도 안 되고 그냥 나간다.

5.4벌금의 함정

벌금 수입 / 총 수입  ≥ 15%   →  전원 만족도 −2 / 월
                    ≥ 25%   →  전원 만족도 −5 / 월 + "돈 뜯긴다" 이벤트

규칙 세 개를 벌금으로 걸면 자연히 이 구간에 들어간다. 회비 30,000 × 12명 = 360,000에 벌금 54,000이면 15%인데, 지각 5,000짜리가 한 달에 열 번이면 도달한다 — 조기축구에서 어려운 숫자가 아니다.

벌금은 제재인데 재정에 도움이 된다. 그래서 규칙을 엄격하게 유지할 재정적 유인이 생기고, 그것이 분위기를 망친다. 돈이 되는 규칙일수록 위험하다.

6.1기준 금액 — 모든 수치가 여기 붙는다

항목기준값비고

회식인당 15,000~20,000
유니폼인당 30,000~40,000가입 일시금 · 적립 목표
벌금 단위5,000 / 10,000 / 20,000회비의 ⅙ · ⅓ · ⅔
회비 하나로는 한 경기가 안 돈다. 12명 × 30,000 = 360,000인데 월 4경기면 대관료만 180,000~240,000이고 소모품과 회식을 얹으면 적자에 가깝다.

이것이 의도한 출발점이다 — 용병 참가비와 스폰서가 그 틈을 메우고, 둘 다 대가가 붙어 있다. 용병은 "우리 팀으로 이긴 게 맞나"를 만들고 스폰서는 출전 압력을 데려온다.

6.2공동 부담이냐 사용자 부담이냐 — 중립이 없다

회비 징수 방식과 회식 갹출 방식이 정확히 같은 모양이다.

회비   월 정액 ↔ 경기당    →  자주 나오는 사람 ↔ 가끔 나오는 사람
회식   회비에서 ↔ 각출     →  안 오는 사람     ↔ 자주 오는 사람

공동 부담으로 돌리면 안 쓰는 사람이 화내고, 사용자 부담으로 돌리면 많이 쓰는 사람이 화낸다. 그래서 둘 다 규칙 개정과 같은 화면에서 바꾼다 — 되돌릴 수 없고 전원에게 영향이 가며 누가 반발할지 미리 보여준다.

회식 주기 × 방식회비에서그날 각출
매 경기 후재정 파탄 — 월 4회 × 200,000참석률 하락 — 매주 2만원
월 1회감당 가능무난
안 함재정 여유 · 궁합이 안 오른다—

"로테이션 팀은 회식으로 메울 수 있다"에 가격표가 붙는다 — 고르게 뛰게 하려면 회식을 자주 해야 하고, 자주 하면 재정이 죽거나 사람이 안 온다.

6.3스폰서 — 돈을 받으면 권한이 더 줄어든다

후원자는 출전 압력을 데려온다. 그리고 총 수입이 커지면 벌금 비중이 낮아지므로 벌금 함정을 피하려다 다른 함정에 들어가는 구조가 된다.

구분 8종 — 수입: 회비 · 벌금 · 스폰서 · 용병 참가비 / 지출: 대관 · 소모품 · 회식 · 장비.
소모품(공 · 조끼 · 마커)은 자동 구매다 — 결정이 없는 항목에 관리 부담을 만들지 않는다.
