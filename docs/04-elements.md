# 04. 요소 체크리스트

기획해야 할 요소를 전부 나열하고 하나씩 지워나간다.
**"어디까지 정했는지"를 이 문서 하나로 파악한다.**

결론은 [01-gdd.md](01-gdd.md) 본문에 쓰고, 여기에는 상태만 표시한다.
결정 로그(D1~D13)와 구분하려고 요소는 `E` 접두어를 쓴다.
