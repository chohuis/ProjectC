# 06. 화면 상세 명세

[05-ui.md](05-ui.md)가 "어떤 화면이 있는가"라면, 이 문서는 **"각 탭이 어떤 섹션으로 나뉘고 거기에 무엇이 들어가는가"** 다.
하나씩 잡아가는 작업 큐로 쓴다.

## 범례

| 표시 | 뜻 |
|---|---|
| ✅ | 구성 확정. 넣을 정보가 다 정해짐 |
| 🔶 | 섹션은 있는데 내용이 덜 정해짐 |
| 🔢 | 구성은 확정, **수치만** 미정 |
| ❌ | 미착수 |

## S-01 이번 주

기본 진입 화면. **이번 주에 무엇이 잘못되어 있는지**를 보여준다.

#### 탭 1 · 할 일 ✅

| 섹션 | 들어가는 정보 | 출처 |
|---|---|---|
| 요약 스트립 5칸 | ① 다음 경기 `D-n` + 날짜·시각·상대 ② 구장명 + 기온 ③ 참석 `9/11` ④ 무응답 수 ⑤ 잔액 | 11장 · 9장 |
| 회원 표 11열 | 이름 · 나이 · POS · **이번 주 참석** · 지난 경기 출전(쿼터) · 4주 누적 · **최근 8주 폼** · 만족도 · 기술 · 체력 · 비고 | 2장 |
| 비고 열 생성 규칙 | 시스템이 판정한 한 줄 — `12주 개근` `이탈 위험 5/5` `경고 2회` `체력 하락` `3경기 연속 득점` | 2.12 · 7장 |

**정렬 기본값** — 등번호순. 헤더 클릭으로 변경, 화면을 나가면 초기화된다.

#### 탭 2 · 참석 현황 ✅

| 섹션 | 들어가는 정보 |
|---|---|
| 요약 스트립 | 탭 1과 동일 (스트립은 탭이 바뀌어도 유지) |
| 4구획 그룹 목록 | **참석 / 미정 / 불참 / 무응답** 으로 묶어 표시. 각 구획에 인원수 + 이름 목록 |
| 각 회원 행 | 이름 · POS · 회신 시각 · **회신 문구**(단톡방에서 가져옴) · 지난 경기 출전 |
| 부족 계산 박스 | 필요 11 − 참석 n = 부족 m · 포지션별 공백(`GK 0명 부족 · DF 1명 부족`) · 용병 응답 수 |

#### 탭 3 · 지난 경기 ✅

| 섹션 | 들어가는 정보 |
|---|---|
| 결과 카드 | 스코어 · 승패 · 상대 · 구장 · 날짜 |
| 득점 · 사건 | 시간순 주요 이벤트 5~8줄 (S-M3의 축약) |
| 개인 평점 표 | 이름 · 출전 쿼터 · 평점 · **만족도 변화** · 한 줄 비고 |
| 여파 | 이 경기로 생긴 것 — 경고 누적 · 부상 · 칭호 획득 · 이탈 위험 변화 |

#### 탭 4 · 상대 정보 ✅

| 섹션 | 들어가는 정보 |
|---|---|
| 상대 카드 | 팀명 · 창단 연차 · 회원 수 · 전력 평가 · 우리와의 관계 |
| 성향 4축 | 거칠기 · 체력 · 조직력 · **매너** (바 형태) |
| 상대 전적 | 통산 `n승 n무 n패` · 최근 3경기 결과 |
| 알려진 것 | 텍스트 2~4줄. 과거 사건에서 생성 — `태클이 거칠고 항의가 잦다` `박현범과 언쟁이 있었다` |
| 주의 | 우리 쪽 위험 요소 — `박현범 경고 2회 누적 · 상대 매너 34` |

## S-02 회원 명단

전 회원을 한 화면에. **30명이 스크롤 없이 들어가는 것**이 설계 조건.

#### 공통 · 표 13열 ✅

`#` · 이름 · 나이 · POS · 이번 주 · 4주 누적 · **최근 8주 폼** · 만족도 · 기술 · 체력 · 센스 · **직업** · 칭호·비고

> 능력은 **기술 · 체력 · 센스 셋만** 낸다. 다섯 개를 다 내면 읽히지 않는다.
> 피지컬 · 스피드는 S-03에서 본다.

| 탭 | 구성 | 상태 |
|---|---|---|
| 1 · 전체 | 등번호순. 위 13열 그대로 | ✅ |
| 2 · 포지션별 | **GK / DF / MF / FW 4구획**으로 나누고 각 구획 안에서 능력순. 구획 헤더에 인원수 + 평균 나이. **공백 포지션 경고** | ✅ |
| 3 · 출전순 | 4주 누적 쿼터 내림차순. **팀 평균선 표시** — 평균 아래는 옅게 | ✅ |
| 4 · 만족도순 | 만족도 오름차순(낮은 사람 위). 이탈 위험 단계 열 추가 | ✅ |
| 5 · 가입순 | 가입일 오름차순. **재적 기간** 열 추가. 창단 멤버 표식 | ✅ |

**모든 탭이 같은 데이터의 다른 정렬이다.** 새 정보를 넣지 않는다.

## S-03 회원 상세

3분할. **좌 프로필 · 중 수치 · 우 경고와 행동.**

#### 공통 · 좌측 프로필 패널 `w196` ✅

탭이 바뀌어도 유지된다.

| 항목 | 내용 |
|---|---|
| 초상 | 파츠 조합 (GDD 14장). 프로토타입 단계에서는 자리만 |
| 기본 | 이름 · 나이 · 소화 포지션(주/부) · 등번호 |
| 생활 | 가입일 + 재적 개월 · **직업 + 근무 형태** · 거주지 + 이동 시간 · 혼인/자녀 · 유입 경로 |
| 회비 | 납부 상태 한 줄 (`2개월 미납`) |
| 상태 칩 | `출전 불만 5/5` `회비 미납` `읽씹` `신입` `창단 멤버` `부상 중` 등 |

#### 탭 1 · 개요 ✅

| 섹션 | 들어가는 정보 |
|---|---|
| 능력 5 | 기술 · 체력 · 피지컬 · 스피드 · 센스 — 바 + 수치. **파랑 계열** |
| 기질 6 | 성실성 · 참을성 · 사교성 · 승부욕 · 협조성 · 자기관리 — **보라 계열** |
| 출전 요약 | 최근 8주 폼 · 총 경기 수 · 총 쿼터 · **팀 평균 대비** |
| 궁합 요약 | `+n` 목록 / `-n` 목록 + 사유 한 줄 |
| 경고 박스 | 이탈 위험 단계 · 회비 미납 · 부상 · 경고 누적 |
| 만족도 | 큰 숫자 + 지난주 대비 변화 |
| 할 수 있는 것 | 행동 목록 + **소모 표시**(`행동 1`) — 따로 만나기 · 선발 확정 · 회비 유예 · 방출 · 탈퇴 수리 |

#### 탭 2 · 능력 🔶

| 섹션 | 들어가는 정보 | 상태 |
|---|---|---|
| 능력 5 상세 | 큰 바 + 수치 + **최근 6개월 변화 화살표** | ✅ |
| 기질 6 상세 | 같은 형식. 기질은 잘 안 변한다는 것을 표시 | ✅ |
| 나이 곡선 | 나이별 능력 곡선 위 **현재 위치 마커**. 앞으로 오를지 내릴지 | 🔶 곡선 미정 |
| 포지션 적합도 | 소화 가능 포지션별 적합도 — 주 포지션 대비 | 🔶 |
| 관찰 상태 | **신입은 일부 수치가 물음표.** 몇 주 더 봐야 하는지 표시 | ✅ |

#### 탭 3 · 출전 이력 ✅

| 섹션 | 들어가는 정보 |
|---|---|
| 경기별 표 | 날짜 · 상대 · 결과 · **출전 쿼터** · 평점 · 득점/도움 · 비고 |

## S-04 라인업

#### 공통 · 요약 스트립 4칸 ✅

포메이션 + 숙련도 · 배치 가능 인원 · 빈 자리 · 용병 응답 수

#### 탭 1 · 선발 ✅

| 섹션 | 들어가는 정보 |
|---|---|
| 포메이션 필드 | 선택된 포메이션의 11자리. 각 자리에 등번호 + 이름. **빈 자리는 점선 + 물음표** |
| 가용 인원 목록 | 참석 확정자를 POS별로 묶음. 배치 여부 표시 |
| 불참 · 미정 | 이름 + 사유 (`불참 · 무릎` `미정` `무응답`) |
| 용병 응답 | 이름 · 나이 · POS · 단가 · **과거 이력**(`지난달 2회 함께함`) |
| 경고 박스 | 인원 부족 시 — 부족 수 + 취소 경로 안내 |

**제약** — 참석 확정자만 배치 가능. 11명 미만이면 확정 불가([S-M1](#s-m1-경기-전-브리핑)으로 못 넘어감).

#### 탭 2 · 교체 순번 🔶

| 섹션 | 들어가는 정보 | 상태 |
|---|---|---|
| 대기 목록 | 순서대로. 드래그로 순서 변경 | ✅ |
| 각 대기자 정보 | 이름 · POS · 체력 · **출전 희망도** · **거부 확률** | 🔢 확률 산식 미정 |
| 투입 조건 | 자동 투입 기준 — `체력 30% 이하일 때` `실점 시` `후반 시작 시` | 🔶 |

#### 탭 3 · 전술 ✅🔢

| 섹션 | 들어가는 정보 |
|---|---|
| 포메이션 카드 8장 | 미니 필드 + 이름 + 난도 + **숙련도 바**. 선택된 것 강조 |
| 지시 4개 | 수비 라인 · 활동량 · 압박 · 출전 배분 — 각 3단 세그먼트 + **수용률 %** |
| 각 지시 힌트 | 누가 무시할 것 같은지 한 줄 |
| 개인 지시 | 최대 2개. 대상 + 지시 + 수용률 |
| 수용 예측 패널 | 선택 포메이션의 **수용률 분해**(기본/숙련도/요구/변경 직후) · 지시별 따를/반반/무시 인원 · **대표 인물 설명** |
| 이 조합의 예상 | 텍스트 2~3줄 — `후반 20분경 체력 붕괴 가능성 높음` |

> 수치(기본 수용률 · 숙련도 증가폭 · 기질 계수)는 전부 미정. 구성은 [01-gdd.md](01-gdd.md) 11.5 확정.

## S-06 단톡방

#### 공통 · 우측 패널 `w196` ✅

| 섹션 | 들어가는 정보 |
|---|---|
| **읽고 답 안 한 사람** | 이름 + 지속 기간(`3주째` `8주째`). 이 화면의 핵심 |
| 안내 문구 | `읽었다는 것만 안다. 왜 답이 없는지는 직접 만나야 알 수 있다` |
| 참석 집계 | 참석 / 불참 / 미정 / 무응답 4행 |
| 보낼 수 있는 것 | 참석 조사(주 1회 무료) · 재촉(만족도 −) · 공지 · 잡담 |

| 탭 | 본문 구성 | 상태 |
|---|---|---|
| 1 · 전체 | 시간순 전 메시지. 각 행 = 보낸이 · 내용 · **읽음 수 또는 날짜** | ✅ |
| 2 · 공지 | 내가 보낸 공지만. 읽음 수 · 회신 수 · 경과 시간 | ✅ |

#### 바둑알 표기 규약 ✅

| 표기 | 뜻 |
|---|---|
| 파랑 원 + 번호 | 우리 팀. **이름은 우리 팀만** 붙는다 |
| 빨강 원 | 상대 (번호만) |
| 노랑 원 | GK · 양팀 공통 |
| **원 둘레 게이지** | **체력.** 초록(60+) → 노랑(40~60) → 빨강(40 미만) |
| 흰 테두리 | 볼 소유 |
| 노랑 테두리 + `⚠` | 경고 누적 · 주의 |
| 빨강 테두리 | 체력 위험 |
| **주황 테두리 + `✗`** | **지시를 무시하는 중** (11.5) |
| `*` 번호 | 용병 |

**남은 확인** — GK 노랑과 선택색 주황이 소형 표시(3px)에서 구분이 애매하다.

#### 전술 오버레이 (개발·튜닝용) 🔶

| 섹션 | 들어가는 정보 |
|---|---|
| 압박 존 | 상대 압박 범위 음영 |
| 라인 표시 | 지시한 수비 라인 위치 + 실제 위치 |
| 효용 값 | 볼 소유자의 선택지별 점수 (`패스 .72 / 드리블 .48 / 슛 .21`) |
| 틱 정보 | 시드 · 현재 틱 · 0.25x · 한 틱씩 진행 |

**11.2 효용 함수를 튜닝할 때 필수.** 플레이어에게는 옵션으로 열어도 된다.

## S-M3 경기 후

**스코어보다 만족도 변화가 본문이다.**

| 섹션 | 들어가는 정보 | 상태 |
|---|---|---|
| 헤더 | 스코어 · 승/무/패 · 상대 · 구장 · **시즌 통산 갱신** | ✅ |
| 좌 · 경기 기록 | 시간순 전체 이벤트. 득점 · 경고 · 부상 · **교체 거부** · 체력 소진 | ✅ |
| 좌 · 기록 | 점유 · 슛 · 파울 · 주행거리 | ✅🔢 |
| 중 · 개인 평점 표 | 이름 · 출전 쿼터 · 평점 · **만족도 + 변화량** · 비고. 용병은 만족도 없음 | ✅🔢 |
| 우 · 이 경기가 남긴 것 | 긍정/주의 카드 2~4장. **S-13 '남긴 것' 열로 축적된다** | ✅ |
| 우 · 정산 | 대관료 · 용병비 → 잔액 | ✅ |
| 하단 | `하이라이트 다시 보기` / **`다음 주로`** | ✅ |

**결과 판정 5종** (11.5) — 지시를 따랐는지 × 이겼는지로 신뢰가 오르내린다.

| 상황 | 결과 |
|---|---|
| 무시 + 승 | 그 사람 만족도 ↑ · **플레이어 신뢰 ↓** |
| 무시 + 패 | 신뢰 ↑ · 다음 경기 수용률 ↑ |
| 따름 + 승 | 신뢰 ↑↑ · **포메이션 숙련도 +2** |
| 따름 + 패 | 신뢰 ↓ · `"그러게 내 맘대로 할 걸"` 이벤트 가능 |
| 아끼라 했는데 무시 → 부상 | 본인 만족도 ↓↓ · 신뢰 ↑ |

> **이겼는데 잃는 사람이 있다.** 승리가 모두를 만족시키지 않는다는 것이 이 표의 요지.

## 오버레이

### O-1 이벤트 드로어

13장 이벤트 시스템의 **출력이 전부 여기로 흐른다.** 모달이 아니라 상태 바 위로 열린다.

| 상태 | 높이 | 섹션 구성 | 상태 |
|---|---|---|---|
| 없음 | `0` | — | ✅ |
| 알림 | `h30` | 한 줄 + 확인 | ✅ |
| 선택 필요 | `h88` | **구분 라벨**(`［이벤트］ 출전 불만 · 5단계`) + **대사** + **선택지 2~4개** | ✅ |
| 연속 | `h88` | 위와 같음 + 우측에 `2 / 5` | ✅ |

**동시에 일어나는 것** — 대상 회원의 행이 표에서 강조되고, 우측 패널이 그 사람 정보로 바뀐다.

> **모달이 아닌 것이 결정적이다.** 이규민의 탈퇴 선언을 듣는 동안
> 그 사람의 만족도 18 · 기술 62 · 체력 74가 계속 보인다.
