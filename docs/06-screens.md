### 행동 카운터를 두지 않는다

**GDD 10장(E16)이 "행동 개수 제한은 두지 않는다"고 못박았다.**
제약은 포인트가 아니라 **시간대 × 상대의 가용성**이다.

> 포인트 예산은 **나 혼자만의 문제**다. 그런데 실제로는 회원을 만나려면 **그 회원도 시간이 돼야 한다.**
> — GDD 10장

따라서 화면 어디에도 `남은 행동 3` 같은 표기를 두지 않는다.
상태 바에는 **`빈 칸 9`** — 이번 주 21칸 중 아직 안 채운 칸 수만 보여준다.
이건 예산이 아니라 **내 일정의 여백**이다.

행동 옆에도 `행동 1` 같은 소모 표시를 붙이지 않는다.
대신 **"시간이 필요한 행동"** 인지만 표시하고, 실제 제약은 S-05에서 칸을 잡을 때 드러난다.

## S-01 이번 주

기본 진입 화면. **이번 주에 무엇이 잘못되어 있는지**를 보여준다.

> **확정 (검토 1회차)** — 탭 4개 → **3개**. 지난 경기 탭 삭제(S-11 · S-M3와 중복).
> 탭 1은 **상단 할 일 + 하단 표** 분할. 비고 열에서 **내부 수치를 뺐다**.

#### 탭 1 · 이번 주 ✅

| 섹션 | 들어가는 정보 | 출처 |
|---|---|---|
| 요약 스트립 5칸 | ① 다음 경기 `D-n` + 날짜·시각·상대 ② 구장명 + 기온 ③ 참석 `9/11` ④ 무응답 수 ⑤ 잔액 | 11장 · 9장 |
| **할 일 영역** `h~62` | **2열 배치.** 처리할 것 3~4개 + 예정 한 줄. 각 항목에 이동 링크 | 아래 |
| 회원 표 **8열** | 이름 · POS · **이번 주 참석** · **최근 회신** · **상태(얼굴)** · 지난 경기 출전(쿼터) · 4주 누적 · 비고 | 2장 |

**정렬 기본값** — 등번호순. 헤더 클릭으로 변경, 화면을 나가면 초기화된다.

##### 열에서 뺀 것 — S-02와 갈라놓기 위해

원래 11열이었고 S-02 표와 거의 같았다. **회원이 12명이면 두 화면이 사실상 동일**했다.
성격을 갈랐다 — **S-01은 단기(이번 주), S-02는 장기(이 사람이 어떤 사람인가).**

| 뺀 열 | 어디로 |
|---|---|
| 나이 | S-02 · S-03 |
| **기술 · 체력** | **S-04 라인업** — 라인업을 짜는 자리에서 본다 |
| 직업 | S-02 |

**능력 열을 명단에서 빼는 것이 핵심이다.** 능력을 한눈에 정렬할 수 있으면
"잘하는 순서대로 쓰면 되지"가 되고, **출전 배분이라는 이 게임의 핵심 갈등이 죽는다**(00-concept).

겹치는 열은 **이름 · POS · 상태(얼굴)** 정도만 남는다.
얼굴은 남긴다 — **매주 여는 화면에서 감정 신호를 빼면 매번 S-02로 건너가야 한다.**

##### 할 일 영역에 올리는 것 — 확실한 사실만

E69("경고 알림은 옵션으로만. 게임이 대신 찾아주면 관찰의 재미가 죽는다")와 충돌하지 않게
**사무는 알려주고 사람 문제는 안 알려준다.**

| 올린다 | 안 올린다 |
|---|---|
| 인원 n명 부족 → 라인업 | 이규민 이탈 위험 5/5 |
| 구장 미예약 → 구장 | 장우준 불만 누적 |
| 회비 미납 n명 → 재정 | 누구를 만나야 한다 |
| 신규 지원자 n명 → 영입 | 만족도 관련 전부 |
| 예정 한 줄 — 회비 납부일 · 구장 추첨 결과 · 군입대 D-n | |

**판단 기준** — 플레이어가 화면을 다 뒤지면 알 수 있는 사실인가.
그렇다면 올리고, 내부 수치라면 안 올린다.

##### 최근 회신 열 — 말투가 정보다

단톡방 마지막 회신 문구를 **그대로** 싣는다. 만족도 숫자를 뺀 자리를 이 열이 메운다.

| 회신 | 읽히는 것 |
|---|---|
| `"ㄱㄱ"` | 무뚝뚝하지만 온다 |
| `"좀 뛰게 ㅋㅋ"` | **농담 형태의 불만** |
| `"봐서요.."` | 회피 |
| `—` | **무응답. 가장 나쁜 신호** |

얼굴이 참을성으로 가려질 수 있으므로(2.6), **이 열이 얼굴을 교차 검증하는 유일한 수단**이다.
얼굴은 `그저 그럼`인데 회신이 `—`이면 뭔가 잘못된 것이다.

##### 비고 열 — 관찰 가능한 사실만

시스템이 판정한 **결론** 대신 **그 사람이 실제로 한 말이나 남긴 기록**을 쓴다.

| 지금 | 고친 뒤 |
|---|---|
| 이탈 위험 5/5 | **읽씹 3주째** |
| 불만 누적 | **"봐서요.."** — 단톡방 회신 문구 그대로 |
| 출전 부족 | **3주 연속 벤치** |
| 체력 하락 | 창단 멤버 |
| 12주 개근 | 12주 개근 *(유지)* |
| 경고 2회 | 경고 2회 *(유지)* |
| 3경기 연속 득점 | 3경기 연속 득점 *(유지)* |

**"불만 누적" → "봐서요.."** 가 이 변경의 핵심이다.

#### 탭 2 · 참석 현황 ✅

| 섹션 | 들어가는 정보 |
|---|---|
| 요약 스트립 | **탭 1과 다르다** — 참석 `9/11` · 부족 인원 · **포지션 공백** · 용병 응답 |
| 4구획 그룹 목록 | **참석 / 미정 / 불참 / 무응답** 으로 묶어 표시. 각 구획에 인원수 + 이름 목록 |
| 각 회원 행 | POS · 이름 · 회신 시각 · **회신 문구**(단톡방에서 가져옴) |
| 무응답 구획 안내 | `읽기는 읽었다. 왜 답이 없는지는 직접 만나야 안다` |
| 상태 바 | 필요 11 − 참석 n = 부족 m · 용병 공고 응답 수 |

**포지션 공백이 이 탭의 고유 정보다.** `DF 1 · MF 1` —
9명이 모였어도 어느 자리가 비는지는 표 정렬로 안 보인다.
**용병을 어떤 포지션으로 구할지가 여기서 정해진다.**

#### 탭 3 · 상대 정보 ✅

| 섹션 | 들어가는 정보 |
|---|---|
| 상대 카드 | 팀명 · 창단 연차 · 회원 수 · 전력 평가 · 우리와의 관계 |
| 성향 4축 | 거칠기 · 체력 · 조직력 · **매너** (바 형태) |
| 상대 전적 | 통산 `n승 n무 n패` · 최근 3경기 결과 |
| 알려진 것 | 텍스트 2~4줄. 과거 사건에서 생성 — `태클이 거칠고 항의가 잦다` `박현범과 언쟁이 있었다` |
| 주의 | 우리 쪽 위험 요소 — `박현범 경고 2회 누적 · 상대 매너 34` |

> **S-12 팀 상세와 겹치지만 남긴다.** 경기 주에는 매일 보는 정보라 편의 중복이 정당하다.
> 반면 **지난 경기 탭은 뺐다** — S-M3를 방금 본 직후에 또 보게 되고, S-11에도 있다.

## S-02 회원 명단

전 회원을 한 화면에. **30명이 스크롤 없이 들어가는 것**이 설계 조건.

> **확정 (검토 1회차)** — 탭 5개 → **2개.** 만족도를 **숫자에서 얼굴 5단계로** 바꿨다.
> 만족도순 탭은 단계가 5개뿐이라 의미를 잃고, 출전순·가입순은 **헤더 클릭**으로 충분하다.
> 포지션별만 정렬이 아니라 **그룹핑**이라 탭이 남는다.

#### 공통 · 표 10열 ✅

`#` · 이름 · 나이 · POS · **가입** · **통산 출전** · **최근 8주 폼** · **상태(얼굴)** · **직업** · 칭호·비고

##### 능력 열은 없다

기술·체력을 명단에 깔면 **능력순으로 정렬해 베스트11을 짜는 플레이**를 유도한다.
이 게임의 핵심 갈등은 **출전 배분**인데, 능력을 한눈에 줄 세울 수 있으면
"잘하는 순서대로 쓰면 되지"가 되어 그 갈등이 죽는다.

| 능력을 보는 곳 | |
|---|---|
| 라인업 짤 때 | **S-04** |
| 영입 판단 | **S-08** — 면접 전에는 어차피 안 보인다 |
| 개인 파악 | **S-03** — 능력 5 전부 |

> 신입은 능력이 물음표다(2.8). 명단에 능력 열이 있으면 **`?`가 잔뜩 뜨는 것도 문제**다.

##### 대신 들어간 것 — 출전 배분의 판단 재료

| 열 | 왜 |
|---|---|
| **가입** | 재적 기간. 나이 위계·발언권의 근거(2.11) |
| **통산 출전** | **이 사람이 지금까지 몇 쿼터 뛰었나.** 4주 누적만으로는 장기 편중이 안 보인다. 연대기(S-13)로 이어지는 숫자 |
| **직업** | 참석 가능 시간대를 결정한다(2.7). "교대"인 사람이 일요일 아침에 못 나오는 이유 |

##### 상태 열 — 얼굴 5단계

만족도를 **숫자로 보여주지 않는다**(GDD 2.6). `16×16` 도트 아이콘 5종.

| 단계 | 내부 범위 |
|---|---|
| 아주 좋음 | 80~100 |
| 좋음 | 60~79 |
| 그저 그럼 | 40~59 |
| 안 좋음 | 20~39 |
| 많이 안 좋음 | 0~19 |

**참을성이 높으면 실제보다 한 단계 좋게 표시된다.** 나쁜 쪽만 가려진다.
표에서 멀쩡해 보이는 사람이 실제로는 바닥일 수 있다.

**이 화면에서 가려진 사람을 알아내는 단서는 두 개뿐이다** —
`통산 출전`이 재적 기간에 비해 유난히 적거나, `최근 8주 폼`이 비어 있거나.
**말투(최근 회신)는 S-01에 있다.** 두 화면을 다 봐야 확신이 선다.

| 탭 | 구성 | 상태 |
|---|---|---|
| 1 · 전체 | 등번호순. 위 10열 그대로 | ✅ |
| 2 · 포지션별 | **GK / DF / MF / FW 4구획**으로 나누고 각 구획 안에서 통산 출전순. 구획 헤더에 인원수 + 평균 나이. **공백 포지션 경고** | ✅ |

**정렬은 헤더 클릭.** 화면을 나가면 초기화된다.

## S-03 회원 상세

3분할. **좌 프로필 · 중 수치 · 우 경고와 행동.**

> **확정 (검토 1회차)** — 탭 4개 → **3개.**
> "능력" 탭이 개요와 **같은 데이터의 다른 크기**여서 없앴고,
> "출전 이력"을 **이력**으로 넓혀 **개인 연표**를 넣었다.
> 궁합은 **관계 탭에만** 둔다.

#### 공통 · 좌측 프로필 패널 `w196` ✅

탭이 바뀌어도 유지된다.

| 항목 | 내용 |
|---|---|
| 초상 | 파츠 조합 (GDD 14장). ⏸ **보류** — 아래 |
| 기본 | 이름 · 나이 · 소화 포지션(주/부) · 등번호 |
| 생활 | 가입일 + 재적 개월 · **직업 + 근무 형태** · 거주지 + 이동 시간 · 혼인/자녀 · 유입 경로 |
| 회비 | 납부 상태 한 줄 (`2개월 미납`) |
| 상태 칩 | `출전 불만 5/5` `회비 미납` `읽씹` `신입` `창단 멤버` `부상 중` 등 |

##### 초상화는 보류한다 ⏸

**지금 필수 아트의 대부분이 여기 몰려 있다** — 파츠 18장(머리 8 × 얼굴 6 × 안경 4).
UI 아이콘과 만족도 얼굴 5장을 합친 것보다 크다.

| 초상화가 하는 일 | 판단 |
|---|---|
| 30명 구분 | **이름으로 된다** |
| 정서적 애착 | **이게 진짜 이유다** |

**바둑알과 같은 판단을 적용한다** — 없어도 게임이 성립하므로 **선택 항목으로 내린다.**
프로토타입은 자리만 비워두고, 여유가 생기면 붙인다.
붙일 때 화면을 다시 만들 필요는 없다 — 패널의 그 칸만 채우면 된다.

#### 탭 1 · 개요 ✅

| 섹션 | 들어가는 정보 |
|---|---|
| 능력 5 | 기술 · 체력 · 피지컬 · 스피드 · 센스 — 바 + 수치. **파랑 계열** |
| 기질 6 | 성실함 · 친화력 · 승부욕 · **자존심** · 참을성 · **영향력** — **보라 계열** (GDD 2.3) |
| 출전 요약 | 최근 8주 폼 · 총 경기 수 · 총 쿼터 · **팀 평균 대비** |
| **승부욕 ↔ 자존심** | 둘을 나란히 놓고 조합을 **문장으로** 설명 — 넷 중 어느 경우인지 (GDD 2.3) |
| **영향력** | 이 사람의 감정이 누구에게 퍼지는지 한 줄. 상세는 탭 3 |
| 관찰 상태 | **신입은 일부 수치가 물음표.** 몇 주 더 봐야 하는지 표시 (2.8) |
| 경고 박스 | 이탈 위험 단계 · 회비 미납 · 부상 · 경고 누적 · **관계 주의 n건** |
| 상태 | **큰 얼굴 + 단계 이름 + 변화 방향**(`▲` `▼` `—`). **숫자는 안 보인다** |
| 할 수 있는 것 | 따로 만나기 **(시간 필요)** · 선발 확정 · 회비 유예 · 방출 · 탈퇴 수리 |

##### "따로 만나기"를 누르면

**S-05 주간으로 이동하고, 나와 이 사람이 둘 다 되는 칸만 밝게 표시된다.**
칸이 하나도 없으면 이번 주에는 못 만난다 — GDD 10장의
*"달래야 할 형님이 있는데 이번 주엔 시간이 안 맞는다"* 가 이 동선에서 나온다.

> **따로 만난 회원은 예외다.** 만나고 나면 그 사람의 만족도 숫자가 **한 주 동안** 보인다(GDD 2.6).
> 시간대가 겹치는 사람이 매주 한둘뿐이라 **"만나기"에 값이 생긴다.**

##### 능력 변화는 화살표로 충분하다

능력 바 옆에 **최근 6개월 변화 방향**(`▲` `▼` `—`)만 붙인다.
"스피드가 떨어지는 중"은 그것으로 전달된다 — **나이 곡선 그래프까지 그리지 않는다.**
그래프를 그리려면 곡선이 확정돼야 하는데(E22), 확정되어도 **정보량 대비 자리를 너무 먹는다.**

#### 탭 2 · 이력 ✅

**개인 연대기 + 출전 기록.** 원래 "출전 이력"이었는데 **연표를 합쳤다.**

| 섹션 | 들어가는 정보 |
|---|---|
| **개인 연표** | 가입 · 첫 출전 · 첫 골 · 부상 · 칭호 획득 · 언쟁 · 장기 결장 시작. **지금 위치 마커** |
| 경기별 표 | 날짜 · 상대 · 결과 · **출전 쿼터** · 평점 · 득점/도움 · 비고 |
| 누적 통계 | 총 경기 · 총 쿼터 · 평균 평점 · 득점 · 도움 · 경고 |
| 결장 사유 | 불참 / 무응답 / **벤치** / 부상. **벤치가 몇 번인지가 이탈의 직접 원인이다** |

##### 개인 연표를 넣는 이유

**S-13 연대기는 떠난 사람만 나온다.** 그런데 지금 있는 사람의 역사를 볼 곳이 없었다.
심기국이 12년 동안 무엇을 했는지가 "창단 멤버"라는 칭호 한 줄뿐이었다.

**떠나고 나서야 처음 보면 늦다.** 연대기가 감정적으로 작동하려면
그 사람이 있는 동안에도 같은 기록을 볼 수 있어야 한다.

```
2028-11  가입 · 회원 모집 공고
2028-12  첫 출전 (대신초FC전 · 1쿼터)
2029-01  박현범과 언쟁 · 궁합 -3
2029-02  3주 연속 결장
2029-03  회비 2개월 미납        ← 지금
```

**떠날 때 이 연표가 그대로 S-13으로 옮겨간다.** 같은 데이터다.

#### 탭 3 · 관계 🔶

| 섹션 | 들어가는 정보 | 상태 |
|---|---|---|
| 궁합 목록 | 회원별 궁합 수치 + 방향. 양수/음수 분리 | ✅ |
| 사건 로그 | 궁합이 변한 계기 — `지난달 언쟁` `회식에서 친해짐` `같이 골 넣음` | ✅ |
| **영향력 전파** | 이 사람의 감정이 **누구에게 퍼지는지**. 전술 수용률과 직결(11.5) | ✅ |
| 소개 체인 | 누가 데려왔는지 / 누구를 데려왔는지 | ✅ |
| 파벌 표시 | 소개 체인 + 궁합이 뭉치면 파벌로 표시 | 🔶 판정 기준 미정 |

**궁합은 이 탭에만 둔다.** 탭 1에는 경고 박스에 `관계 주의 n건`만 뜬다.

## S-04 라인업

> **확정 (검토 1회차)** — 탭 3개 → **2개.** 교체 순번 탭을 선발로 흡수했다.
> 가용 인원 목록에 **적성 등급 · 체력 · 최근 4주 출전**이 들어간다 — 능력 5개는 깔지 않는다.

#### 공통 · 요약 스트립 4칸 ✅

포메이션 + 숙련도 · 배치 가능 인원 · 빈 자리 · 용병 응답 수

**포메이션과 숙련도는 스트립에만 둔다.** 전술 탭 안에서 중복 표시하지 않는다.

#### 탭 1 · 선발 ✅

| 섹션 | 들어가는 정보 |
|---|---|
| 포메이션 필드 | 선택된 포메이션의 11자리. 각 자리에 등번호 + 이름. **빈 자리는 점선 + 물음표** |
| **가용 인원 목록** | 참석 확정자를 POS별로 묶음. 각 행에 **적성 등급 · 체력 · 최근 4주 출전** |
| **교체 대기** | 선발에 안 들어간 참석자가 **자동으로 내려온다.** 순서는 드래그로 변경 |
| 불참 · 미정 | 이름 + 사유 (`불참 · 무릎` `미정` `무응답`) |
| 용병 응답 | 이름 · 나이 · POS · **참가비**(우리가 받는다) · **과거 이력**(`지난달 2회 함께함`) |
| 경고 박스 | 인원 부족 시 — 부족 수 + 취소 경로 안내 |

**제약** — 참석 확정자만 배치 가능. 11명 미만이면 확정 불가([S-M1](#s-m1-경기-전-브리핑)으로 못 넘어감).

##### 능력 5개를 깔지 않는다

11명분 능력 5개를 나열하면 **S-02에서 뺀 문제가 여기서 재발한다** —
수치로 줄을 세우게 되고 출전 배분 갈등이 죽는다.

배치 판단에 필요한 것은 셋뿐이다.

| 항목 | 답하는 질문 | 출처 |
|---|---|---|
| **적성 등급** | 이 자리에 세울 수 있나 | GDD 2.1 — GK/DF/MF/FW 각 등급 |
| **체력** | 오늘 뛸 수 있나 | 2.1 상태 |
| **최근 4주 출전** | 이 사람 덜 뛰었나 | 2.6 · 11.5 |

**적성은 상대 비교가 아니라 자리 적합도다.** `이정표 — DF:A MF:C`는 줄 세우기가 안 된다.
세부 능력 5개는 **O-5 빠른보기**(이름 hover)로 본다 — 이미 있는 컴포넌트라 추가 비용이 없다.

##### 최근 4주 출전이 없으면 출전 배분 지시가 공허하다

전술 탭에서 출전 배분을 **"고르게"** 로 놓았는데
**화면에서 누가 덜 뛰었는지 안 보이면 그 지시를 실행할 수가 없다.**
이 열은 장식이 아니라 지시와 한 쌍이다.

##### 교체 대기 — 별도 탭을 두지 않는 이유

선발 11명을 배치하면 **남은 참석자가 자동으로 대기열이 된다.**
순서만 드래그하면 되는 일에 탭 하나를 쓸 이유가 없다.

각 대기자 옆에 **출전 희망도**와 **거부 확률**을 한 줄로 표시한다 (🔢 신뢰 산식 확정 후).

> **자동 투입 조건은 만들지 않는다.**
> `체력 30% 이하면 자동 교체` 같은 규칙을 넣으면
> **11.5의 "교체는 거부당할 수 있다"가 무력해진다** — 자동화가 거부를 삼켜버린다.
> 교체는 경기 중에 플레이어가 그때 판단한다.

#### 탭 2 · 전술 ✅🔢

| 섹션 | 들어가는 정보 |
|---|---|
| 포메이션 카드 8장 | 미니 필드 + 이름 + 난도 + **숙련도 바**. 선택된 것 강조 |
| 지시 4개 | 수비 라인 · 활동량 · 압박 · 출전 배분 — 각 3단 세그먼트 + **수용률 %** |
| 각 지시 힌트 | 누가 무시할 것 같은지 한 줄 |
| 개인 지시 | 최대 2개. 대상 + 지시 + 수용률 |
| 수용 예측 패널 | 선택 포메이션의 **수용률 분해**(기본/숙련도/요구/변경 직후) · 지시별 따를/반반/무시 인원 · **대표 인물 설명** |
| 이 조합의 예상 | 텍스트 2~3줄 — `후반 20분경 체력 붕괴 가능성 높음` |

> 수치(기본 수용률 · 숙련도 증가폭 · 기질 계수)는 전부 미정. 구성은 [01-gdd.md](01-gdd.md) 11.5 확정.

## S-05 일정

> **확정 (검토 1회차)** — 탭 3개 → **2개.** 연간을 월간에 흡수(달 이동).
> **회원 가용 시간 겹쳐보기**를 추가했다 — 이게 없으면 21칸이 그냥 달력이다.

#### 탭 1 · 주간 ✅

| 섹션 | 들어가는 정보 |
|---|---|
| 요약 스트립 4칸 | 내 직업 + 근무 형태 · 쓸 수 있는 칸 · 배치한 칸 · **빈 칸** |
| **21칸 격자** | 7일 × 3시간대(아침/낮/저녁). 칸 상태 3종 — **근무(회색) / 배치(주황) / 경기(초록)** |
| 각 배치 칸 | 행동명 + 대상 (`김상수 / 따로 만남`) |
| 경기 칸 | 시각 + 상대 |
| **회원 가용 겹쳐보기** | 특정 회원을 지정하면 **그 사람과 내가 둘 다 되는 칸만 밝게** |
| 범례 | 3색 설명 + 칸 수 |

##### 회원 가용 겹쳐보기 — E16의 실제 구현체

GDD 10장이 이 게임의 진짜 고충으로 든 문장이 이것이다.

> **달래야 할 형님이 있는데 이번 주엔 시간이 안 맞는다.**

이게 성립하려면 **21칸에 상대의 가용 시간이 보여야 한다.**
플레이어 자기 일정만 있으면 21칸은 그냥 달력이고,
E16이 "포인트제를 안 쓰는 이유"로 든 논거가 화면에서 사라진다.

```
        월    화    수    목    금    토    일
아침   근무  근무  근무  근무  근무   ·    경기
낮     근무  근무  근무  근무  근무   ●     ·
저녁    ●     ●     ·     ●     ●     ●     ·
                   ↑
              김상수는 이날 야근
```

**진입 경로** — S-03 회원 상세에서 `따로 만나기` → 이 화면으로 오면서 대상이 지정된다.
겹치는 칸이 하나도 없으면 **이번 주에는 못 만난다.**

배치 가능한 행동은 GDD 10장의 10종 — 회원 모집·면접 · 회원 관리 · 회비 조정 ·
예산 배분 · 경기 섭외 · 소모임/회식 · 경조사 · 구장 예약 · 상대팀 섭외 · 규칙 제정.

#### 탭 2 · 월간 ✅

| 섹션 | 들어가는 정보 |
|---|---|
| 달력 | 4~5주. 날짜별 주요 일정. **달 이동으로 12개월 조망** |
| 표시 항목 | 경기 · 회식 · 회비 납부일 · 구장 예약 마감 · 대회 일정 |
| **기온 · 계절** | 날짜별 기온 표시. 겨울 = 대관료↑ 부상↑ / 여름 = 체력 소모↑ |
| 미예약 경고 | 경기 예정인데 구장이 없는 주 강조 |

##### 연간 탭을 없앤 이유

52주 조망이 답하는 것은 **"비시즌 없이 연중이다"** 인데,
이건 **한 번 알면 되는 사실**이지 매주 확인할 정보가 아니다.
계절과 기온은 달력에 표시하면 되고, 12개월을 훑고 싶으면 **달 이동**으로 된다.

반대로 월간이 답하는 **"앞으로 3~4주에 경기가 몇 번인가"** 는
구장 예약(S-09)을 미리 잡으려면 매달 필요하다.

> 월간이 담기로 했던 것 중 **미예약 경고와 회비 납부일은 S-01에도 있다.**
> S-01은 "이번 주에 처리할 것", 월간은 "앞으로 몇 주의 계획"으로 성격이 다르다.

## S-06 단톡방

> **확정 (검토 1회차)** — 탭 4개 → **1개(탭 없음).**
> 참석 탭은 S-01 탭2와 중복이라 넘겼고, 공지·잡담은 **필터 칩**으로 내렸다.
> **침묵 표시**와 **메시지 작성 방식**(자유 입력이 아니라 버튼 4개)을 명시했다.

#### 본문 · 단일 흐름 ✅

**탭으로 쪼개지 않는다.** 실제 단톡방에 탭이 없고,
쪼개는 순간 이 화면이 **분위기를 느끼는 곳에서 데이터베이스로** 바뀐다.
공지 밑에 "넵" 세 개가 달리고 그다음 침묵이 오는 것이 **한 화면에 있어야** 한다.

| 섹션 | 들어가는 정보 |
|---|---|
| 필터 칩 | `전체`(기본) · `공지만` · `잡담만` — 2~3개. 탭이 아니라 칩 |
| 메시지 행 | 보낸이 · 내용 · **읽음 수**(내 메시지) 또는 **회신 시각**(남의 메시지) |
| **시간 간격** | 메시지 사이 경과 표시. `— 3시간 경과 —` |
| **침묵 표시** | 답장이 끊긴 구간을 명시적으로 그린다 — `— 이후 답장 없음 · 3시간 경과 —` |

##### 침묵이 가장 많은 정보를 준다

```
나 (총무)   아직 두 자리 비어요. 용병 부르기 전에 한 번만 더...    읽음 12
—— 이후 답장 없음 · 3시간 경과 ——
```

**12명이 읽었는데 아무도 답을 안 했다**는 것은 어떤 수치보다 강한 신호다.
경과 시간이 없으면 그냥 목록의 끝일 뿐이고, **의미가 사라진다.**

##### 메시지 문체가 캐릭터를 드러낸다

`ㄱㄱ`(무뚝뚝) · `봐서요..`(회피) · `이번엔 좀 뛰게 해주세요 ㅋㅋ`(농담 형태의 불만).
문체 규칙은 13장 어투 시스템과 같은 데이터를 쓴다.

#### 우측 패널 `w196` ✅

| 섹션 | 들어가는 정보 |
|---|---|
| **읽고 답 안 한 사람** | 이름 + 지속 기간(`3주째` `8주째`). **이 화면의 핵심** |
| 안내 문구 | `읽었다는 것만 안다. 왜 답이 없는지는 직접 만나야 알 수 있다` |
| 참석 집계 | 참석 / 불참 / 미정 / 무응답 4행. **상세는 S-01 탭2** |
| **보내기 버튼 4개** | 아래 |

##### 자유 입력이 아니라 버튼 4개

플레이어가 아무 문장이나 쓰면 **시뮬레이션이 반응할 수 없다.**
GDD 10장의 **"고정 메시지 4종"** 이 이것이다 — 하단에 입력창이 아니라 버튼이 놓인다.

| 버튼 | 대가 |
|---|---|
| 참석 조사 | **주 1회 무료.** 그 이상은 시간이 필요 |
| 재촉 | **만족도 −.** 편하게 쓰는 버튼이 아니다 |
| 공지 | — |
| 잡담 | 분위기 · 궁합에 소폭 영향 |

##### 잡담은 회원끼리의 대화다 🔶

내가 보내는 잡담과 별개로, **회원끼리 주고받는 대화가 흐름에 섞여 나온다.**
관계와 파벌이 드러나는 유일한 통로지만 **생성 규칙이 미정**이다 —
이벤트 카탈로그(E67)와 같은 문체 데이터를 쓴다.

#### 트리 뱃지 — 방향을 바꾼다

| | |
|---|---|
| ~~안 읽은 메시지 수~~ | **내가** 안 읽은 것. 들어가면 어차피 보인다 |
| **답 없음 수** | **남이** 내 걸 읽고 답 안 한 것. **이 화면의 주제** |

두 개는 방향이 반대다. 뱃지는 후자를 센다.

##### 회비 설정이 빠져 있었다

GDD 10장 주간 행동 목록에 **"회비 금액 · 방식 조정 — 재정 ↔ 만족도"** 가 있고,
결정 로그에서 **"회비 방식도 플레이어가 정한다"** 고 했는데
화면에는 납부 현황만 있고 **설정하는 곳이 없었다.**

회비는 플레이어가 가진 **몇 안 되는 실질 레버**다 —
올리면 재정이 풀리고 만족도가 깎이고 **못 내는 사람이 생긴다.**

| 설정 항목 | 내용 |
|---|---|
| 금액 | 월 정액. 변경 시 **전원 만족도에 영향** |
| 징수 방식 | 월 정액 / 경기당 갹출 / 혼합 — 방식마다 반발하는 사람이 다르다 |
| 납부일 | 월 n일 |

**변경은 [O-7](#o-7-규칙--회비-개정)에서 한다.** 되돌릴 수 없고 전원에게 영향이 가므로
규칙 개정과 **같은 화면 · 같은 반발 예상**을 쓴다.

| 구매 | 유니폼 발주 — 단가 × 인원 · 납기 |

##### 소모품은 자동 구매로 내린다

공 · 조끼 · 구급 · 마커에는 **결정이 없다.**
떨어지면 사는 것이고, 안 사면 경기에 지장인데 **일부러 그럴 이유가 없다.**
관리 부담만 늘고 판단이 없으므로 **자동 구매**로 처리하고
지출만 거래 내역에 찍는다.

**유니폼은 다르다** — 적립 목표가 있고, 만족도에 영향이 있고, 스폰서 로고가 박힌다.
**적립의 주 목적이 유니폼이라 원래 한 이야기였다.**

## S-08 영입

> **확정 (검토 1회차)** — 탭 5개 → **4개.** 지인 소개를 지원자로 흡수(경로 열).
> 모집 공고를 **문구 선택에서 조건 5축으로** 바꿨다.
> 인원 표기 `12 / 30`이 하드 상한처럼 읽혀 **경고로** 내렸다.

#### 공통 · 요약 스트립 4칸 ✅

공고 상태 + 경과 주차 · 누적 지원 수 · 수락 수 · **현재 인원**

> `12 / 30` 표기를 쓰지 않는다. 결정 로그에서 **"크게 제한을 둘 생각은 아직 없다"** 고 했는데
> 분수 표기는 하드 상한으로 읽힌다. **현재 인원만 쓰고**,
> 인원이 늘 때의 부담은 우측 경고로 알린다.

#### 탭 1 · 모집 공고 ✅

**문구를 고르는 게 아니라 조건을 건다.** 문구는 조건에서 자동 생성된다.

| 조건 | 선택지 | 효과 |
|---|---|---|
| **포지션** | 무관 / GK / DF / MF / FW | 좁히면 **지원 수 ↓, 해당 POS 비율 ↑** |
| **연령대** | 무관 / 20~30대 / 30~40대 / 40대 이상 | 나이 곡선(2.2)상 능력 분포가 갈린다 |
| **경력** | 무관 / 초보 환영 / 경력자 | 초보는 능력 낮되 **성실함·친화력 경향** |
| **성향** | 무관 / 친목 위주 / 진지하게 | **승부욕·자존심 분포가 바뀐다** |
| **회비 명시** | 함 / 안 함 | 명시하면 지원 ↓, **미납 위험 ↓** |

| 섹션 | 들어가는 정보 |
|---|---|
| 조건 5축 | 위 표. 세그먼트 선택 |
| **예상 지원 수** | 조건에 따라 실시간 갱신 — `주당 1~2명 (무조건일 때 3~5)` |
| **생성된 공고문** | 조건 조각을 조합한 실제 게시글. **결과물이 눈에 보인다** |
| 게시 상태 | 게시 여부 · 경과 주차 · 주간 지원 추이 |

```
관악구 대신동FC입니다.
수비수 한 분 모십니다. 30~40대 환영, 초보도 괜찮습니다.
즐겁게 뛰실 분. 회비 월 3만원.
일요일 오전 6시 상평체육공원.
```

##### 조건이 만드는 갈등

> 인원이 급하다 → 조건 없이 올린다 → **아무나 온다** → 몇 달 뒤 문제가 된다
> 조건을 건다 → **안 온다** → 인원 미달 → 경기 취소 (11.7)

**S-01 탭2의 포지션 공백과 직접 이어진다** — `DF 1 부족`을 보고
여기서 `포지션: DF`를 걸면 DF 지원자가 온다.

> **문구 3~4종을 쓰는 것보다 콘텐츠 부담이 작다.** 조각을 조합하면 되고,
> 조합이 조건 수만큼 늘어난다.

#### 탭 2 · 지원자 ✅

**공고 지원자와 지인 소개를 한 표에 담는다.** 둘 다 *"내 결정 대기"* 상태라 같은 목록이다.

| 섹션 | 들어가는 정보 |
|---|---|
| 표 9열 | 이름 · 나이 · 소화 POS · **경로** · 직업 · 거주 · 이동 시간 · 경력 · **지원 사유** |
| 경로 열 | `공고` 또는 `김상수 소개` — **소개자 이름이 그대로 뜬다** |
| 우측 · 기본 | 근무 형태 · 거주지 · 혼인/자녀 |
| 우측 · 면접 전에 아는 것 | **경력 · 접근성 · 여유** 3축만. 바 형태 |
| 우측 · 안내 | `능력과 기질은 안 보인다. 면접을 하거나 몇 주 같이 뛰어봐야 드러난다` |
| 우측 · 할 수 있는 것 | 면접 **(시간 필요)** · 바로 수락(모르는 채로) · 거절 · 보류 |
| 우측 · **소개 경고** | 소개받은 사람이면 — `거절하면 김상수의 만족도가 떨어진다` |
| 우측 · 경고 | `회원이 늘면 비용도 는다 — 유니폼·회식이 인원 비례` |

> **면접 전에는 능력·기질을 보여주지 않는다.** 정보 공개 범위(2.8)가 가장 강하게 작동하는 화면.

#### 탭 3 · 영입 권유 🔶

**앞의 둘과 상태가 다르다** — 지원자는 *"내 결정 대기"* 인데
권유 대상은 **아직 아무것도 안 된 상태**다. 내가 먼저 접촉해야 한다.

| 섹션 | 들어가는 정보 | 상태 |
|---|---|---|
| 대상 목록 | 타 팀 회원 · **자주 오는 용병** | ✅ |
| 성공 확률 | 상대 팀에서의 처지 · 우리와의 접점 | 🔶 |
| **관계 위험** | 그 팀과 사이가 나빠진다. 반복하면 **기피 대상**(S-12) | ✅ |

#### 탭 4 · 용병 ✅🔢

**가입이 아니라 1회성이라 성격이 다르다.** 그리고 **인원 미달 시 경기 성립을 좌우한다**(11.7).

| 섹션 | 들어가는 정보 |
|---|---|
| 공고 게시 | 날짜 · 장소 · 필요 포지션 · **참가비 금액** |
| **참가비 설정** | 아래 |
| 응답자 목록 | 이름 · 나이 · POS · **과거 이력**(`지난달 2회 함께함`) |
| 응답률 | **경기까지 남은 날짜에 따라 달라진다** — 급하면 잘 안 온다 |

##### 참가비는 용병이 낸다 — 우리가 받는다

GDD 6장이 명확하다.

> 용병에게 사례비를 주는 일은 없다. **그냥 축구하고 싶어서 오는 사람들**이고,
> **그날 뛰는 값으로 참가비를 낸다.** 구장비 갹출 성격이다.

**용병은 수입이다.** 인원도 채우고 **구장비도 회수한다.**

| 참가비 | 지원자 | 재정 |
|---|---|---|
| 높게 | **적다** | 구장비를 많이 회수 |
| 낮게 | 많다 | 조금 회수 |

**구장 속성이 여기에 곱해진다** — 좋은 구장이면 비싸도 오고, 맨땅이면 싸도 안 온다.

##### 참가비가 취소 압박과 물린다

급한데 참가비를 높게 걸어놨으면 **아무도 안 온다.**
금액을 내리는 것은 언제든 되지만 **공고를 다시 올리면 시간이 간다** — 그사이 경기일이 다가온다.

**타이밍 딜레마(6장)에 금액 축이 하나 더 붙는 셈**이다.

| | 일찍 올림 | 늦게 올림 |
|---|---|---|
| 인원 파악 | 모른다 | 정확히 안다 |
| 지원자 | 많다 | 적다 |
| **참가비 여유** | **높게 불러도 된다** | **낮춰야 온다** |

## S-09 구장

> **확정 (검토 1회차)** — 탭 2개 → **1개.** 두 탭이 같은 표였다.
> **주 구장 지정을 삭제**(단골 등급과 중복), **정기 예약**과 **예약 실패 경로**를 추가했다.

#### 단일 화면 ✅🔢

| 섹션 | 들어가는 정보 |
|---|---|
| 요약 스트립 4칸 | 주 구장 · 이번 달 누적 대관비 · **단골 등급** · 기온 + 부상 영향 |
| 구장 표 10열 | 구장명 · 거리(분) · 잔디 · 규격 · 대관료 · **예약 방식** · 슬롯별 상태 · **단골 등급** · 과거 이용 횟수 · 비고 |
| 선택 구장 상세 | 시설(조명 · 주차 · 화장실) · **등급별 혜택** · 알려진 단점 |
| 이번 주 판단 | 텍스트 3줄 — 기온 · 규격 · 추첨 결과 대기 |
| **정기 예약** | 단골 3년+ 시 자동 갱신. **깨졌을 때만 알림** |

**탭을 나누지 않는 이유** — GDD 3.6이 구장을 **구마다 2~5개**로 정했다.
표가 5행짜리라 "예약"과 "구장 목록"을 나눌 크기가 아니다.

**예약 방식 3종** — 선착순 / 추첨 / 단골 우대. 각각 다른 게임이 된다.
**규격 미달 구장**(8인 · 5인)은 친선만 가능.

##### 주 구장 지정을 없앤다

| | |
|---|---|
| **단골 등급** | 누적 이용 → 등급 → 우선권. **자연 발생** |
| ~~주 구장 지정~~ | 명시적 선택 버튼 — **삭제** |

둘 다 있으면 중복이고, **톤에도 안 맞는다** — 조기축구단이 "주 구장을 지정"하지 않는다.
매주 거기 가다 보니 단골이 되는 것이다. 스트립의 `주 구장`은
**지정값이 아니라 최근 가장 많이 쓴 곳**을 자동으로 표시한다.

##### 정기 예약 — 단골 등급의 보상

같은 구장 같은 시간을 매주 잡는데 매주 화면을 여는 것은 노동이다.
실제 조기축구단도 **정기 대관**을 한다.

| 등급 | 혜택 |
|---|---|
| 신규 | 매주 직접 예약 |
| 단골 1~2년 | 슬롯 우선권 |
| **단골 3년+** | **정기 예약** — 매주 자동 갱신 |

**S-01 할 일의 `구장 미예약`이 예외 상황이 된다.** 평소엔 조용하다가
정기가 깨졌을 때(구장 공사 · 대회로 인한 취소)만 뜬다.

> **놓쳐서 취소되는 사고가 초반에만 일어나고, 팀이 자리 잡으면 사라진다.**
> 성장의 실감이 여기서도 나온다.

##### 예약 실패 — 경기 취소의 두 번째 경로

선착순은 늦으면 마감이고 추첨은 떨어진다. **구장을 못 잡아도 경기가 없다.**

```
추첨 떨어짐 → 다른 구장 시도 → 다 마감 → 경기 취소
```

| | 인원 미달 (11.7) | **구장 미확보** |
|---|---|---|
| 회원 만족도 | 크게 하락 | **작게 하락** — 총무 잘못이라기보다 운 |
| 상대팀 관계 | 악화 | **똑같이 악화** |
| 대관료 | 90% 환불 | **해당 없음** (예약 자체가 없음) |
| 구단 평판 | 하락 | 하락 |

## S-10 규칙

> **확정 (검토 1회차)** — 탭 3개 → **2개.** 벌금 탭이 담던 것이 전부 다른 화면에 있었다.
> 반발 표시를 **수치에서 이름 목록으로** 바꿨다. 기준값(🔢)은 별도로 잡는다.

**규칙을 만드는 것이 플레이어의 유일한 실질 권한이다**(00-concept).

| 탭 | 섹션 구성 | 상태 |
|---|---|---|
| 1 · 규칙 목록 | 규칙 8종 × (on/off · **기준값** · **벌칙 금액** · **반대하는 사람**) | 🔶 8종 확정, 기준값 미정 |
| 2 · 위반 이력 | 누가 · 언제 · 무엇을 · 처리 결과. **누적 횟수가 방출 사유가 된다** | ✅ |

##### 벌금 탭을 없앤 이유

담고 있던 것이 전부 다른 화면에 있었다.

| 벌금 탭 항목 | 실제 위치 |
|---|---|
| 항목별 금액 | **규칙 목록의 열** — 규칙마다 벌칙이 붙는다 |
| 이번 달 징수액 | **S-07 재정** — 거래 내역 `벌금` 구분 |
| 면제 이력 | **위반 이력의 처리 결과 열** |
| 누적 | S-07 |

규칙 8종 각각에 `무단 불참 → 10,000`이 붙으면 그것이 벌금 설정이다.

##### 반발은 수치가 아니라 이름으로

`현재 반발 정도`를 수치로 보여주면 **만족도에서 뺀 것과 같은 문제**가 생긴다.
**누가 싫어하는지 이름 목록**으로 표시한다 —
[O-7](#o-7-규칙--회비-개정)의 *"찬성할 사람 / 반대할 사람"* 과 같은 형식이라
**컴포넌트를 재사용**한다.

**규칙에는 반드시 반발이 따른다.** 무단 불참 벌금을 세우면 성실한 사람은 좋아하고
바쁜 사람은 싫어한다. 목록에 그 예상이 미리 표시된다.

##### 위반 이력을 남기는 이유

S-03 개인 연표에도 규칙 위반이 들어가지만 **범위가 다르다.**

| | |
|---|---|
| S-03 개인 연표 | **한 사람**의 시간순 |
| S-10 위반 이력 | **전원**의 시간순 |

*"이번 달에 몇 건 있었나"* 와 *"이 규칙이 실제로 작동하나"* 는 전원 목록이라야 보인다.

**변경 행위는 [O-7](#o-7-규칙--회비-개정)로 분리한다** — 체크박스로 처리하면 무게가 안 실린다.

#### 공통 · 연도 토글 ✅

`2029` / `2028` / … / **`통산`**

52주 연중이라 비시즌이 없지만(D3~D4) 기록은 **연 단위로 끊는다.**

|---|---|---|

| 2 · 개인 기록 | 회원별 **경기 기록만** — 출전 · 쿼터 · 득점 · 도움 · 평균 평점 · 경고 | ✅ |

#### 탭 1 · 표 8열

날짜 · 상대 · 결과 · 구장 · **출전 인원** · **용병 수** · 득점자 · **기억할 만한 일**

- `기억할 만한 일`은 이벤트 로그에서 자동으로 뽑은 한 줄. **득점보다 먼저 읽히도록 폭을 넓게** 잡는다
- `용병 수` 열이 있는 이유 — "우리 팀으로 이긴 게 맞나"라는 질문이 여기서 생긴다
- 행 더블클릭 → **하이라이트 리플레이**. 틱을 저장하지 않고 같은 시드로 엔진을 다시 돌린다(11.4)

#### 탭 2 · S-02와 열을 가른다

| 화면 | 담는 것 |
|---|---|
| **S-02 회원 명단** | **사람 정보** — 나이 · 가입 · 직업 · 상태(얼굴) · 칭호 |
| **S-11 개인 기록** | **경기 기록만** — 출전 · 쿼터 · 득점 · 도움 · 평점 · 경고 |

이 탭의 고유 가치는 **랭킹**이다. 득점왕 · 도움왕 · 개근이 **칭호(2.12)의 근거**가 된다.
그래서 정렬이 열마다 의미가 있고, S-02와 달리 **수치를 줄 세우는 것이 목적**이다.

> 능력을 줄 세우는 것은 막았지만(S-02) **기록을 줄 세우는 것은 막지 않는다.**
> 능력은 내부 평가고 기록은 **실제로 일어난 일**이다.

## S-13 연대기

**이 게임의 정서적 결산 화면.** 후반부에 값이 커진다 — 1년차에는 비어 있고 10년차에는 게임 전체의 요약이 된다.

> **확정 (검토 1회차)** — 탭 3개 유지, **내용을 채웠다.**
> GDD 4.10의 **물려받은 회원 비율**이 빠져 있어 스트립에 넣었고,
> 연표 형식은 4.10에 이미 정의돼 있어 🔶가 풀렸다.
> **떠난 뒤에는 숫자를 공개**하는 규칙과 **그 시점 명단 스냅샷**을 추가했다.

#### 공통 · 요약 스트립 4칸 ✅

거쳐 간 사람 수 · 현재 인원 · 평균 재적 기간 · **물려받은 회원 `n / n`**

##### 물려받은 회원 비율이 장기 목표의 계기판이다

GDD 4.10이 명시했는데 화면 어디에도 없었다.

```
물려받은 회원   3 / 14  (21%)
내가 받은 회원  20
```

**0이 되는 순간 이벤트가 발생한다** — *"이제 이 팀에 나보다 오래 있은 사람이 없다."*
E63의 "그만두는 순간" 후보이기도 하다. **연대기가 결산 화면이면 이 숫자가 여기 있어야 한다.**

`가장 오래 있은 사람`은 이 지표에 흡수된다.

| 탭 | 섹션 구성 | 상태 |
|---|---|---|
| 1 · 연표 | 연도별 기록 + **연도 선택 시 그 시점 명단** | ✅ |
| 2 · 거쳐 간 사람들 | 표 7열 + **선택 시 사후 공개 상세** | ✅ |
| 3 · 통계 | 이탈 사유 분포 + **운영 요약 문장** | ✅ |

#### 탭 1 · 연표 ✅

**형식은 GDD 4.10에 이미 정의돼 있다.**

```
3년차 (2029)
  성적    12승 8무 14패 · 3부 6위
  들어옴  6명   나감  4명
  기억할 것
    - 창단 멤버 심기국, 무릎으로 명예회원 전환
    - 신입 이규민 첫 골
    - 8월, 인원 미달로 2경기 취소
```

##### `기억할 것` 자동 생성 규칙

| 조건 | 문장 |
|---|---|
| 창단 멤버 이탈 · 명예회원 전환 | `창단 멤버 n, …` |
| 첫 골 · 첫 승 · 첫 우승 | `신입 n 첫 골` |
| 경기 취소 2회 이상 | `n월, 인원 미달로 n경기 취소` |
| 한 달에 3명 이상 이탈 | **대량 이탈** |
| 회원 수 최대 · 최저 갱신 | |
| 규칙 제정 · 폐지 | |
| 구장 이전 | |
| **물려받은 회원 0 도달** | 4.10 |

**플레이어 이전의 시간도 있다** — 인수(D1) 이전 연차는 요약만 표시된다.

##### 연도를 고르면 그 시점 명단

```
2024년 8월  — 정한수가 마지막으로 뛴 달

  서민규 · 이정표 · 최승철 · 정한수 · 류기범 · 손민기
  오세진 · 임태식 · 심기국 · 강대호 · 배준영

  ▸ 지금도 남아 있는 사람   2명
```

4.10의 *"5년이 지나니 그때 있던 사람은 3명만 남았다"* 가 화면에서 일어난다.
스냅샷은 **연 1회 + 이탈 시점**에 저장한다 — 이름 목록이라 용량이 작다.

#### 탭 2 · 거쳐 간 사람들 ✅

##### 표 7열

이름 · **재적 기간**(`2021~2023 · 2년`) · 출전 · 득점 · **떠난 이유** · 마지막 날짜 · **남긴 것**

| 열 | 규칙 |
|---|---|
| 떠난 이유 | 미화하지 않는다 — `규칙 위반 방출` `출전 불만` `자연 이탈` 그대로 |
| **남긴 것** | **이 게임에서 가장 중요한 텍스트.** 지금 화면에 남아 있는 것의 유래를 적는다 — `첫 유니폼을 이 사람이 골랐다` `회계 장부 양식이 이 사람 것` |
| 자동 생성 문장 | 출전이 팀 평균 30% 미만인 채로 불만 이탈 → `거의 못 뛰었다. 잘 챙기지 못했다` |
| 마지막 얼굴 | 떠날 때의 얼굴을 남긴다. **참을성 높은 사람은 웃는 얼굴로 기록된다** — 그게 더 아프다 |

##### 떠난 뒤에는 숫자를 공개한다

살아 있을 때는 얼굴만 보인다. 참을성이 높으면 그마저 가려진다(2.6).
**그런데 떠나고 나면 전부 보여준다.**

```
배준영 · 2021~2023 · 31경기

  마지막 6개월
    출전     1Q · 0Q · 0Q · 2Q · 0Q · 0Q
    만족도   44 → 38 → 31 → 25 → 19 → 12
    내가 만난 횟수   0회
    표시되던 얼굴    "그저 그럼"   ← 참을성 71
```

**이미 늦었으니까 보여줘도 된다. 그게 아프다.**

> 나는 "그저 그럼"으로 보고 있었고, 실제로는 44에서 12까지 내려가는 중이었고,
> 한 번도 안 만났다.

`거의 못 뛰었다. 잘 챙기지 못했다` 라는 문장의 **근거가 화면에 남는다.**
2.6의 참을성 보정이 **사후에 청구서로 돌아오는 유일한 지점**이다.

**하단 연결 문구** — 과거 기록을 현재의 경고로 잇는다.
`배준영 · 2년 · 31경기 — … 이규민이 지금 그 자리에 있다`

#### 탭 3 · 통계 ✅

| 섹션 | 들어가는 정보 |
|---|---|
| 통산 | 전적 · 평균 재적 · 최다 기록 · 포지션별 누적 |
| **이탈 사유 분포** | 사유별 인원 + 비율 |
| **운영 요약 문장** | 아래 |

##### 이탈 사유 분포가 내 운영의 지문이다

| 분포 | 읽히는 것 |
|---|---|
| **출전 불만**이 많다 | 이기려고만 했다 |
| **자연 이탈**이 많다 | 챙기지 못했다 |
| 이사 · 육아가 많다 | 어쩔 수 없었다 |
| 규칙 위반 방출이 많다 | 문턱을 높게 세웠다 |

이걸 **문장 한 줄로 요약**한다.

> 12년 동안 47명이 거쳐 갔다. 그중 **11명이 못 뛰어서 나갔다.**

**E69와 충돌하지 않는다** — 진행 중에 판단을 대신해 주는 것이 아니라 **결산이다.**
이미 일어난 일을 세어 보여주는 것뿐이다.

| **직책 위임** | 주장 · 회계 · 장비 담당 + 적임자 추천 (GDD 5.5 · E46) | ✅ |
| 이력 | 재임 기록 · 통산 전적 · **내가 한 일** · 시작 시 4축 | ✅ |

> **신뢰가 여기 있어야 하는 이유.** S-04는 "누가 내 말을 안 듣는가"를 보여주지만
> **왜 안 듣는지의 절반은 나에게 있다.**

#### 신뢰 — 움직이는 방법까지 적는다

**"팀 평판은 물려받지만 개인 신뢰는 0부터다"**(5.4). 초반 압박의 정체가 이것이다.

> 팀은 알아도 나는 모른다.

| 올리는 것 | 깎는 것 |
|---|---|
| 약속 지키기 *(자기 규칙 준수)* | **예외 두기** |
| 일관된 집행 | 설정 자주 변경 *(말 바꾸기)* |
| 경기 성사 | 방출 통보 |
| 경조사 챙김 | **경기 취소** |

목록만 있고 움직이는 방법이 화면에 없으면 **플레이어가 신뢰를 관리할 수가 없다.**

#### 직책 위임 — 21칸을 푸는 유일한 수단

GDD 5.5(E46)가 정한 3종인데 화면 어디에도 없었다.
**행동 제약이 시간대(E16)인 게임에서 위임은 그 제약을 푸는 유일한 장치**다.

| 직책 | 대신 해주는 것 | 필요한 자질 | 리스크 |
|---|---|---|---|
| **주장** | 회원 관리 일부 (10장) | 영향력 · 친화력 | 그 사람 색깔이 팀에 스며든다 |
| **회계** | 회비 징수 · 독촉 (9.2) | 성실함 | **감정적 부담을 넘긴다** — 미움도 넘어간다 |
| **장비 담당** | **유니폼 발주 · 관리** (9.3) | 성실함 | 발주 실수 |

각 직책에 **적임자 추천**이 뜬다 — 자질에 맞는 회원 2~3명.

> **장비 담당의 역할을 유니폼으로 재정의했다.** 원래 "소모품 · 내구재"였는데
> S-07에서 **소모품을 자동 구매로 내리면서 이 직책이 할 일이 없어졌다.**
> 유니폼은 남겼고, 사이즈를 취합해 발주하는 것은 실제 조기축구단의 일이다.

**지정은 여기서, 표시는 해당 화면에서** — S-07 회비 탭에 `회계: 최승철`이 뜬다.

#### 이력 — S-13과 짝을 이룬다

| | |
|---|---|
| **S-13 연대기** | 팀에게 **일어난** 일 |
| **S-14 이력** | 내가 **한** 일 |

| 항목 | 내용 |
|---|---|
| 재임 | 인수 시점부터 n년차 · 통산 전적 |
| **내가 한 일** | 방출 n회 · 규칙 n개 제정 · 경기 취소 n회 · 면접 n회 · **회원을 만난 총 횟수** |
| 시작 시 4축 | 캐릭터 생성값 — 사실상 난이도(E62). **이력에 흡수**했다, 못 바꾸는 값을 상시 노출할 이유가 없다 |

**S-13의 "운영 요약 문장"과 짝이다** — 거기가 결과라면 여기는 행위다.
*"11명이 못 뛰어서 나갔다"* 옆에 *"회원을 만난 총 횟수 34회"* 가 있으면 그 자체로 문장이 된다.

## 설정

트리에 두지 않고 타이틀 바에서 연다.

> **확정 (검토 1회차)** — `경고 알림`이 무엇을 켜는지 명확히 하고,
> **스킨 미리보기**와 **시드 표시**를 추가했다. 접근성 섹션은 항목이 둘뿐이라 화면으로 흡수.

| 섹션 | 들어가는 정보 |
|---|---|
| 화면 | 해상도 · 전체화면 · **스킨 A~D + 미리보기 4장** · 글자 크기 · 색맹 모드 |
| 게임 | 자동 저장 주기 · 배속 기본값 · **회원 경고 알림**(기본 꺼짐) |
| 자동화 | 용병 자동 호출 · 신입 자동 거절 — **기본 꺼짐**(4.9) |
| 정보 | **시드**(읽기 전용) · 버전 |

#### 회원 경고 알림이 켜는 것

검토를 거치며 S-01에 **할 일 영역**이 생겼다. 그래서 E69가 말한 "경고 알림"의
범위를 명확히 해야 한다.

| | 상태 |
|---|---|
| **할 일 영역** — 구장 미예약 · 인원 부족 · 회비 미납 | **항상 켜짐.** 사무는 알려준다 |
| **회원 경고** — 이탈 위험 · 불만 누적 | **기본 꺼짐.** 이것이 E69의 옵션 |

켜면 S-01 비고 열과 S-03 경고 박스에 **내부 판정이 표시**된다.
관찰이 어려운 플레이어를 위한 장치이지 기본값이 아니다.

> 사실상 **접근성 옵션에 가깝다** — "어려우면 켜세요."
> 켜는 순간 2.6의 참을성 보정도 무력해지므로, **끄고 하는 것이 설계 의도**다.

#### 스킨은 미리보기가 있어야 고를 수 있다

`A 클래식 / B 현대 / C 새벽 / D 잔디` — **색이 전부인데 이름만 있으면** 고를 수가 없다.
표 몇 줄이 들어간 작은 썸네일 4장을 나란히 둔다.

#### 시드를 읽을 수 있어야 한다

결정론(1.2)이 이 게임의 기반인데 시드를 확인할 곳이 없었다.

- 개발 중 **버그 재현**에 필요하다
- 출시 후에도 *"같은 시드로 다시"* 가 성립한다

**읽기 전용**으로 표시한다. 입력받아 새 게임을 시작하는 것은 뉴게임 화면의 일이다.

#### 색맹 모드가 할 일이 적어졌다

검토를 거치며 UI가 **색에 덜 의존하게** 됐다.

| 요소 | 색 없이도 구분되는 이유 |
|---|---|
| 만족도 | **얼굴 모양이 다르다** |
| 폼 스파크 | `●◐○·` 기호 |
| 참석 · 불참 | 텍스트 |

**만족도를 얼굴로 고른 것이 여기서 이득을 봤다.**
색맹 모드는 상태색 팔레트 교체 정도만 하면 된다.

## S-M1 경기 전 브리핑

전체화면. 주중 골격(트리·탭·상태 바)을 쓰지 않는다 — **다른 모드로 들어간다는 것을 화면으로 알린다.**

| 섹션 | 들어가는 정보 | 상태 |
|---|---|---|
| 헤더 | 양팀명 · 날짜 · 시각 · 구장 · 잔디 · **기온 + 날씨** | ✅ |
| 좌 · 우리 | 선발 11 표 — POS · 이름 · 나이 · **경기 시작 체력** · **얼굴**. 용병은 표식 | ✅ |
| 좌 · 교체 대기 | 인원수 + 명단. **0명이면 경고 문구** | ✅ |
| 중 · 상대 | 창단 연차 · 회원 수 · 전력 평가 · 상대 전적 · 최근 결과 | ✅ |
| 중 · 성향 4축 | 거칠기 · 체력 · 조직력 · 매너 (바) | ✅🔢 |
| 중 · 알려진 것 | 텍스트 2~4줄 + **우리 쪽 위험 요소** | ✅ |
| 중 · **지시 요약** | 포메이션 + 지시 4개를 한 줄로 | ✅ |
| 우 · 경기 전 판단 | 경고 박스 3~4개. **이 경기에서 터질 것 같은 일을 미리 적는다** | ✅ |
| 우 · **수용률** | 평균 수용률 + **무시 예상 n명 · 이름** | ✅🔢 |
| 우 · 수지 예고 | 대관료 **지출** · 용병 참가비 **수입** → 예상 잔액 | ✅ |
| 하단 | `라인업 수정` / **`경기 시작`** + "되돌릴 수 없다" 상시 노출 | ✅ |

> 경고 박스가 **예언처럼 쓰인다.** "심기국 · 체력 31 · 후반에 반드시 떨어진다"가 실제로 68분에 일어난다.
> **몰라서 당하는 게 아니라 알면서도 못 막는** 구조.

##### 지시 요약과 수용률이 여기 있어야 한다

S-04에서 포메이션과 지시 4개를 정해놓고 **마지막 확인 지점에서 안 보였다.**

```
4-4-2 (숙련 18) · 라인 내림 · 활동량 아끼기 · 압박 보통 · 출전 고르게
평균 수용률 64%   무시 예상 4명 — 심기국 · 김상수 · 박현범 · 이정표
```

**S-M2에서 `✗` 표시로 확인될 것을 미리 아는 자리다.**
경고가 "예언처럼 쓰인다"고 해놓고 **가장 중요한 예언이 빠져 있었다.**

##### 선발 표에 얼굴을 넣는다

`POS · 이름 · 나이 · 체력`만 있었는데 **만족도가 수용률에 걸린다**(11.5).
얼굴이 있으면 *"저 사람 오늘 말 들을까"* 가 읽힌다. 한 칸이면 된다.

##### 경고 박스에는 관찰 가능한 것만

| 경고 | 판정 |
|---|---|
| `교체 없음 — 11명 정확히` | ✅ 사실 |
| `심기국 · 58세 · 3°C · 체력 31` | ✅ 관찰 가능 |
| `박현범 · 경고 2회` | ✅ 기록 |
| ~~`이규민 불만 누적`~~ | ❌ **내부 판정.** 설정에서 회원 경고를 켠 경우에만 |

##### 용병 참가비는 수입이다

**우리가 주는 돈이 아니라 받는 돈**이다 (GDD 6장 — *"용병에게 사례비를 주는 일은 없다"*).
용병은 인원을 채우면서 **구장비를 회수해 준다.**

여기서는 확정이 아니라 **수지 예고**다 — 확정은 S-04에서 끝났다.

## S-M2 매치 뷰어

**바둑알 + 체력 링.** 아트 0장, 전부 `_draw()`.

> **확정 (검토 1회차)** — **교체 거부 드로어**와 **지시 변경 팝오버**를 정하고,
> 우측에 얼굴을 넣고, 배속 4x 자동 전환을 명시했다.
> 전술 오버레이는 **개발 전용**으로 못박아 🔶를 닫았다.

| 섹션 | 들어가는 정보 | 상태 |
|---|---|---|
| 헤더 | 양팀명 · 스코어 · **경기 시각**(전/후반 mm:ss) · 구장 · 기온 | ✅ |
| 필드 | 잔디 스트라이프 + 라인 + **바둑알 22개 + 공** | ✅ |
| 우 · 출전 | 등번호 원 + 이름 + 체력 바 + **얼굴** 11행. **필드와 같은 색으로 대응** | ✅ |
| 우 · 주의 | 체력 위험 · 경고 누적 · **교체 대기 없음** | ✅ |
| 우 · 로그 | 최근 3~5줄. 시각 + 문장 | ✅ |
| **드로어** | **교체 거부 대사** — O-1 컴포넌트 재사용 | ✅ |
| **팝오버** | 지시 변경 4개 | ✅ |
| 하단 컨트롤 | 일시정지 · 배속 1/2/4x · 건너뛰기 · 텍스트 모드 · 교체 · 지시 변경 | ✅ |

##### 교체 거부는 드로어로 멈춰 세운다

GDD 5.4가 이것을 **"컨셉의 핵심 장면"** 이라고 했다.
그런데 표시 방식이 정해지지 않아 S-M3 로그의 결과 한 줄로만 남을 뻔했다.

**핵심 장면을 로그로 흘려보내면 안 된다.** 경기가 멈추고 아래에서 말한다.

```
▶ 심기국 「형, 저 아직 괜찮아요.」
                                    ［확인］
```

**선택지가 없는 것이 핵심이다.** 거부는 통보지 협상이 아니다.
플레이어가 할 수 있는 것은 확인뿐이고, 그 사람은 계속 뛴다.

##### 지시 변경 팝오버

지시 4개만 바꾼다. **포메이션은 못 바꾼다** — 경기 중이니까.

팝오버에 이 문구를 상시 노출한다.

```
지시를 바꿔도 이미 안 듣기로 한 사람은 계속 안 듣습니다
```

**11.5의 "재굴림 없음"을 화면에서 알려주지 않으면** 플레이어가
*"바꾸면 되겠지"* 하고 계속 만지게 된다.

##### 우측 패널에 얼굴을 넣는다

S-M1에는 넣었는데 여기엔 체력만 있었다.
**90분이 지나면 누가 어떤 상태였는지 잊는다.**
교체를 누르기 전에 **거부할 것 같은지**를 알려면 얼굴이 필요하다.

##### 배속 4x 이상이면 텍스트 모드로 자동 전환

빠르게 돌릴 때 **원은 어차피 안 보인다.**
수동으로 텍스트 모드를 켤 수도 있고, 배속을 낮추면 자동으로 돌아온다.

#### 바둑알 표기 규약 ✅

| 표기 | 뜻 |
|---|---|
| 파랑 원 + 번호 | 우리 팀. **이름은 우리 팀만** 붙는다 |
| 빨강 원 | 상대 (번호만) |
| 노랑 원 | GK · 양팀 공통 |
| **원 둘레 게이지** | **체력.** 초록(60+) → 노랑(40~60) → 빨강(40 미만) |
| 흰 테두리 | 볼 소유 |
| 노랑 테두리 + `⚠` | 경고 누적 · 주의 |
| 빨강 테두리 | 체력 위험 |
| **주황 테두리 + `✗`** | **지시를 무시하는 중** (11.5) |
| `*` 번호 | 용병 |

**남은 확인** — GK 노랑과 선택색 주황이 소형 표시(3px)에서 구분이 애매하다.

#### 전술 오버레이 — **개발 전용** ✅

| 섹션 | 들어가는 정보 |
|---|---|
| 압박 존 | 상대 압박 범위 음영 |
| 라인 표시 | 지시한 수비 라인 위치 + 실제 위치 |
| 효용 값 | 볼 소유자의 선택지별 점수 (`패스 .72 / 드리블 .48 / 슛 .21`) |
| 틱 정보 | 시드 · 현재 틱 · 0.25x · 한 틱씩 진행 |

**11.2 효용 함수를 튜닝할 때 필수**지만 **플레이어에게는 열지 않는다.**

`패스 .72 / 드리블 .48 / 슛 .21` 을 보여주면 **엔진의 속이 그대로 드러나** —
이 게임이 관찰로 알아가는 구조인데 정면으로 충돌한다.
만족도 숫자를 감춘 것과 같은 이유다.

**설정에도 노출하지 않는다.** 실행 인자나 디버그 빌드로만 켠다.

|---|---|---|
| 헤더 | 스코어 · 승/무/패 · 상대 · 구장 · **시즌 통산 갱신** | ✅ |
| 좌 · 경기 기록 | 시간순 전체 이벤트. 득점 · 경고 · 부상 · **교체 거부** · 체력 소진 | ✅ |
| 좌 · 기록 | 점유 · 슛 · 파울 · 주행거리 | ✅🔢 |
| 중 · 개인 평점 표 | 이름 · 출전 쿼터 · 평점 · **얼굴 + 변화 방향**(`▲` `▼` `—`) · 비고. 용병은 상태 없음 | ✅🔢 |
| 우 · 이 경기가 남긴 것 | 긍정/주의 카드 2~4장 + **상대 관계 변화** | ✅ |
| 우 · **지시 결산** | 따른 수 / 무시 수 · **신뢰 변화** · 한 줄 요약 | ✅🔢 |
| 우 · 정산 | 대관료 **지출** · **용병 참가비 수입** · 단골 등급 진행 → 잔액 | ✅ |
| 하단 | `하이라이트 다시 보기` / **`주간 정산 ▶`** | ✅ |

##### 지시 결산 — 신뢰가 움직이는 유일한 순간

11.5의 결과 판정 5종이 표로만 있고 **화면 어디에 뜨는지 없었다.**
S-14에서 신뢰를 *"전술 수용률과 교체 거부의 근거"* 라고 했는데
**그것이 움직이는 순간이 여기인데 표시가 없었다.**

```
지시 결산
  따른 사람 7명  ·  무시 4명
  결과 승        →  신뢰 ▼2

  "아끼라 했지만 심기국은 끝까지 뛰었고, 이겼다."
```

**결과 판정 5종** — 지시를 따랐는지 × 이겼는지로 신뢰가 오르내린다.

| 상황 | 결과 |
|---|---|
| 무시 + 승 | 그 사람 만족도 ↑ · **플레이어 신뢰 ↓** |
| 무시 + 패 | 신뢰 ↑ · 다음 경기 수용률 ↑ |
| 따름 + 승 | 신뢰 ↑↑ · **포메이션 숙련도 +2** |
| 따름 + 패 | 신뢰 ↓ · `"그러게 내 맘대로 할 걸"` 이벤트 가능 |
| 아끼라 했는데 무시 → 부상 | 본인 만족도 ↓↓ · 신뢰 ↑ |

> **이겼는데 잃는 사람이 있다.** 승리가 모두를 만족시키지 않는다는 것이 이 표의 요지.

##### 이 경기가 기록되는 곳

`이 경기가 남긴 것`은 **한 곳이 아니라 네 곳으로 흐른다.**

| 대상 | 무엇이 |
|---|---|
| **S-03 개인 연표** | 첫 골 · 부상 · 언쟁 · 칭호 획득 — **그 사람의 역사** |
| **S-13 연대기** | `남긴 것` 열 · 연표의 `기억할 것` |
| **S-11 경기 기록** | 표 한 행 + `기억할 만한 일` |
| **S-12 상대팀** | **관계 변화** · 과거 사건 로그 |

**상대 관계 변화를 빼면 안 된다** — 거친 경기였거나 언쟁이 있었으면
**다음에 이 팀과 경기를 잡기 어려워지는 원인**이 여기서 생긴다.

##### 화면 흐름

```
S-01 [주 진행] → S-M1 → S-M2 → S-M3 → O-3 주간 정산 → S-01
```

**S-M3는 경기 결산이고 O-3는 주간 결산**이다. 겹치지 않는다 —
O-3에는 회비 입금 · 지원자 도착 · 다음 주 예고가 들어간다.

그래서 하단 버튼이 `다음 주로`가 아니라 **`주간 정산 ▶`** 이다.

## 오버레이

> **확정 (검토 1회차)** — O-5에 **능력 5 추가**(S-04가 여기로 보냈는데 빠져 있었다),

### O-1 이벤트 드로어

13장 이벤트 시스템의 **출력이 전부 여기로 흐른다.** 모달이 아니라 상태 바 위로 열린다.

| 상태 | 높이 | 섹션 구성 | 상태 |
|---|---|---|---|
| 없음 | `0` | — | ✅ |
| 알림 | `h30` | 한 줄 + 확인 | ✅ |
| 선택 필요 | `h88` | **구분 라벨**(`［이벤트］ 출전 불만 · 5단계`) + **대사** + **선택지 2~4개** | ✅ |
| 연속 | `h88` | 위와 같음 + 우측에 `2 / 5` | ✅ |

**동시에 일어나는 것** — 대상 회원의 행이 표에서 강조되고, 우측 패널이 그 사람 정보로 바뀐다.

> **모달이 아닌 것이 결정적이다.** 이규민의 탈퇴 선언을 듣는 동안
> 그 사람의 만족도 18 · 기술 62 · 체력 74가 계속 보인다.

##### 경기 중에도 같은 컴포넌트를 쓴다

S-M2의 **교체 거부**가 이 드로어로 나온다.
다만 **S-M2는 골격을 안 써서 상태 바가 없으므로** 하단 컨트롤 바 위로 열린다.
**위치만 다르고 컴포넌트는 같다.**

| 쓰이는 곳 | 열리는 위치 |
|---|---|
| 주중 화면 | 상태 바 위 |
| **S-M2 매치 뷰어** | **하단 컨트롤 바 위** |
| **O-6 면접** | 같은 컴포넌트로 대화 진행 |

### O-2 확인

**되돌릴 수 없는 행동에만** 붙는다.

| 대상 | 표시 정보 |
|---|---|
| 방출 | 대상 · 재적 기간 · 다른 회원 반응 예상 |
| 탈퇴 수리 | 대상 · 남길 기록 |
| **경기 취소** | 환불액 · 손실 · **만족도 하락 예상**(참석 예정자는 더 크게) · 상대 관계 · 평판 |
| 규칙 · 회비 개정 | [O-7](#o-7-규칙--회비-개정)이 담당 |

목록을 늘리지 않는다. 남용하면 무게가 사라진다.

### O-3 주 진행 결과

한 주의 결산. **사실상 화면급 정보량**이지만 닫으면 S-01로 돌아가는 흐름이라 오버레이로 둔다.

| 섹션 | 들어가는 정보 | 상태 |
|---|---|---|
| 이번 주 일어난 일 | 색점 + 한 줄 × 5~8개. 경기 결과 · 만족도 변화 · 경고 · 이탈 위험 · **미처리 항목** | ✅ |
| 재정 | 이번 주 입출금 + 잔액 | ✅ |
| 다음 주 | 상대 · **구장 미예약 경고** · 결장자 · 가용 인원 | ✅ |
| 하단 | "되돌릴 수 없다" + 확인 | ✅ |

##### 주 유형 3종

경기가 있는 주만 가정하고 있었다. 실제로는 셋이다.

| 주 | 흐름 | O-3의 역할 |
|---|---|---|
| 경기 있음 | S-01 → S-M1~M3 → **O-3** | 경기 외의 것 — 회비 · 지원자 · 다음 주 |
| **경기 없음** | S-01 → **O-3** | 유일한 결산 |
| **취소됨** | S-01 → **O-3** | **유일한 결산 + 취소 결과** — S-M3가 없다 |

**취소된 주가 가장 조용하다.** 경기 화면 셋이 통째로 건너뛰어지고
O-3에 만족도 하락과 상대 관계 악화만 적힌다. **그 공백이 곧 벌이다.**

### O-4 저장 / 불러오기

슬롯 **3개.** 캐릭터 생성 4축이 사실상 다른 게임이라 병행이 필요하다.
스커밍은 슬롯 수가 아니라 **시드 고정**으로 막는다(1.2).

| 섹션 | 들어가는 정보 |
|---|---|
| 슬롯 카드 3장 | 구단명 · 연차 · 주차 · 회원 수 · 전적 · 저장 시각 |
| 자동 저장 | 별도 슬롯 1개. 주 진행 시 갱신 |

### O-5 회원 빠른보기

표에서 이름 hover 시 뜨는 작은 카드. **화면 이동 없이 확인**하기 위한 것.

이름 · 나이 · POS · **얼굴** · 최근 8주 폼 · **능력 5** · 상태 칩 2~3개

##### 능력 5가 여기 있어야 하는 이유

S-02에서 명단의 능력 열을 없애며 **"세부 능력은 O-5로 본다"** 고 했고,
S-04에서도 **"가용 인원 목록에는 적성 등급만, 능력 5는 O-5"** 로 보냈다.
**그런데 O-5 명세에 능력이 없었다** — 보낸 곳에 받을 자리가 없었던 셈이다.

능력을 표에서 뺀 것은 **줄 세우기를 막기 위해서**지 감추기 위해서가 아니다.
**한 사람씩 보는 것은 언제든 된다.**

### O-6 면접 대화 🔶

S-08 지원자 탭에서 진입. **O-1과 같은 컴포넌트를 쓴다.**

| 섹션 | 들어가는 정보 | 상태 |
|---|---|---|
| 상대 | 이름 · 나이 · 사진 자리 | ✅ |
| 질문 선택지 | 3~5개. **축은 아래로 확정**, 문구는 미정 | 🔶 문구 |
| 답변 | 텍스트. **기질이 부분적으로 드러난다** — 능력은 여전히 안 보인다 | 🔶 |
| 진행 | 질문 n회 제한 → 수락 / 거절 / 보류 | 🔶 횟수 미정 |

##### 질문 축은 공고 조건과 짝을 이룬다

S-08 공고가 조건 5축으로 거르므로, **면접은 조건으로 못 거른 것을 확인하는 자리**다.

| 공고 조건 | 면접에서 확인 |
|---|---|
| 성향 | 이기는 것과 어울리는 것 중 뭐가 더 중요한가 → **승부욕 · 자존심** |
| 경력 | 전에 어디서 뛰었나 → 경력의 진위 |
| 연령 · 포지션 | *(공고에서 이미 걸렀다)* |
| 회비 명시 | 회비가 감당되나 → **미납 위험** |
| — | **시간이 되나** → 직업·근무 형태. **조건으로 못 거른다** |

**"시간이 되나"가 공고에 없는 축이다.** 21칸 제약(E16)의 상대편이라
면접에서만 알 수 있고, 이게 면접을 하는 가장 큰 이유가 된다.

### O-7 규칙 · 회비 개정 🔶

S-10 · **S-07 회비 탭**에서 진입. **되돌릴 수 없고 전원의 만족도에 영향**을 준다.

| 섹션 | 들어가는 정보 | 상태 |
|---|---|---|
| 대상 | 규칙명 또는 **회비 항목**(금액 · 징수 방식 · 납부일) · 현재 → 바꿀 상태 | ✅ |
| 기준값 | 슬라이더 또는 단계 선택 | 🔶 |
| **반발 예상** | 찬성할 사람 / 반대할 사람 목록 + 이유. **전술 수용 예측과 같은 방식** | ✅ |
| 예상 영향 | 팀 평균 만족도 변화 · 재정 영향 | 🔢 |
| 확인 | "되돌릴 수 없다" | ✅ |

##### 회비도 여기서 바꾼다

S-07에서 회비 설정을 만들며 *"O-7과 같은 무게"* 라고 했는데,
O-2 목록에도 없고 O-7 대상도 아니어서 **둘 사이에 걸쳐 있었다.**

**화면이 하는 일이 같다** — 되돌릴 수 없고, 전원에게 영향이 가고, **누가 반발할지 미리 보여준다.**
회비 방식도 결국 팀의 규칙이다.

| 대상 | 반발하는 사람 |
|---|---|
| 무단 불참 벌금 | 바쁜 사람 |
| 회비 인상 | **여유 없는 직업**(2.7) |
| 경기당 갹출로 전환 | 자주 나오는 사람 |
| 월 정액으로 전환 | 가끔 나오는 사람 |

**징수 방식을 바꾸면 반발하는 쪽이 정반대로 뒤집힌다** — 이것이 회비를 규칙과 같이 다루는 이유다.
