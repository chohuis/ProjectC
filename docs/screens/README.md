## 고치고 다시 뽑기

```powershell
cd docs\screens
.\build.ps1
```

`src\p*.html` 을 순서대로 이어 붙여 `spec.html` 을 만들고,
Edge(없으면 Chrome)를 헤드리스로 돌려 PDF 를 뽑는다.

| 조각 | 범위 |
|---|---|
| `src/p1.html` | CSS + 표지 + 시스템 개요 — **문서가 여기서 시작한다** |
| `src/p2a.html` | S-01 ~ S-03 |
| `src/p2b.html` | S-04 ~ S-06 |
| `src/p2c.html` | S-07 ~ S-13 |
| `src/p3.html` | 경기 화면 + 오버레이 + 부록 — `</body></html>` 로 닫는다 |

조각을 나눈 이유는 편집 단위를 작게 두기 위해서다.
화면 하나를 고치려면 해당 조각만 열면 된다.
**스타일은 전부 `p1.html` 한 곳에 있다.**

`.\build.ps1 -KeepHtml` 을 쓰면 합쳐진 `spec.html` 이 남는다.
브라우저로 열어 확인한 뒤 PDF 를 뽑고 싶을 때 쓴다.

## 스크린샷을 고칠 때

게임 화면은 `940px` 폭으로 그린 뒤 `transform: scale(.7395)` 로 줄여 A4 폭에 맞춘다.
프레임 높이는 클래스로 준다.

```html
<div class="frame h400"><div class="g h400"> … </div></div>
```

`h340` `h400` `h420` `h432` `h452` 가 있다.
바깥 `.frame` 과 안쪽 `.g` 의 클래스를 **같이** 바꿔야 잘리지 않는다.

색은 `.g` 안에서 CSS 변수로만 쓴다 (`var(--sel)`, `var(--tx2)` …).
스킨 C 새벽 값이 `.g` 에 박혀 있으므로 다른 스킨으로 뽑으려면 거기만 바꾸면 된다.

## 알아둘 것

- **PDF 는 생성물이다.** 문서를 고쳤으면 `build.ps1` 을 다시 돌려서 함께 커밋한다
- `spec.html` 은 빌드 중간 산출물이라 `.gitignore` 에 있다
- 인쇄 색이 나오려면 `print-color-adjust: exact` 가 필요하다 — `p1.html` 상단에 있다
- 브라우저 프로필 디렉터리를 따로 주지 않으면 이미 떠 있는 브라우저에 붙어서 아무것도 안 한다
