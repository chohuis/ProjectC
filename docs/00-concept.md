# 00. 컨셉

> "어떻게 만드는가"는 [01-gdd.md](01-gdd.md).

## 한 줄 정의

**조기 축구단을 운영하는 매니지먼트 게임.**
축구를 잘하게 만드는 게임이 아니라, **회원들이 계속 나오게 만드는 게임**이다.

## 코어 판타지

플레이어는 프로 구단 감독이 아니라 **동네 조기축구단 감독 겸 총무**다.

FM의 감독은 왕이다. 지시하면 실행된다.
이 게임의 감독은 **눈치를 본다.** 교체하자고 했더니 형님이 거부하고, 아침에 못 나온다는
연락이 오고, 회비 얘기를 언제 꺼낼지 고민한다.

> **핵심 감정: 권한이 없는 사람이 조직을 굴러가게 만드는 일.**

### 권한이 없는 사람은 어떻게 조직을 움직이는가

이 게임이 주는 답은 **규칙**이다.

| | 통하는가 |
|---|---|
| 개별 지시 ("너 오늘 빠져") | **거부당한다** |
| 미리 세워둔 규칙 ("무단결석 3회면 탈퇴") | **통한다** |

감독의 진짜 힘은 지시가 아니라 **규칙 제정**이다. 권한 없는 사람이 조직을 움직이는
현실적인 방법이 이것이고, 게임의 주요 결정도 여기에 걸린다.

---

## 세 개의 목표 축

플레이어마다 원하는 게 다르다. **게임이 목표를 정해주지 않는다.**

| # | 축 | 내용 |
|---|---|---|
| 1 | **승리** | 많이 이기는 강팀, 대회 우승. 프로가 아니어도 이기면 기분 좋다 |
| 2 | **화목** | 회원들이 골고루 뛰고 분위기 좋은 팀 |
| 3 | **규모** | 회원 많고 유명한 팀 |

중복 추구도 가능하다. 많이 이기면서 골고루 뛰고 사람도 많은 팀을 노려도 된다.
**다만 셋을 동시에 최대화할 수는 없다.**

### 목표는 선언하지 않는다

시작할 때 "우리 팀의 목표를 고르시오" 같은 화면은 **없다.**
운영 결정이 쌓이면서 팀 성격이 저절로 굳는다.

- 친선경기 위주로 돌리면 → 승부형 회원이 답답해하며 떠난다
- 대회만 나가면 → 출전형 회원이 벤치에서 삭는다
- 회비를 낮추면 → 사람은 모이는데 경기를 못 잡는다

**남아 있는 회원 구성이 곧 플레이어가 선택한 방향이다.** 게임은 그걸 읽으면 된다.

## 축들은 서로 물려 있다

```
        ┌─────────── 승리 (강팀) ───────────┐
        │                                    ↓
   전력 ↑                                평판 ↑
        ↑                                    ↓
   잘하는 사람 위주 기용            지원자 증가 → 골라 받을 수 있음
        ↑                                    ↓
        │                              회원 수 ↑
        │                                    ↓
        │                  출전 수요 ↑ / 갈등 조합 ↑ / 관리 부담 ↑
        │                                    ↓
        └──────── 벤치 불만 ↑ ──────── 화목 유지가 어려워짐
                      ↓
                 이탈 / 분위기 악화
                      ↓
                   전력 ↓
```

**성공이 스스로 문제를 만든다.** 이기고 유명해질수록 사람이 몰리고, 몰릴수록 벤치가
늘고, 벤치가 늘수록 팀이 흔들리고, 흔들리면 다시 약해진다.
어떤 전략도 영원히 지배하지 못한다.

## 코어 루프

```
운영 결정   →   회원 만족도   →   참석 / 이탈   →   경기 성사와 결과   →   평판   →   유입
(경기 수, 회비,      (성향별로                                                         │
 라인업, 규칙)        다르게 반응)                                                     │
     ▲                                                                                │
     └──────────────────── 규모가 커져 결정이 더 어려워짐 ───────────────────────────────┘
```

## 플레이어가 쥔 손잡이

직접 정하는 것:

- **경기 수** — 많이 잡으면 골고루 뛰지만 돈이 나간다
- **경기 종류** — 친선 / 리그 / 대회. 교체 여유와 승리의 무게가 다르다
- **회비 금액과 방식** — 월 정액 / 경기당 참가비 / 혼합
- **예산 배분** — 같은 돈을 경기에 쓸지 회식에 쓸지
- **라인업** — 누구를 내보낼지
- **규칙** — 얼마나 엄격하게, 그리고 예외를 둘지
- **누구를 받을지** — 면접에서 거절할 수 있다

직접 정하지 못하는 것:

- 회원이 실제로 나올지 (확률)
- 교체 지시를 받아들일지 (거부 가능)
- 회원의 인생 (이사, 결혼, 육아, 부상)

## 입구는 통제되고 출구는 통제되지 않는다

**FM은 방출이 자유롭지만 조기축구단은 사람을 못 내보낸다.**

실력이 형편없어도, 분위기를 흐려도 "나오지 마세요"라고 말하기가 거의 불가능하다.
동호회니까. 방출은 가능하되 **비싸다** — 남은 회원들의 만족도가 급락하고, 친한 회원이
같이 나간다. 할 수는 있지만 안 하는 게 낫다.

그래서 **받을 때 신중해야 한다.** 정보가 불완전한 상태에서 되돌리기 어려운 결정을 한다.
FM에서 영입 실패는 손절하면 되지만, 여기서는 몇 년을 같이 가야 한다.

규칙에 근거한 탈퇴는 예외다. 같은 사람을 내보내도 **독단은 감독이 나쁜 놈**이 되고,
**규칙 위반 누적은 본인이 자초한 일**이 된다.

## 차별점 (FM 대비)

| | FM | 조기축구 매니저 |
|---|---|---|
| 지시 | 100% 전달됨 | **전달될지부터 불확실** (거부, 불참, 컨디션) |
| 선수 | 계약된 자원 | **자기 인생이 있는 사람** (결혼, 이사, 무릎) |
| 방출 | 자유롭다 | **거의 불가능. 하면 내가 나쁜 놈** |
| 권한 | 지시 | **규칙 제정** |
| 실패 | 성적 부진, 경질 | **인원 미달로 경기 취소** |
| 목표 | 우승 | 게임이 정해주지 않는다 (세 축) |
| 텍스트 | 부속물 | **게임의 엔진** |

## 톤

- 코믹 · 유쾌 (기본값)
- 현실적 · 씁쓸함 (배경음)
- 짠하고 따뜻함 (가끔, 결정적일 때)
- **열혈 스포츠물 아님** — 승부물이 아니라 생활물이다

승리는 목표가 아니라 **분위기**다. "지난주 이겨서 다들 기분 좋음" 정도지 우승을 향해
달리는 게 아니다. 다만 이기는 게 아무 의미도 없으면 능력치가 장식이 되므로,
승리는 세 축 중 하나로 존재한다.

### 톤 가이드라인: 어디까지가 짠함이고 어디부터가 우울인가

| 쓰지 않음 | 사용함 |
|---|---|
| 이혼, 실직, 큰 병 | 이사, 야근, 육아, 무릎 |
| 돈 문제로 인한 절연 | 옆 동네 팀 회비가 더 싸다더라 |
| 진짜 원한 | 그냥 시들해짐, 연락이 뜸해짐 |

같은 "한 명이 사라졌다"라도 전자는 **슬프고**, 후자는 **아쉽다.**
이 게임은 아쉬움만 다룬다. 그리고 아쉬움만으로도 플레이어는 충분히 붙잡으려 애쓴다.

회원 간 분쟁과 불화는 **사용한다.** 단, 비극이 아니라 코미디로 처리한다.

## 배경

실제 한국 동네. 새벽 인조잔디 구장, 회비, 단톡방, 아이스박스, 용병, 뒤풀이.

> 주의: 실제 협회명 · 리그 공식 명칭 · 실존 팀/인물 이름은 사용하지 않는다.
> 지명과 일반명사는 자유.

## 구조

- 시즌이 끝없이 반복. **엔딩 없음**
- **게임 오버 없음.** 대신 인원 미달 → 경기 취소/몰수가 실질적 실패
- 잃는 축(회원 이탈, 노화)과 쌓이는 축(승격, 평판, 창단 멤버의 연차)이 동시에 존재
- 팀이 분열해 나가면 **라이벌 팀**이 되어 계속 남는다

## 절대 하지 않는 것

- 잔인한 연출
- 과금 / 광고
- 멀티플레이 / 온라인
- **실제 축구 조작** (직접 공을 차는 액션 요소) → 경기 화면은 100% 관전
- 무거운 소재 (이혼, 실직, 병, 절연)

## 타깃

1차: 조기축구를 하는 / 해본 한국인
2차: 매니지먼트 시뮬레이션 애호가
플랫폼: PC (Steam), 한국어 우선

명백한 니치다. 다만 이 소재에 감응하는 사람에게는 **대체재가 존재하지 않는다.**

## 알려진 리스크

| 리스크 | 대응 |
|---|---|
| 개발자가 조기축구 경험이 없음 | **취재를 일정에 포함** (용병 참여 2~3회). 단 구현 1~3단계와 병행 |
| 첫 게임 + 매니지먼트 시뮬 = 큰 스코프 | 프로토타입으로 재미부터 검증. 구현 범위는 기획 완료 후 잘라낸다 |
| **설계 논의 중 시스템이 계속 늘어남** | 설계는 넓게, 구현은 좁게. 전체를 [04-elements.md](04-elements.md) 로 가시화 |
| 주 5~10시간, 기간 미정 | 기간을 단계로 쪼개 각 단계에 종료 조건 부여 |
| 텍스트 물량이 최대 작업량 | 이벤트 작성을 상시 병행 작업으로 일정화 |
| 목표를 게임이 안 정해줌 = 방향 상실 | 세 축의 현황 지표를 항상 보여줄 것. **자유가 공백이 되면 안 된다** |
