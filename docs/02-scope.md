## M1 — 코어 루프 프로토타입

> 목표: **"세 축 사이에서 조율하는 게 재미있는가?"** 이것 하나만 검증한다.
> 재미없으면 여기서 멈춘다. 아트·사운드·경기 화면 없이 네모와 글씨로만 만든다.

**예산: 3개월 / 약 100시간**

- [ ] 1. 회원 데이터 모델 + 성향 + 만족도 계산 (순수 GDScript, UI 없음)
- [ ] 2. 헤드리스 시즌 시뮬레이터 (콘솔 출력, 100시즌 돌려 밸런싱)
- [ ] 3. 참석 판정 + 라인업 + 재정 로직 (여전히 UI 없음)
- [ ] 4. 최소 UI — **노드 3종 제한** (`ItemList`/`Button`/`RichTextLabel`)
- [ ] 5. 이벤트 시스템 + 20개 작성
- [ ] 6. 경기 텍스트 로그
- [ ] 7. **직접 플레이. 재미 판정** ← 진짜 목적지

범위 상세와 "넣지 않는 것" 목록은 [01-gdd.md](01-gdd.md) 12장 참조.

## 스코프 방어선

> 여기에 적힌 것은 "안 한다". 하고 싶어지면 이 문서를 먼저 고칠 것.

- 멀티플레이어 / 온라인: 안 함
- 실제 축구 조작(액션): 안 함. 경기는 100% 관전
- 정밀 물리 경기 시뮬레이션: 안 함. 연출형으로 간다
- 세이브 슬롯 다중화: 안 함
- 로컬라이제이션: M4 이후 검토
